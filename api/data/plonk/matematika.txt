=== osnove_logike
## Izjave in povezave
\(\neg A\) :: negacija: resnična, ko je \(A\) neresnična :: \(A\): »7 je sodo« (N), \(\neg A\) (R)
\(A \wedge B\) :: konjunkcija »in«: R samo, ko sta obe R :: \(2 < 3 \wedge 3 < 1\): N
\(A \vee B\) :: disjunkcija »ali«: N samo, ko sta obe N :: \(2 < 3 \vee 3 < 1\): R
\(A \Rightarrow B\) :: implikacija: N samo pri R \(\Rightarrow\) N :: \(N \Rightarrow R\) je R
\(A \Leftrightarrow B\) :: ekvivalenca: R, ko imata enako vrednost :: \(R \Leftrightarrow N\): N
## Vrstni red in tabela
\(\neg,\ \wedge,\ \vee,\ \Rightarrow,\ \Leftrightarrow\) :: od najmočnejše do najšibkejše :: \(\neg A \vee B \wedge C = (\neg A) \vee (B \wedge C)\)
\(2^n\) vrstic :: resničnostna tabela za \(n\) izjav :: 3 izjave: 8 vrstic
## Tavtologija in enakovrednost
tavtologija :: vedno resnična :: \(A \vee \neg A\)
protislovje :: vedno neresnična :: \(A \wedge \neg A\)
\(A \Rightarrow B \sim \neg A \vee B\) :: implikacija brez puščice :: \(\neg(A \Rightarrow B) \sim A \wedge \neg B\)
\(\neg(A \wedge B) \sim \neg A \vee \neg B\) :: De Morgan (tudi \(\neg(A \vee B) \sim \neg A \wedge \neg B\)) :: ni res, da (dežuje in sneži) = ne dežuje ali ne sneži
\(A \Rightarrow B \sim \neg B \Rightarrow \neg A\) :: obrat s kontrapozicijo :: če je deljivo s 4, je sodo = če ni sodo, ni deljivo s 4
! Implikacija z neresnično predpostavko je vedno resnična.
! Negacija »in« je »ali« (in obratno).

\(n_1 \cdot n_2 \cdots n_k\) :: pravilo produkta (zaporedne izbire) :: 3 majice, 4 hlače: 12 kombinacij
\(n_1 + n_2\) :: pravilo vsote (ali, ali) :: 5 knjig ali 3 filmi: 8 možnosti
## Razporeditve
\(P_n = n!\) :: permutacije: vrstni red vseh :: 4 osebe v vrsto: \(24\)
\(P_n^{k_1, k_2, \ldots} = \frac{n!}{k_1!\,k_2!\cdots}\) :: s ponavljanjem :: besedi ANA: \(\frac{3!}{2!} = 3\)
\(V_n^r = \frac{n!}{(n - r)!}\) :: variacije: izbor \(r\) z vrstnim redom :: 1., 2., 3. mesto med 10: \(720\)
\(\bar{V}_n^r = n^r\) :: variacije s ponavljanjem :: PIN s 4 števkami: \(10^4\)
\(C_n^r = \binom{n}{r} = \frac{n!}{r!\,(n - r)!}\) :: kombinacije: brez vrstnega reda :: 3 izmed 10: \(120\)
## Binomski izrek
\((a + b)^n = \sum_{k=0}^{n} \binom{n}{k} a^{n-k} b^k\) :: binomski izrek :: \((x + 1)^3 = x^3 + 3x^2 + 3x + 1\)
\(\binom{n}{k} = \binom{n}{n-k}\) :: simetrija; \(\binom{n}{k} + \binom{n}{k+1} = \binom{n+1}{k+1}\) :: Pascalov trikotnik: \(1, 4, 6, 4, 1\)
\(\binom{n}{k} a^{n-k} b^k\) :: \((k + 1)\)-ti člen :: 3. člen \((x + 2)^5\): \(\binom52 x^3 \cdot 4 = 40x^3\)

=== verjetnostni_racun
## Dogodki
\(A \cup B\), \(A \cap B\), \(\bar{A}\) :: vsota, produkt, nasprotni :: kocka: \(A\) sodo, \(\bar A\) liho
\(A \cap B = \emptyset\) :: nezdružljiva dogodka :: »pade 1« in »pade 6«
## Verjetnost
\(P(A) = \frac{m}{n}\) :: ugodni / vsi enako verjetni :: kocka, praštevilo: \(\frac36 = \frac12\)
\(P(\bar{A}) = 1 - P(A)\) :: nasprotni dogodek :: vsaj ena šestica v 2 metih: \(1 - \frac{25}{36} = \frac{11}{36}\)
\(P(A \cup B) = P(A) + P(B) - P(A \cap B)\) :: vsota dogodkov :: karta: srce ali as: \(\frac{13 + 4 - 1}{52}\)
\(P(A \cap B) = P(A)P(B)\) :: neodvisna dogodka :: dve glavi: \(\frac14\)
\(P(A \mid B) = \frac{P(A \cap B)}{P(B)}\) :: pogojna :: sodo, če je \(> 3\): \(\frac23\)
\(\binom{n}{k} p^k (1 - p)^{n-k}\) :: \(k\) uspehov v \(n\) poskusih :: 2 šestici v 3 metih: \(3 \cdot \frac{1}{36} \cdot \frac56\)
