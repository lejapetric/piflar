=== temeljni_pojmi
## Kaj je filozofija
ljubezen do modrosti :: kritično spraševanje o temeljih :: Sokrat: »Vem, da nič ne vem.«
## Zgradba izpita
esej + komentar besedila :: pisni del :: izbira naslova eseja
## Merila
razumevanje, argumentacija, uporaba pojmov :: ocenjevanje :: jasna teza
## Temeljni pojmi
bit, resnica, dobro, svoboda, um :: temeljni pojmi :: metafizika, etika, epistemologija
## Argument in sklepanje
premisi → sklep :: argument :: Vsi ljudje so smrtni; Sokrat je človek; Sokrat je smrten.
dedukcija / indukcija :: nujno / verjetno :: iz primerov k splošnemu
veljavnost / resničnost :: oblika / vsebina :: veljaven argument z napačno premiso
zmote :: ad hominem, slamnati mož, krožni sklep :: »Ne verjemi mu, ker je mlad.«
! Veljaven argument ni nujno resničen.

=== filozofski_esej
## Izbira naslova
izberi naslov, ki ga znaš problematizirati :: izbira :: povezava z obravnavanimi deli
## Analiza pojmov
razčleni ključne pojme naslova :: definicije :: »svoboda« kot odsotnost prisile / samodoločitev
## Zgradba
uvod s problemom, jedro z argumenti in protiargumenti, sklep :: zgradba :: navezava na filozofe
## Primeri naslovov
iz kataloga :: navezava na temo :: »Ali je človek svoboden?«
## Postopek in čas
načrt, pisanje, pregled :: razporedi čas :: 10 minut za načrt
! Esej ni obnova: razpravljaj.

=== platon_drzava
