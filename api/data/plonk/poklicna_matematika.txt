=== ulomki_odstotki
## Ulomki
\(\frac{a}{b} \pm \frac{c}{d} = \frac{ad \pm bc}{bd}\) :: seštevanje (najmanjši skupni imenovalec) :: \(\frac12 + \frac13 = \frac56\)
\(\frac{a}{b} \cdot \frac{c}{d} = \frac{ac}{bd}\) :: množenje :: \(\frac23 \cdot \frac34 = \frac12\)
\(\frac{a}{b} : \frac{c}{d} = \frac{a}{b} \cdot \frac{d}{c}\) :: deljenje: pomnoži z obratno vrednostjo :: \(\frac12 : \frac14 = 2\)
\(0{,}\overline{ab} = \frac{ab}{99}\) :: periodični decimalni zapis :: \(0{,}\overline{6} = \frac23\)
## Razmerja
\(a : b = c : d \iff ad = bc\) :: sorazmerje :: \(3 : x = 6 : 8\): \(x = 4\)
razdelitev v razmerju \(a : b\) :: deli celote \(\frac{a}{a+b}\), \(\frac{b}{a+b}\) :: 60 v \(2 : 3\): 24 in 36
## Odstotki
\(d = \frac{p}{100} \cdot c\) :: delež :: 15 % od 80 = 12
\(p = \frac{d}{c} \cdot 100\) :: odstotek :: 12 od 48 = 25 %
\(c = \frac{d \cdot 100}{p}\) :: osnova :: 20 % je 30, celota 150
\(c \cdot \left(1 \pm \frac{p}{100}\right)\) :: podražitev, pocenitev :: 80 € + 25 % = 100 €
! Po podražitvi za 20 % in pocenitvi za 20 % cena ni enaka začetni.
