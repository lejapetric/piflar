=== skloni_cleni_de

=== glagolski_casi_de
## Sedanjik
-e, -st, -t, -en, -t, -en :: končnice :: ich mache, du machst
a → ä, e → i/ie :: močni glagoli :: fahren: du fährst; sehen: er sieht
ločljive predpone :: na konec stavka :: Ich stehe um 7 Uhr auf.
## Pretekli časi
Perfekt: haben/sein + Partizip II :: govorjeni preteklik :: Ich habe gegessen. Ich bin gefahren.
sein :: glagoli premikanja in spremembe stanja :: Er ist eingeschlafen.
Präteritum :: pisni preteklik; war, hatte, modalni :: Ich war müde.
Plusquamperfekt :: hatte/war + Partizip II :: Nachdem ich gegessen hatte, …
## Prihodnjik, velelnik, modalni
werden + nedoločnik :: Futur I :: Ich werde lernen.
velelnik :: du: Komm! ihr: Kommt! Sie: Kommen Sie! :: Sei ruhig!
können, müssen, dürfen, sollen, wollen, mögen :: modalni + nedoločnik na koncu :: Ich muss heute arbeiten.
! nicht müssen = ni treba, nicht dürfen = ne smeš.

=== odvisniki_de
## Priredje

deshalb, trotzdem, dann :: prislovi: inverzija :: Es regnet, deshalb bleibe ich.
## Vrste odvisnikov

## Oziralni odvisniki

## Posredna vprašanja

=== konjunktiv_de
## Oblike

## Neresnični pogoji
Wenn ich … wäre, würde ich … :: sedanjost :: Wenn ich reich wäre, würde ich reisen.
Wenn ich … hätte, hätte ich … :: preteklost :: Wenn ich Zeit gehabt hätte, wäre ich gekommen.
## Želje, nasveti, vljudnost
Wenn ich doch … :: želja :: Wenn ich doch mehr Zeit hätte!
Du solltest … :: nasvet :: Du solltest mehr schlafen.
Könnten Sie …? :: vljudnost :: Könnten Sie mir helfen?
als ob + Konjunktiv II :: kot da :: Er tut so, als ob er krank wäre.
! Po »als ob« je glagol na koncu.

=== trpnik_de

## Trpnik stanja in nadomestne oblike
