Pogojniki in želje

Cela razlaga

1Štirje pogojniki

0: if + present, present
splošna resnica
If you heat ice, it melts.
1: if + present, will
realna prihodnost
If it rains, I'll stay home.
2: if + past, would
neresnično zdaj
If I had money, I would travel.
3: if + past perfect, would have + V3
neresnična preteklost
If I had studied, I would have passed.

2Mešani in drugi vezniki

3 + 2
pretekli pogoj, sedanja posledica
If I had taken the job, I would be rich now.
unless, provided, as long as, in case
drugi vezniki
Unless you hurry, you'll be late.
inverzija (VR)
brez if
Had I known, I would have come.

3Želje

wish + past
želja zdaj
I wish I were taller.
wish + past perfect
obžalovanje preteklosti
I wish I hadn't said that.
wish + would
nadležnost, sprememba
I wish you would stop.
it's time / would rather + past
čas je / raje bi
It's time we left.

!Pazi

  • Za »if« ni »will«: If it rains (ne: will rain).
