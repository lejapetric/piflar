Pogojniki in želje

Pogojni stavek ima dva dela: pogoj (if-stavek) in posledico. Kateri čas uporabiš, je odvisno od tega, ali je pogoj resničen, malo verjeten ali nemogoč, ker se je že zgodil. Isto logiko uporabljajo želje z wish in if only.

3Podpoglavja
3Tipi nalog
~10 minBranja

Kar moraš znati

  • zero: if + present, present (dejstva); first: if + present, will (realna možnost)
  • second: if + past, would + osnovna oblika (neresnično zdaj); if I were
  • third: if + past perfect, would have + V3 (neresnično v preteklosti)
  • mešani: if + past perfect, would + osnovna oblika (pretekli vzrok, sedanja posledica)
  • v if-stavku nikoli will ali would (razen vljudnostnega if you would…)
  • I wish / if only + past (zdaj), + past perfect (preteklost), + would (motnja, želja po spremembi)

Formula: čim bolj neresnično, tem bolj »nazaj« greš s časom: present → past → past perfect.

Podpoglavja

Štirje osnovni pogojniki

Zero, first, second, third.

Razlaga

TipIf-stavekGlavni stavekPomen
zeropresent simplepresent simplesplošno dejstvo: If you heat ice, it melts.
firstpresent simplewill / can / may + Vrealna prihodnost: If it rains, we'll stay in.
secondpast simplewould / could / might + Vneresnično ali malo verjetno zdaj: If I had more time, I would travel.
thirdpast perfectwould / could / might have + V3neresnično v preteklosti: If she had studied, she would have passed.

Stavka lahko zamenjata vrstni red. Ko je if-stavek prvi, za njim napišemo vejico: If I were you, I'd apologise. / I'd apologise if I were you.

Was ali were?

V drugem pogojniku je v knjižni angleščini za vse osebe were: If he were taller, he could play basketball. Na maturi je were vedno pravilen.

Pazi: First conditional uporablja present tudi pri drugih časovnih veznikih: when, as soon as, before, after, until. I'll call you when I arrive (ne when I will arrive).

Tipi nalog v tem sklopu

Tip 1: Vstavi pravilno obliko v pogojni stavek

Naloga

Complete with the correct form: If I ___ (know) about the party, I ___ (come). Unfortunately nobody told me.

Kako prepoznaš: vrzel je v stavku z if (ali unless), glagol je v oklepaju.

  • „if“
  • „correct form“
  • „verbs in brackets“
Univerzalni postopek

  1. Ugotovi, ali gre za preteklost, sedanjost ali prihodnost.

    nobody told me → preteklost.

  2. Ugotovi, ali je pogoj resničen ali neresničen.

    Nisem vedel → neresnično.

  3. Izberi tip in zapiši obe obliki.

    Third: had known, would have come.

  4. Preveri vejico, nikalnice in krajšave.

    If I had known about the party, I would have come.

Še nekaj primerov

Primer 1: If you ___ (not hurry), you ___ (miss) the bus.

Realna prihodnost: don't hurry, will miss.

Primer 2: She ___ (buy) that house if she ___ (have) enough money, but she doesn't.

Neresnično zdaj: would buy, had.

Mešani pogojniki in drugi vezniki

Ko se časa v obeh delih razlikujeta.

Razlaga

Mešani pogojnik poveže dva različna časa:

  • pretekli pogoj → sedanja posledica: If I had taken the job, I would be rich now. (past perfect + would + V)
  • sedanja lastnost → pretekla posledica: If she were more careful, she wouldn't have crashed the car. (past + would have + V3)

Drugi vezniki

VeznikPomenPrimer
unlessrazen če (= if … not)You won't pass unless you study.
provided / providing (that), as long aspod pogojem, daYou can borrow it as long as you give it back.
in caseza primer, da (previdnost, ne pogoj)Take an umbrella in case it rains.
otherwisesicerHurry, otherwise we'll be late.
suppose / supposing, imaginerecimo, daSuppose you won the lottery, what would you do?

Inverzija (VR)

V formalnem slogu if izpustimo in obrnemo besedni red: Had I known = If I had known; Were I you = If I were you; Should you need help = If you need help.

Tipi nalog v tem sklopu

Tip 2: Pretvorba: povej isto z drugim veznikom

Naloga

Complete the second sentence so that it means the same: I didn't go to bed early, so I am tired now. → If I ___, I ___ tired now.

Kako prepoznaš: dana je poved in začetek druge povedi, ki mora pomeniti isto.

  • „means the same“
  • „complete the second sentence“
  • „unless“
Univerzalni postopek

  1. Ugotovi dejstva v prvi povedi in njihov čas.

    Nisem šel spat zgodaj (preteklost) → utrujen sem zdaj (sedanjost).

  2. Obrni dejstva: pogojni stavek govori o nasprotnem.

    didn't go → had gone; am tired → wouldn't be.

  3. Izberi tip glede na čase obeh delov.

    Mešani: past perfect + would + V.

  4. Zapiši in preveri, da pomeni isto.

    If I had gone to bed early, I wouldn't be tired now.

Še nekaj primerov

Primer 1: You must hurry or you will be late. → Unless ___.

Unless you hurry, you will be late.

Primer 2: If I were you, I would tell her. → Were ___.

Were I you, I would tell her.

3 · 3

Želje: wish, if only, would rather, it's time

Neresnične želje uporabljajo iste »časovne korake«.

Razlaga

Želja o …StrukturaPrimer
sedanjostiwish / if only + past simpleI wish I had a car. (nimam ga)
preteklosti (obžalovanje)wish / if only + past perfectIf only I hadn't said that.
drugi osebi, ki naj se spremeniwish + would + VI wish you would stop talking.
sposobnostiwish + couldI wish I could swim.

Podobno delujejo: - would rather + oseba + past: I'd rather you didn't smoke here. (ista oseba: I'd rather stay.) - it's (high) time + past: It's time we left. - as if / as though + past: He talks as if he knew everything.

Pazi: I wish I would ni pravilno: would po wish uporabimo le za druge osebe ali stvari. Za sebe uporabi could ali past.

Tipi nalog v tem sklopu

Tip 3: Izrazi željo ali obžalovanje

Naloga

Rewrite using wish: I'm sorry I didn't listen to my parents. → I wish ___.

Kako prepoznaš: poved izraža žal, nezadovoljstvo ali motnjo; začetek je I wish ali If only.

  • „I wish“
  • „If only“
  • „rewrite“
Univerzalni postopek

  1. Ugotovi, ali se želja nanaša na zdaj, preteklost ali vedenje druge osebe.

    didn't listen → preteklost.

  2. Pomakni čas en korak nazaj in obrni trditev.

    didn't listen → had listened.

  3. Zapiši.

    I wish I had listened to my parents.

Še nekaj primerov

Primer 1: My brother keeps borrowing my clothes. → I wish ___.

Motnja: I wish my brother would stop borrowing my clothes.

Primer 2: I can't speak French. → If only ___.

If only I could speak French.

Ključ: kateri tip naloge je to?

Poišči besedo iz navodila naloge in skoči na pravi postopek.

V navodilu naloge piše …Tip
„if“, „correct form“, „verbs in brackets“Tip 1 · Vstavi pravilno obliko v pogojni stavek
„means the same“, „complete the second sentence“, „unless“Tip 2 · Pretvorba: povej isto z drugim veznikom
„I wish“, „If only“, „rewrite“Tip 3 · Izrazi željo ali obžalovanje

Pogoste napake

  • will ali would v if-stavku: If I will see him… → If I see him…
  • Zamenjan vrstni red časov v third conditional: If I would have known → If I had known.
  • unless z nikalnico: unless you don't study pomeni ravno nasprotno; unless je že nikalen.
  • in case uporabljen kot if: in case pomeni previdnost (vzameš dežnik vnaprej).
  • I wish I would namesto I wish I could / I wish I had.
