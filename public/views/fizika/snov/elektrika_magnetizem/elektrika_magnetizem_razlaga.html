Elektrika in magnetizem

Vse o elektriki in magnetizmu za maturo: električni naboj in Coulombov zakon, električno polje in napetost, električni tok in upor, Ohmov zakon, električna moč in delo, vezave uporov, magnetno polje, Lorentzova sila in elektromagnetna indukcija.

1. Teorija — pojmi in formule

Kar moraš znati na pamet, preden se lotiš nalog.

Elektrostatika

Električni naboj

\(e\) [C]

Osnovni naboj: \(e_0 = 1{,}6 \cdot 10^{-19}\) C. Naboj je kvantiziran.

Coulombov zakon

\(F = \dfrac{1}{4\pi\varepsilon_0} \dfrac{e_1 e_2}{r^2}\)

\(\varepsilon_0 = 8{,}85 \cdot 10^{-12}\) F/m.

Jakost električnega polja

\(E = \dfrac{F}{e}\) [N/C]

Električna napetost

\(U = \dfrac{A}{e}\) [V]

Delo, ki ga opravi polje pri premiku naboja.

Homogeno polje

\(E = \dfrac{U}{d}\)

\(d\) = razdalja med ploščama kondenzatorja.

Kapaciteta kondenzatorja

\(C = \dfrac{e}{U}\) [F]

Ploščni kondenzator

\(C = \varepsilon_0 \varepsilon_r \dfrac{S}{d}\)

Energija kondenzatorja

\(W = \dfrac{1}{2}CU^2 = \dfrac{1}{2}eU\)

Enosmerni električni tok

Električni tok

\(I = \dfrac{e}{t}\) [A]

Ohmov zakon

\(U = RI\)

\(R\) = upor [Ω].

Upor vodnika

\(R = \rho \dfrac{l}{S}\)

\(\rho\) = specifični upor, \(l\) = dolžina, \(S\) = presek.

Odvisnost upora od temperature

\(R = R_0(1 + \alpha \Delta T)\)

Električna moč

\(P = UI = \dfrac{U^2}{R} = I^2 R\) [W]

Električno delo

\(A = UIt = Pt\) [J]

Pogosto v kWh: 1 kWh = 3,6 MJ.

Zaporedna vezava

\(R = R_1 + R_2 + \ldots\)

Tok je enak, napetosti se seštevajo.

Vzporedna vezava

\(\dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2} + \ldots\)

Napetost je enaka, tokovi se seštevajo.

Magnetizem

Magnetna sila na vodnik

\(F = BIl\sin\alpha\)

\(B\) = gostota magnetnega polja [T], \(\alpha\) = kot med vodnikom in poljem.

Lorentzova sila (naboj)

\(F = e v B \sin\alpha\)

Magnetno polje ravnega vodnika

\(B = \dfrac{\mu_0 I}{2\pi r}\)

\(\mu_0 = 4\pi \cdot 10^{-7}\) T·m/A.

Magnetno polje v tuljavi

\(B = \mu_0 \dfrac{N}{l} I\)

Magnetni pretok

\(\Phi = BS\cos\alpha\) [Wb]

Faradayev zakon indukcije

\(U_i = -\dfrac{\Delta \Phi}{\Delta t}\)

Inducirana napetost v vodniku

\(U_i = B l v\)

Transformator

\(\dfrac{U_1}{U_2} = \dfrac{N_1}{N_2}\)

Za idealni transformator: \(P_1 = P_2\).

Izmenični tok

Efektivna vrednost napetosti

\(U_{\text{ef}} = \dfrac{U_0}{\sqrt{2}}\)

Efektivna vrednost toka

\(I_{\text{ef}} = \dfrac{I_0}{\sqrt{2}}\)

Moč izmeničnega toka

\(P = U_{\text{ef}} I_{\text{ef}} \cos\varphi\)

\(\cos\varphi\) = faktor moči.

Frekvenca (EU)

\(f = 50\) Hz, \(T = 0{,}02\) s

2. Tipi nalog — postopki po korakih

Za vsak tip: kako ga prepoznaš, kako ga rešiš, primer.

Tip 1: Coulombov zakon

\(F = \dfrac{1}{4\pi\varepsilon_0} \dfrac{e_1 e_2}{r^2}\)

Kako prepoznaš: "sila med dvema nabojema".

Postopek:

  1. Zapiši \(e_1\), \(e_2\), \(r\).
  2. Uporabi \(F = k \dfrac{e_1 e_2}{r^2}\), kjer je \(k \approx 9 \cdot 10^9\) N·m²/C².

Primer: \(e_1 = e_2 = 1\) μC, \(r = 0{,}1\) m.

\(F = 9 \cdot 10^9 \cdot \dfrac{(10^{-6})^2}{0{,}01} = 0{,}9\) N.

Tip 2: Električna napetost in jakost polja

\(E = \dfrac{U}{d}\)

Kako prepoznaš: "med ploščama kondenzatorja".

Postopek:

  1. \(E = \dfrac{U}{d}\) (homogeno polje).
  2. \(F = eE\) za naboj v polju.

Primer: \(U = 200\) V, \(d = 0{,}02\) m.

\(E = 10\,000\) V/m.

Tip 3: Ohmov zakon

\(U = RI\)

Kako prepoznaš: "izračunajte tok/napetost/upor".

Postopek:

  1. Prepoznaj neznanko (\(U\), \(R\) ali \(I\)).
  2. Uporabi \(U = RI\).

Primer: \(U = 12\) V, \(R = 4\) Ω.

\(I = \dfrac{U}{R} = 3\) A.

Tip 4: Upor vodnika

\(R = \rho \dfrac{l}{S}\)

Kako prepoznaš: "upor bakrene žice dolžine …".

Postopek:

  1. Zapiši \(\rho\), \(l\), \(S\).
  2. Uporabi \(R = \rho \dfrac{l}{S}\).
  3. Pazi na enote (mm² → m²).

Primer: Cu žica, \(\rho = 1{,}7 \cdot 10^{-8}\) Ω·m, \(l = 10\) m, \(S = 1\) mm² \(= 10^{-6}\) m².

\(R = 1{,}7 \cdot 10^{-8} \cdot \dfrac{10}{10^{-6}} = 0{,}17\) Ω.

Tip 5: Električna moč in delo

\(P = UI\), \(A = Pt\)

Kako prepoznaš: "koliko porabi", "moč porabnika".

Postopek:

  1. \(P = UI = \dfrac{U^2}{R} = I^2 R\).
  2. \(A = Pt\).
  3. Pretvori v kWh, če je potrebno.

Primer: \(U = 230\) V, \(I = 2\) A, \(t = 3\) h.

\(P = 460\) W = 0,46 kW. \(A = 0{,}46 \cdot 3 = 1{,}38\) kWh.

Tip 6: Zaporedna vezava

\(R = R_1 + R_2\), \(I\) enak

Kako prepoznaš: "upori so vezani zaporedno".

Postopek:

  1. Skupni upor: \(R = R_1 + R_2 + \ldots\).
  2. Tok je skozi vse enak: \(I = \dfrac{U}{R}\).
  3. Napetosti: \(U_1 = R_1 I\), \(U_2 = R_2 I\).

Primer: \(R_1 = 2\) Ω, \(R_2 = 4\) Ω, \(U = 12\) V.

\(R = 6\) Ω, \(I = 2\) A. \(U_1 = 4\) V, \(U_2 = 8\) V.

Tip 7: Vzporedna vezava

\(\dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2}\)

Kako prepoznaš: "vzporedno vezana upora".

Postopek:

  1. \(\dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2}\).
  2. Za dva upora: \(R = \dfrac{R_1 R_2}{R_1 + R_2}\).
  3. Napetost je enaka: \(U_1 = U_2 = U\).
  4. Tokova: \(I_1 = \dfrac{U}{R_1}\), \(I_2 = \dfrac{U}{R_2}\).

Primer: \(R_1 = 2\) Ω, \(R_2 = 4\) Ω, \(U = 12\) V.

\(R = \dfrac{8}{6} \approx 1{,}33\) Ω. \(I_1 = 6\) A, \(I_2 = 3\) A, \(I_{\text{skupni}} = 9\) A.

Tip 8: Magnetna sila na vodnik

\(F = BIl\sin\alpha\)

Kako prepoznaš: "vodnik v magnetnem polju".

Postopek:

  1. Zapiši \(B\), \(I\), \(l\), \(\alpha\).
  2. Uporabi \(F = BIl\sin\alpha\).
  3. Če je vodnik pravokoten na polje (\(\alpha = 90°\)), \(F = BIl\).

Primer: \(B = 0{,}5\) T, \(I = 2\) A, \(l = 0{,}3\) m, \(\alpha = 90°\).

\(F = 0{,}5 \cdot 2 \cdot 0{,}3 = 0{,}3\) N.

Tip 9: Lorentzova sila

\(F = evB\sin\alpha\)

Kako prepoznaš: "nabit delec v magnetnem polju".

Postopek:

  1. Zapiši \(e\), \(v\), \(B\), \(\alpha\).
  2. Uporabi \(F = evB\sin\alpha\).
  3. Za kroženje delca: \(F = \dfrac{mv^2}{r}\).

Primer: \(e = 1{,}6 \cdot 10^{-19}\) C, \(v = 10^6\) m/s, \(B = 0{,}1\) T, \(\alpha = 90°\).

\(F = 1{,}6 \cdot 10^{-19} \cdot 10^6 \cdot 0{,}1 = 1{,}6 \cdot 10^{-14}\) N.

Tip 10: Magnetno polje ravnega vodnika in tuljave

\(B = \dfrac{\mu_0 I}{2\pi r}\), \(B = \mu_0 \dfrac{N}{l}I\)

Kako prepoznaš: "magnetno polje na razdalji …", "v tuljavi".

Postopek:

  1. Za ravni vodnik: \(B = \dfrac{\mu_0 I}{2\pi r}\).
  2. Za tuljavo: \(B = \mu_0 \dfrac{N}{l}I\).

Primer: \(I = 5\) A, \(r = 0{,}1\) m.

\(B = \dfrac{4\pi \cdot 10^{-7} \cdot 5}{2\pi \cdot 0{,}1} = 10^{-5}\) T.

Tip 11: Elektromagnetna indukcija

\(U_i = -\dfrac{\Delta \Phi}{\Delta t}\)

Kako prepoznaš: "kolikšna napetost se inducira".

Postopek:

  1. Za tuljavo: \(U_i = -N \dfrac{\Delta \Phi}{\Delta t}\).
  2. Za vodnik, ki se giblje v polju: \(U_i = Blv\).
  3. \(\Phi = BS\cos\alpha\).

Primer: \(B = 0{,}5\) T, \(l = 1\) m, \(v = 2\) m/s.

\(U_i = 0{,}5 \cdot 1 \cdot 2 = 1\) V.

Tip 12: Transformator

\(\dfrac{U_1}{U_2} = \dfrac{N_1}{N_2}\)

Kako prepoznaš: "transformator z … ovoji".

Postopek:

  1. \(\dfrac{U_1}{U_2} = \dfrac{N_1}{N_2}\).
  2. Za idealni transformator: \(P_1 = P_2 \Rightarrow U_1 I_1 = U_2 I_2\).

Primer: \(U_1 = 230\) V, \(N_1 = 1000\), \(N_2 = 100\).

\(U_2 = U_1 \dfrac{N_2}{N_1} = 23\) V.

Tip 13: Energija kondenzatorja

\(W = \dfrac{1}{2}CU^2\)

Kako prepoznaš: "koliko energije shrani kondenzator".

Postopek:

  1. Zapiši \(C\), \(U\).
  2. Uporabi \(W = \dfrac{1}{2}CU^2\).

Primer: \(C = 10\) μF, \(U = 100\) V.

\(W = \dfrac{1}{2} \cdot 10^{-5} \cdot 10^4 = 0{,}05\) J.

Tip 14: Izmenični tok in efektivne vrednosti

\(U_{\text{ef}} = \dfrac{U_0}{\sqrt{2}}\)

Kako prepoznaš: "efektivna vrednost napetosti".

Postopek:

  1. \(U_{\text{ef}} = \dfrac{U_0}{\sqrt{2}} \approx 0{,}707 \cdot U_0\).
  2. Za EU omrežje: \(U_{\text{ef}} = 230\) V, \(U_0 \approx 325\) V.
  3. Moč: \(P = U_{\text{ef}} I_{\text{ef}}\).

Primer: \(U_0 = 325\) V.

\(U_{\text{ef}} = \dfrac{325}{\sqrt{2}} \approx 230\) V.

3. Pogoste napake

  • Pri Coulombovem zakonu pozabiš kvadrirati razdaljo.
  • Pozabiš pretvoriti μC → C, mA → A, μF → F.
  • Pri vezavah zamešaš zaporedno in vzporedno.
  • Pri vzporedni vezavi seštevaš upore namesto obratnih vrednosti.
  • Pri moči zamešaš \(P = UI\) s \(P = I^2R\) (oba sta pravilna, odvisno od podatkov).
  • Pri magnetni sili pozabiš \(\sin\alpha\) (kot med vodnikom in poljem).
  • Pri indukciji pozabiš minus v \(U_i = -\dfrac{\Delta \Phi}{\Delta t}\) (smer).
  • Pri transformatorju zamešaš \(U_1/U_2\) z \(N_1/N_2\).
  • Pri izmeničnem toku uporabiš \(U_0\) namesto \(U_{\text{ef}}\).

4. Študijski vodič — hitri pregled

📋 Kaj moraš znati na pamet

  • Coulomb: \(F = k\dfrac{e_1 e_2}{r^2}\).
  • Polje: \(E = \dfrac{U}{d}\), \(F = eE\).
  • Ohm: \(U = RI\), \(R = \rho \dfrac{l}{S}\).
  • Moč: \(P = UI = \dfrac{U^2}{R} = I^2R\).
  • Zaporedno: \(R = R_1 + R_2\), vzporedno: \(1/R = 1/R_1 + 1/R_2\).
  • Magnetna sila: \(F = BIl\sin\alpha\), \(F = evB\sin\alpha\).
  • Polje vodnika: \(B = \dfrac{\mu_0 I}{2\pi r}\), tuljava: \(B = \mu_0 \dfrac{N}{l}I\).
  • Indukcija: \(U_i = -\dfrac{\Delta \Phi}{\Delta t}\), \(U_i = Blv\).
  • Transformator: \(\dfrac{U_1}{U_2} = \dfrac{N_1}{N_2}\).
  • Efektivna: \(U_{\text{ef}} = \dfrac{U_0}{\sqrt{2}}\).

🎯 Kako pristopiti k nalogi

  1. Preberi nalogo in prepoznaj tip: elektrostatika, tok, magnetizem, indukcija?
  2. Za elektrostatiko: Coulomb, polje, napetost.
  3. Za tok: Ohm, moč, vezave.
  4. Za magnetizem: sila na vodnik/naboj, polje.
  5. Za indukcijo: Faraday, \(Blv\), transformator.
  6. Za izmenični tok: \(U_{\text{ef}} = U_0/\sqrt{2}\).

⏱️ Časovni načrt za en večer

  • 30 min: Teorija — elektrostatika, tok, magnetizem, indukcija.
  • 60 min: Tipi 1–7 (Coulomb, polje, Ohm, upor, moč, vezave).
  • 60 min: Tipi 8–14 (magnetna sila, Lorentz, polje, indukcija, transformator, kondenzator, izmenični).
  • 30 min: Ponovi pogoste napake in študijski vodič.
  • 30 min: Reši 2–3 izpitne pole za vajo.
