Samostalnik, člen, pridevnik in zaimki

Cela razlaga

1Samostalnik in člen

el / la / los / las, un / una
členi
el libro, la casa
-o moški, -a ženski (izjeme)
spol
el día, la mano, el problema
-s / -es
množina
la ciudad → las ciudades

2Pridevnik in stopnjevanje

ujema se s samostalnikom
spol, število
los chicos simpáticos
más / menos … que, tan … como
primerjava
Es más alto que yo.
mejor, peor, mayor, menor
nepravilni
Es el mejor.
-ísimo
absolutni presežnik
guapísimo

3Osebni zaimki in gustar

me, te, lo/la, nos, os, los/las
tožilnik
Lo veo.
me, te, le, nos, os, les
dajalnik
Le doy el libro.
le + lo → se lo
sestavljeni
Se lo doy.
gustar
me gusta + ed. / me gustan + mn.
Me gustan los perros.

4Drugi zaimki in števniki

este, ese, aquel
kazalni (blizu, srednje, daleč)
este libro
mi, tu, su / mío, tuyo
svojilni
Es mío.
algo, nada, alguien, nadie
nedoločni
No hay nadie.

!Pazi

  • Pri »gustar« se glagol ujema s tem, kar je všeč.
