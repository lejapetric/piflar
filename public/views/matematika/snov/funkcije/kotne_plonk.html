Kotne funkcije

Cela razlaga

1Pravokotni trikotnik

\(\sin\alpha = \frac{a}{c},\ \cos\alpha = \frac{b}{c},\ \tan\alpha = \frac{a}{b}\)
nasprotna, priležna, hipotenuza
\(3, 4, 5\): \(\sin\alpha = 0{,}6\)
\(30^\circ: \frac12, \frac{\sqrt3}{2}\); \(45^\circ: \frac{\sqrt2}{2}\)
\(\sin, \cos\) znanih kotov
\(\sin 60^\circ = \frac{\sqrt3}{2}\)

2Zveze

\(\sin^2 x + \cos^2 x = 1\)
osnovna zveza
\(\sin x = 0{,}6\): \(\cos x = \pm 0{,}8\)
\(\tan x = \frac{\sin x}{\cos x}\)
\(1 + \tan^2 x = \frac{1}{\cos^2 x}\)
\(\tan x = 1\): \(\cos^2 x = \frac12\)
\(\sin(\pi - x) = \sin x,\ \cos(-x) = \cos x\)
prehod v I. kvadrant
\(\sin 150^\circ = \frac12\)

3Adicijski izreki

\(\sin(x \pm y) = \sin x \cos y \pm \cos x \sin y\)
sinus vsote
\(\sin 75^\circ = \frac{\sqrt6 + \sqrt2}{4}\)
\(\cos(x \pm y) = \cos x \cos y \mp \sin x \sin y\)
kosinus vsote
\(\cos 15^\circ = \frac{\sqrt6 + \sqrt2}{4}\)
\(\sin 2x = 2\sin x\cos x,\ \cos 2x = \cos^2 x - \sin^2 x\)
dvojni kot
\(\sin x = \frac35\) (I. kv.): \(\sin 2x = \frac{24}{25}\)

4Grafi

\(f(x) = a\sin(bx + c) + d\)
amplituda \(|a|\), perioda \(\frac{2\pi}{b}\)
\(2\sin 3x\): perioda \(\frac{2\pi}{3}\)
\(\tan x\): perioda \(\pi\)
poli v \(\frac{\pi}{2} + k\pi\)
\(\tan\frac{\pi}{4} = 1\)
\(180^\circ = \pi\)
stopinje v radiane
\(60^\circ = \frac{\pi}{3}\)

5Enačbe

\(\sin x = a\): \(x = x_0 + 2k\pi,\ \pi - x_0 + 2k\pi\)
dve družini rešitev
\(\sin x = \frac12\): \(\frac{\pi}{6}, \frac{5\pi}{6}\)
\(\cos x = a\): \(x = \pm x_0 + 2k\pi\)
simetrično
\(\cos x = 0\): \(\frac{\pi}{2} + k\pi\)
\(\tan x = a\): \(x = x_0 + k\pi\)
ena družina
\(\tan x = 1\): \(\frac{\pi}{4} + k\pi\)

!Pazi

  • Ne pozabi \(+ 2k\pi\) (pri tangensu \(+ k\pi\)).
  • Kalkulator v pravem načinu (DEG / RAD).
