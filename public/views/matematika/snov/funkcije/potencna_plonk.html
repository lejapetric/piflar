Potenčna funkcija

Cela razlaga

1Naravni eksponent

\(f(x) = x^n\)
\(n\) sod: soda, \(Z_f = [0, \infty)\)
\(x^4\): \(f(-2) = 16\)
\(n\) lih
liha funkcija, \(Z_f = \mathbb{R}\)
\(x^3\): \(f(-2) = -8\)
vse gredo skozi \((1, 1)\)
sode tudi skozi \((-1, 1)\)
lihe skozi \((-1, -1)\)

2Negativni eksponent

\(f(x) = x^{-n} = \frac{1}{x^n}\)
\(D_f = \mathbb{R} \setminus \{0\}\), pol v 0
\(x^{-1}\): hiperbola
asimptoti \(x = 0\), \(y = 0\)
obe osi
\(x^{-2}\) je soda, vedno pozitivna

3Modeliranje

\(y = k x^n\)
premo sorazmerje s potenco
ploščina kvadrata \(S = a^2\)
\(y = \frac{k}{x}\)
obratno sorazmerje
\(v = \frac{s}{t}\) pri stalni poti

!Pazi

  • Pri \(x^{-n}\) je \(x = 0\) izključen.
