Logaritemska funkcija

Cela razlaga

1Logaritem

\(\log_a b = x \iff a^x = b\)
\(a > 0, a \ne 1, b > 0\)
\(\log_2 8 = 3\)
\(\log_a (xy) = \log_a x + \log_a y\)
produkt
\(\log 2 + \log 5 = 1\)
\(\log_a \frac{x}{y} = \log_a x - \log_a y\)
kvocient
\(\log_3 18 - \log_3 2 = 2\)
\(\log_a x^n = n \log_a x\)
potenca
\(\log_2 \sqrt{2} = \frac12\)
\(\log_a b = \frac{\log_c b}{\log_c a}\)
prehod na novo osnovo
\(\log_4 8 = \frac{3}{2}\)
\(\log x = \log_{10} x,\ \ln x = \log_e x\)
desetiški, naravni
\(\ln e^2 = 2\)

2Funkcija

\(f(x) = \log_a x\)
\(D_f = (0, \infty)\), skozi \((1, 0)\)
\(\log_a(x - 2)\): \(x > 2\)
inverz \(a^x\)
navpična asimptota \(x = 0\)
\(a > 1\) narašča

3Enačbe

\(\log_a f(x) = \log_a g(x) \Rightarrow f = g\)
in preveri \(f, g > 0\)
\(\log(x + 1) = \log(2x - 3)\): \(x = 4\)
\(\log_a f(x) = c \Rightarrow f(x) = a^c\)
po definiciji
\(\log_2(x - 1) = 3\): \(x = 9\)

!Pazi

  • \(\log(x + y) \ne \log x + \log y\).
  • Na koncu preveri, da so argumenti pozitivni.
