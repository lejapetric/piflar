Eksponentna funkcija

Cela razlaga

1Funkcija

\(f(x) = a^x,\ a > 0,\ a \ne 1\)
\(D_f = \mathbb{R},\ Z_f = (0, \infty)\)
\(2^3 = 8\)
\(a > 1\) narašča, \(0 < a < 1\) pada
graf gre skozi \((0, 1)\)
\(\left(\frac12\right)^x\) pada
\(y = 0\)
vodoravna asimptota
\(2^x + 3\): asimptota \(y = 3\)

2Enačbe

\(a^x = a^y \Rightarrow x = y\)
enaki osnovi
\(2^{x+1} = 8\): \(x = 2\)
\(a^x = b \Rightarrow x = \log_a b\)
različni osnovi
\(3^x = 5\): \(x = \frac{\ln 5}{\ln 3} \approx 1{,}46\)
uvedba nove neznanke
\(t = a^x > 0\)
\(4^x - 3 \cdot 2^x + 2 = 0\): \(t^2 - 3t + 2\), \(x = 0, 1\)

3Rast in razpad

\(N(t) = N_0 a^{\frac{t}{\tau}}\)
rast / razpad v času
podvajanje vsake 3 h: \(N = N_0 2^{\frac{t}{3}}\)
\(N = N_0 \left(\frac12\right)^{\frac{t}{t_{1/2}}}\)
razpolovni čas
po \(2 t_{1/2}\) ostane \(\frac14\)

!Pazi

  • \(a^x\) je vedno pozitivno: \(t = a^x\) ne sme biti negativen.
