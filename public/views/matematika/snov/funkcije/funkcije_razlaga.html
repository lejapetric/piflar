📈 6. Funkcije

Linearne, kvadratne, kotne, eksponentne in logaritemske funkcije

📖 Splošne lastnosti funkcij

  • Definicijsko območje (D_f) - množica dovoljenih vrednosti x
  • Zaloga vrednosti (Z_f) - množica vrednosti, ki jih funkcija zavzame
  • Ničle: f(x) = 0
  • Presečišče z osjo y: f(0)
  • Soda funkcija: f(-x) = f(x) (simetrična glede na os y)
  • Liha funkcija: f(-x) = -f(x) (simetrična glede na izhodišče)

📈 Linearna funkcija

f(x) = kx + n
  • k = smerni koeficient (naklon)
  • n = začetna vrednost (presečišče z osjo y)
  • Vzporedni premici: k₁ = k₂
  • Pravokotni premici: k₁ · k₂ = -1

📈 Kvadratna funkcija

f(x) = ax² + bx + c (a ≠ 0)
Temenska oblika:
f(x) = a(x - p)² + q, T(p, q)
p = -b/(2a), q = c - b²/(4a)
Ničli:
x₁,₂ = (-b ± √D)/(2a), D = b² - 4ac

📐 Kotne funkcije

Osnovne zveze
sin²x + cos²x = 1
tan x = sin x / cos x
Adicijski formuli
sin(x+y) = sin x cos y + cos x sin y
cos(x+y) = cos x cos y - sin x sin y
Dvojni kot
sin 2x = 2 sin x cos x
cos 2x = cos²x - sin²x

📈 Eksponentna in logaritemska funkcija

Eksponentna
f(x) = aˣ (a > 0, a ≠ 1)

a > 1: narašča, 0 < a < 1: pada

Logaritemska
f(x) = logₐ x (a > 0, a ≠ 1, x > 0)
Lastnosti logaritmov:
logₐ(x·y) = logₐ x + logₐ y
logₐ(x/y) = logₐ x - logₐ y
logₐ(xⁿ) = n · logₐ x
