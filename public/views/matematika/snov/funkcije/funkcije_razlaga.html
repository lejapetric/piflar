Funkcije

Vse o funkcijah za maturo: linearna, kvadratna, potenčna, korenska, eksponentna, logaritemska, polinomska, racionalna in kotne funkcije. Definicijsko območje, zaloga vrednosti, ničle, poli, asimptote, inverzna funkcija in transformacije grafov.

📋 Formule na maturi — osnovna raven

Na maturitetnem listu s formulami so za funkcije relevantne naslednje formule:

  • Logaritem: \(\log_a(xy) = \log_a x + \log_a y\), \(\log_a x^n = n \log_a x\)
  • Prehod na novo osnovo: \(\log_a x = \dfrac{\log_b x}{\log_b a}\)
  • Adicijski izreki: \(\sin(x \pm y) = \sin x \cos y \pm \cos x \sin y\), \(\cos(x \pm y) = \cos x \cos y \mp \sin x \sin y\)
  • Kotne funkcije polovičnih kotov: \(\sin^2 \dfrac{x}{2} = \dfrac{1-\cos x}{2}\), \(\cos^2 \dfrac{x}{2} = \dfrac{1+\cos x}{2}\)
  • Faktorizacija: \(\sin x \pm \sin y = 2\sin\dfrac{x\pm y}{2}\cos\dfrac{x\mp y}{2}\)

1. Teorija — pojmi in osnovne funkcije

Kar moraš znati na pamet, preden se lotiš nalog.

Osnovni pojmi

Funkcija

\(f: A \to B\)

Preslikava, ki vsakemu \(x \in A\) priredi natanko en \(y \in B\).

Definicijsko območje \(D_f\)

\(D_f\)

Množica vseh \(x\), za katere je \(f(x)\) definirana.

Zaloga vrednosti \(Z_f\)

\(Z_f\)

Množica vseh možnih \(f(x)\).

Ničla

\(f(x_0) = 0\)

Presečišče z osjo \(x\).

Začetna vrednost

\(f(0)\)

Presečišče z osjo \(y\).

Pol

\(f(x_0)\) ni definirana

Navadno pri racionalnih funkcijah (imenovalec \(= 0\)).

Soda / liha funkcija

\(f(-x) = f(x)\) / \(f(-x) = -f(x)\)

Soda: simetrična glede na os \(y\). Liha: glede na izhodišče.

Inverzna funkcija

\(f^{-1}(x)\)

Zamenjamo \(x\) in \(y\), nato izrazimo \(y\).

Linearna funkcija

Predpis

\(f(x) = kx + n\)

\(k\) = smerni koeficient (naklon), \(n\) = začetna vrednost.

Ničla

\(x = -\dfrac{n}{k}\)

Za \(k \neq 0\).

Vzporedni premici

\(k_1 = k_2\)

Pravokotni premici

\(k_1 \cdot k_2 = -1\)

Kvadratna funkcija

Predpis

\(f(x) = ax^2 + bx + c\)

Teme

\(T\left(-\dfrac{b}{2a}, c - \dfrac{b^2}{4a}\right)\)

\(a > 0\): minimum, \(a < 0\): maksimum.

Ničle

\(x_{1,2} = \dfrac{-b \pm \sqrt{D}}{2a}\), \(D = b^2 - 4ac\)

Oblika temena

\(f(x) = a(x-p)^2 + q\), \(T(p,q)\)

Eksponentna in logaritemska funkcija

Eksponentna: predpis

\(f(x) = a^x\), \(a > 0, a \neq 1\)

Eksponentna: lastnosti

\(D_f = \mathbb{R}\), \(Z_f = (0, \infty)\)

Asimptota \(y = 0\); gre skozi \((0, 1)\).

Logaritemska: predpis

\(f(x) = \log_a x\), \(a > 0, a \neq 1\)

Logaritemska: lastnosti

\(D_f = (0, \infty)\), \(Z_f = \mathbb{R}\)

Asimptota \(x = 0\); gre skozi \((1, 0)\).

Potenčna, korenska in racionalna funkcija

Potenčna funkcija

\(f(x) = x^n\)

\(n\) naravno število, negativno celo število ali ulomek.

Korenska funkcija

\(f(x) = \sqrt[n]{x}\)

Inverz potenčne funkcije.

Racionalna funkcija

\(f(x) = \dfrac{p(x)}{q(x)}\)

Poli: \(q(x) = 0\). Ničle: \(p(x) = 0\) in \(q(x) \neq 0\).

Asimptote

navpična: pri polu, vodoravna: limita

Vodoravna asimptota: \(\lim_{x\to\pm\infty} f(x)\).

2. Tipi nalog — postopki po korakih

Za vsak tip: kako ga prepoznaš, kako ga rešiš, primer.

Tip 1: Definicijsko območje funkcije

\(D_f\)

Kako prepoznaš: "zapišite definicijsko območje", "za katere \(x\) je definirana".

Postopek:

  1. Poišči omejitve:
    • ulomek: imenovalec \(\neq 0\)
    • koren sode stopnje: argument \(\geq 0\)
    • logaritem: argument \(> 0\)
    • tangens: argument \(\neq \dfrac{\pi}{2} + k\pi\)
  2. Reši omejitve.
  3. Zapiši \(D_f\) kot interval ali unijo intervalov.

Primer: \(f(x) = \log_2(x^2 + x - 6)\)

Pogoj: \(x^2 + x - 6 > 0\). Ničli: \(x_1 = 2, x_2 = -3\). \(D_f = (-\infty, -3) \cup (2, \infty)\).

Tip 2: Ničle funkcije

\(f(x) = 0\)

Kako prepoznaš: "izračunajte ničle".

Postopek:

  1. Nastavi \(f(x) = 0\).
  2. Reši enačbo (linearna, kvadratna, eksponentna, logaritemska ...).
  3. Preveri, ali so rešitve v \(D_f\).
  4. Zapiši ničle kot točke \((x_0, 0)\).

Primer: \(f(x) = 2\sin x - 1\)

\(\sin x = \dfrac{1}{2}\). \(x = \dfrac{\pi}{6} + 2k\pi\) ali \(x = \dfrac{5\pi}{6} + 2k\pi\).

Tip 3: Teme kvadratne funkcije

\(T\left(-\dfrac{b}{2a}, c - \dfrac{b^2}{4a}\right)\)

Kako prepoznaš: "zapišite teme", "največja/najmanjša vrednost".

Postopek:

  1. Zapiši v obliki \(f(x) = ax^2 + bx + c\).
  2. Izračunaj \(x_T = -\dfrac{b}{2a}\).
  3. Izračunaj \(y_T = f(x_T) = c - \dfrac{b^2}{4a}\).

Primer: \(f(x) = -2x^2 - 8x + 2\)

\(x_T = -\dfrac{-8}{2 \cdot (-2)} = -2\). \(y_T = -2(4) - 8(-2) + 2 = 10\). Teme: \(T(-2, 10)\).

Tip 4: Asimptote racionalne funkcije

navpična: \(q(x)=0\), vodoravna: \(\lim f\)

Kako prepoznaš: "zapišite asimptote", "poli funkcije".

Postopek:

  1. Navpična: reši \(q(x) = 0\) (imenovalec).
  2. Vodoravna:
    • stopnja števca < stopnja imenovalca: \(y = 0\)
    • stopnji enaki: \(y = \dfrac{a_n}{b_n}\) (razmerje vodilnih koef.)
    • stopnja števca > stopnja imenovalca: ni vodoravne

Primer: \(f(x) = \dfrac{2x-1}{3x+4}\)

Navpična: \(3x + 4 = 0 \Rightarrow x = -\dfrac{4}{3}\). Vodoravna: \(y = \dfrac{2}{3}\).

Tip 5: Zaloga vrednosti funkcije

\(Z_f\)

Kako prepoznaš: "zapišite \(Z_f\)".

Postopek:

  1. Določi tip funkcije.
  2. Uporabi znano \(Z_f\):
    • kvadratna \(a > 0\): \([y_T, \infty)\)
    • kvadratna \(a < 0\): \((-\infty, y_T]\)
    • eksponentna: \((0, \infty)\)
    • logaritemska: \(\mathbb{R}\)
    • sin, cos: \([-1, 1]\)

Primer: \(f(x) = x^2 + 3\) → \(Z_f = [3, \infty)\).

Tip 6: Inverzna funkcija

\(f^{-1}(x)\)

Kako prepoznaš: "poiščite inverzno funkcijo".

Postopek:

  1. Zapiši \(y = f(x)\).
  2. Zamenjaj \(x\) in \(y\): \(x = f(y)\).
  3. Izrazi \(y\) iz enačbe.
  4. Zapiši \(f^{-1}(x)\).

Primer: \(f(x) = \dfrac{2-x}{x+2}\)

\(x = \dfrac{2-y}{y+2}\). \(x(y+2) = 2-y \Rightarrow y = \dfrac{2-2x}{x+1}\). \(f^{-1}(x) = \dfrac{2-2x}{x+1}\).

Tip 7: Presečišča grafov

\(f(x) = g(x)\)

Kako prepoznaš: "izračunajte presečišče grafov \(f\) in \(g\)".

Postopek:

  1. Nastavi \(f(x) = g(x)\).
  2. Reši enačbo.
  3. Izračunaj \(y\) za vsak \(x\).
  4. Zapiši točke \((x, y)\).

Primer: \(f(x) = 2^x\), \(g(x) = 65 \cdot 2^x - 1\)

\(1 = 64 \cdot 2^x \Rightarrow 2^x = 2^{-6} \Rightarrow x = -6\). \(y = 2^{-6} = \dfrac{1}{64}\).

Tip 8: Soda / liha funkcija

\(f(-x) = f(x)\) / \(f(-x) = -f(x)\)

Kako prepoznaš: "ali je funkcija soda/liha".

Postopek:

  1. Izračunaj \(f(-x)\).
  2. Primerjaj s \(f(x)\) in \(-f(x)\).

Primer: \(f(x) = x^3 - x\)

\(f(-x) = -x^3 + x = -(x^3 - x) = -f(x)\). → liha.

Tip 9: Transformacije grafov

\(f(x-c)\), \(f(x)+c\), \(-f(x)\), \(a f(x)\)

Kako prepoznaš: "narišite graf \(g(x) = f(x-2)+1\)".

Postopek:

  1. Začni z osnovnim grafom \(f(x)\).
  2. Uporabi transformacije:
    • \(f(x)+c\) → premik navzgor za \(c\)
    • \(f(x-c)\) → premik desno za \(c\)
    • \(-f(x)\) → zrcaljenje čez os \(x\)
    • \(f(-x)\) → zrcaljenje čez os \(y\)
    • \(a f(x)\) → razteg v smeri \(y\)

Primer: \(g(x) = -f(x)\) → zrcaljenje čez os \(x\).

Tip 10: Obravnava funkcije brez odvoda

\(D_f, f(0), f(x)=0, q(x)=0, \lim\)

Kako prepoznaš: "narišite graf", "zapišite ničle, pole, asimptote".

Postopek:

  1. Določi \(D_f\).
  2. Ničle: \(f(x) = 0\).
  3. Poli: \(q(x) = 0\).
  4. Začetna vrednost \(f(0)\).
  5. Asimptote.
  6. Nariši graf (obnašanje pri polih, v neskončnosti).

Primer: \(f(x) = \dfrac{x-2}{x}\)

\(D_f = \mathbb{R}\setminus\{0\}\), ničla \(x = 2\), pol \(x = 0\), vodoravna \(y = 1\).

Tip 11: Eksponentna in logaritemska funkcija — iskanje parametra

Vstavi koordinate točke

Kako prepoznaš: "določite \(a\) tako, da gre graf skozi točko".

Postopek:

  1. Vstavi koordinate točke v enačbo \(y = f(x)\).
  2. Reši enačbo za parameter.

Primer: \(f(x) = \log_a x\) poteka skozi \(A\left(\dfrac{1}{8}, -\dfrac{3}{2}\right)\)

\(a^{-3/2} = \dfrac{1}{8} = 2^{-3} \Rightarrow a^{1/2} = 2 \Rightarrow a = 4\).

Tip 12: Limita funkcije

\(\lim_{x \to a} f(x)\)

Kako prepoznaš: "izračunajte limito".

Postopek:

  1. Poskusi vstaviti \(a\).
  2. Če dobiš \(0/0\): razstavi, racionaliziraj ali L'Hôpital.
  3. Če \(x \to \infty\): deli z najvišjo potenco.
  4. Znane limite: \(\lim_{x\to 0} \dfrac{\sin x}{x} = 1\), \(\lim_{x\to\infty}(1+\tfrac{1}{x})^x = e\).

Primer: \(\lim_{x \to 7} \dfrac{x^2-49}{x^2-2x-35} = \dfrac{14}{12} = \dfrac{7}{6}\).

Tip 13: Kotne funkcije — ničle in presečišča

\(\sin x = 0 \Rightarrow x = k\pi\), \(\cos x = 0 \Rightarrow x = \dfrac{\pi}{2} + k\pi\)

Kako prepoznaš: "izračunajte ničle funkcije \(2\sin x - 1\)".

Postopek:

  1. Nastavi \(f(x) = 0\).
  2. Reši trigonometrijsko enačbo (uporabi znane vrednosti in periodo).
  3. Zapiši splošno rešitev \(x = \ldots + 2k\pi\) ali \(+ k\pi\).

Primer: \(2\sin x - 1 = 0\)

\(\sin x = \dfrac{1}{2} \Rightarrow x = \dfrac{\pi}{6} + 2k\pi \lor x = \dfrac{5\pi}{6} + 2k\pi\).

Tip 14: Risanje grafa kvadratne funkcije

Teme + ničle + začetna vrednost

Kako prepoznaš: "narišite graf \(f(x) = ax^2 + bx + c\)".

Postopek:

  1. Izračunaj teme \(T(x_T, y_T)\).
  2. Izračunaj ničle (če obstajajo).
  3. Izračunaj začetno vrednost \(f(0) = c\).
  4. Nariši parabolo skozi te točke.
  5. Preveri, ali je \(a > 0\) (odprta navzgor) ali \(a < 0\) (navzdol).

Primer: \(f(x) = x^2 - 2x - 3\)

Teme: \(T(1, -4)\). Ničle: \(x = 3, -1\). Začetna: \(f(0) = -3\).

3. Pogoste napake

  • Pozabiš preveriti, ali so ničle v \(D_f\).
  • Pri racionalni funkciji zamenjaš ničle in pole.
  • Pri vodoravni asimptoti pozabiš primerjati stopnji števca in imenovalca.
  • Pri inverzni funkciji pozabiš zamenjati \(x\) in \(y\).
  • Pri transformacijah zamenjaš \(f(x-2)\) (premik desno) s \(f(x+2)\) (premik levo).
  • Pri limiti \(0/0\) pozabiš razstaviti ali racionalizirati.
  • Pri eksponentni/logaritemski funkciji zamenjaš \(D_f\) in \(Z_f\).
  • Pri trigonometričnih enačbah pozabiš na periodo (\(+ 2k\pi\) ali \(+ k\pi\)).

4. Študijski vodič — hitri pregled

📋 Kaj moraš znati na pamet

  • Linearna: \(f(x) = kx+n\), ničla \(x = -\dfrac{n}{k}\).
  • Kvadratna: \(f(x) = ax^2+bx+c\), teme \(T\left(-\dfrac{b}{2a}, c - \dfrac{b^2}{4a}\right)\).
  • Eksponentna: \(a^x\), \(D_f = \mathbb{R}\), \(Z_f = (0, \infty)\), asimptota \(y = 0\).
  • Logaritemska: \(\log_a x\), \(D_f = (0, \infty)\), \(Z_f = \mathbb{R}\), asimptota \(x = 0\).
  • Racionalna: poli = ničle imenovalca, asimptote pri polih.
  • Inverzna: zamenjaj \(x\) in \(y\).
  • Kotne: \(D_f\) in \(Z_f\), perioda.
  • Limite: \(\lim_{x\to 0}\dfrac{\sin x}{x} = 1\), \(\lim_{x\to\infty}(1+\tfrac{1}{x})^x = e\).

🎯 Kako pristopiti k nalogi

  1. Preberi nalogo in prepoznaj tip: \(D_f\), ničle, teme, asimptote, \(Z_f\), inverz, presečišča, transformacije, limita?
  2. Za \(D_f\): preveri omejitve (ulomek, koren, logaritem).
  3. Za ničle: reši \(f(x) = 0\).
  4. Za teme: uporabi \(x_T = -\dfrac{b}{2a}\).
  5. Za asimptote: poli + limita.
  6. Za \(Z_f\): tip funkcije.
  7. Za limite: vstavi, nato razstavi/racionaliziraj/L'Hôpital.
  8. Za graf: teme, ničle, začetna vrednost, asimptote.

⏱️ Časovni načrt za en večer

  • 30 min: Teorija — linearna, kvadratna, eksponentna, logaritemska, racionalna, kotne.
  • 70 min: Tipi 1–7 (D_f, ničle, teme, asimptote, Z_f, inverz, presečišča).
  • 55 min: Tipi 8–14 (soda/liha, transformacije, obravnava, parametri, limite, kotne, graf).
  • 30 min: Ponovi pogoste napake in študijski vodič.
  • 30 min: Reši 2–3 izpitne pole za vajo.
