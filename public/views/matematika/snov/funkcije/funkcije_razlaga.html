Funkcije

Vse o funkcijah za maturo: linearna, kvadratna, eksponentna, logaritemska, racionalna in trigonometrična. Definicijsko območje, zaloga vrednosti, ničle, poli, asimptote, ekstremi.

1. Teorija — formule in pravila

Kar moraš znati na pamet, preden se lotiš nalog.

Osnovni pojmi

  • Definicijsko območje \(D_f\): vse vrednosti \(x\), za katere je \(f(x)\) definirana.
  • Zaloga vrednosti \(Z_f\): vse vrednosti \(f(x)\), ko \(x\) preteče \(D_f\).
  • Ničla: \(x_0\), kjer \(f(x_0) = 0\) (presečišče z osjo \(x\)).
  • Začetna vrednost: \(f(0)\) (presečišče z osjo \(y\)).
  • Pol: \(x_0\), kjer \(f\) ni definirana (imenovalec = 0).
  • Asimptota: premica, ki se ji graf približuje, a je ne doseže.
  • Soda funkcija: \(f(-x) = f(x)\) (simetrična glede na os \(y\)).
  • Liha funkcija: \(f(-x) = -f(x)\) (simetrična glede na izhodišče).

Linearna funkcija \(f(x) = kx + n\)

  • Smerni koeficient: \(k\) (naklon premice)
  • Začetna vrednost: \(n\) (presečišče z osjo \(y\))
  • Ničla: \(x = -\dfrac{n}{k}\) (za \(k \neq 0\))
  • \(k > 0\) → naraščajoča; \(k < 0\) → padajoča; \(k = 0\) → konstantna
  • Vzporedni premici: enak \(k\)
  • Pravokotni premici: \(k_1 \cdot k_2 = -1\)

Kvadratna funkcija \(f(x) = ax^2 + bx + c\)

  • Teme: \(T\left(-\dfrac{b}{2a}, c - \dfrac{b^2}{4a}\right)\)
  • Ničle: \(x_{1,2} = \dfrac{-b \pm \sqrt{D}}{2a}\), \(D = b^2 - 4ac\)
  • \(a > 0\) → odprta navzgor (minimum v temenu)
  • \(a < 0\) → odprta navzdol (maksimum v temenu)
  • Presečišče z osjo y: \((0, c)\)
  • Oblika temena: \(f(x) = a(x - p)^2 + q\), kjer je \(T(p, q)\)

Eksponentna funkcija \(f(x) = a^x\)

  • \(D_f = \mathbb{R}\), \(Z_f = (0, \infty)\)
  • \(a > 1\) → naraščajoča; \(0 < a < 1\) → padajoča
  • Vodoravna asimptota: \(y = 0\)
  • Vedno gre skozi \((0, 1)\)

Logaritemska funkcija \(f(x) = \log_a x\)

  • \(D_f = (0, \infty)\), \(Z_f = \mathbb{R}\)
  • \(a > 1\) → naraščajoča; \(0 < a < 1\) → padajoča
  • Navpična asimptota: \(x = 0\)
  • Vedno gre skozi \((1, 0)\)
  • Ničla: \(x = 1\)

Racionalna funkcija \(f(x) = \dfrac{p(x)}{q(x)}\)

  • Definicijsko območje: \(q(x) \neq 0\)
  • Ničle: \(p(x) = 0\) (in \(q(x) \neq 0\))
  • Poli: \(q(x) = 0\)
  • Navpična asimptota: pri polu
  • Vodoravna asimptota: \(\lim_{x \to \pm\infty} f(x)\)

Trigonometrične funkcije

  • \(\sin x\): \(D_f = \mathbb{R}\), \(Z_f = [-1, 1]\), perioda \(2\pi\)
  • \(\cos x\): \(D_f = \mathbb{R}\), \(Z_f = [-1, 1]\), perioda \(2\pi\)
  • \(\tan x\): \(D_f = \mathbb{R} \setminus \{\frac{\pi}{2} + k\pi\}\), \(Z_f = \mathbb{R}\), perioda \(\pi\)
  • \(\sin x = 0 \Rightarrow x = k\pi\); \(\cos x = 0 \Rightarrow x = \dfrac{\pi}{2} + k\pi\)

2. Tipi nalog — postopki po korakih

Za vsak tip: kako ga prepoznaš, kako ga rešiš, primer.

Tip 1: Definicijsko območje funkcije

Kako prepoznaš: "Zapišite definicijsko območje", "za katere \(x\) je funkcija definirana".

Postopek:

  1. Poišči omejitve:
    • Ulomek: imenovalec \(\neq 0\)
    • Koren sode stopnje: argument \(\geq 0\)
    • Logaritem: argument \(> 0\)
    • Tangens: argument \(\neq \dfrac{\pi}{2} + k\pi\)
  2. Reši omejitve.
  3. Zapiši \(D_f\) kot interval ali unijo intervalov.
$$\text{Primer: } f(x) = \log_2(x^2 + x - 6)$$

1. Pogoj: \(x^2 + x - 6 > 0\). 2. Ničli: \(x_1 = 2, x_2 = -3\). 3. Kvadratna funkcija je pozitivna zunaj intervala med ničlama. 4. \(D_f = (-\infty, -3) \cup (2, \infty)\).

$$\text{Primer: } f(x) = \sqrt{x - 1}$$

1. Pogoj: \(x - 1 \geq 0\). 2. \(x \geq 1\). 3. \(D_f = [1, \infty)\).

Tip 2: Ničle funkcije

Kako prepoznaš: "Izračunajte ničle", "kje graf seka os \(x\)".

Postopek:

  1. Nastavi \(f(x) = 0\).
  2. Reši enačbo (linearna, kvadratna, eksponentna, logaritemska ...).
  3. Preveri, ali so rešitve v \(D_f\).
  4. Zapiši ničle kot točke \((x_0, 0)\).
$$\text{Primer: } f(x) = 2\sin x - 1$$

1. \(2\sin x - 1 = 0 \Rightarrow \sin x = \dfrac{1}{2}\). 2. \(x = \dfrac{\pi}{6} + 2k\pi\) ali \(x = \dfrac{5\pi}{6} + 2k\pi\), \(k \in \mathbb{Z}\).

$$\text{Primer: } f(x) = \log_3(x+1) - 1$$

1. \(\log_3(x+1) = 1 \Rightarrow x + 1 = 3 \Rightarrow x = 2\). 2. Preveri: \(x = 2 > -1\). ✓ 3. Ničla: \((2, 0)\).

Tip 3: Teme kvadratne funkcije

Kako prepoznaš: "Zapišite teme", "največja/najmanjša vrednost".

Postopek:

  1. Zapiši v obliki \(f(x) = ax^2 + bx + c\).
  2. Izračunaj \(x_T = -\dfrac{b}{2a}\).
  3. Izračunaj \(y_T = f(x_T) = c - \dfrac{b^2}{4a}\).
  4. Teme: \(T(x_T, y_T)\).
  5. Če \(a > 0\), je v temenu minimum; če \(a < 0\), maksimum.
$$\text{Primer: } f(x) = -2x^2 - 8x + 2$$

1. \(x_T = -\dfrac{-8}{2 \cdot (-2)} = -2\). 2. \(y_T = -2(4) - 8(-2) + 2 = -8 + 16 + 2 = 10\). 3. Teme: \(T(-2, 10)\). 4. \(a < 0\) → maksimum.

Tip 4: Asimptote racionalne funkcije

Kako prepoznaš: "Zapišite asimptote", "poli funkcije".

Postopek:

  1. Navpična asimptota: reši \(q(x) = 0\) (imenovalec = 0).
  2. Vodoravna asimptota:
    • Če je stopnja števca \(<\) stopnja imenovalca: \(y = 0\)
    • Če sta stopnji enaki: \(y = \dfrac{a_n}{b_n}\) (razmerje vodilnih koeficientov)
    • Če je stopnja števca \(>\) stopnja imenovalca: ni vodoravne (je poševna)
  3. Zapiši enačbe asimptot.
$$\text{Primer: } f(x) = \frac{2x - 1}{3x + 4}$$

1. Navpična: \(3x + 4 = 0 \Rightarrow x = -\dfrac{4}{3}\). 2. Vodoravna: enaki stopnji → \(y = \dfrac{2}{3}\). 3. Ničla: \(2x - 1 = 0 \Rightarrow x = \dfrac{1}{2}\).

Tip 5: Zaloga vrednosti funkcije

Kako prepoznaš: "Zapišite zalogo vrednosti \(Z_f\)".

Postopek:

  1. Določi tip funkcije (linearna, kvadratna, eksponentna, ...).
  2. Uporabi znano zalogo:
    • Kvadratna \(a > 0\): \(Z_f = [y_T, \infty)\)
    • Kvadratna \(a < 0\): \(Z_f = (-\infty, y_T]\)
    • Eksponentna \(a^x\): \(Z_f = (0, \infty)\)
    • Logaritemska: \(Z_f = \mathbb{R}\)
    • Sinus/kosinus: \(Z_f = [-1, 1]\)
$$\text{Primer: } f(x) = x^2 + 3$$

1. Teme: \(T(0, 3)\). 2. \(a = 1 > 0\). 3. \(Z_f = [3, \infty)\).

Tip 6: Inverzna funkcija

Kako prepoznaš: "Poiščite inverzno funkcijo \(f^{-1}\)".

Postopek:

  1. Zapiši \(y = f(x)\).
  2. Zamenjaj \(x\) in \(y\): \(x = f(y)\).
  3. Izrazi \(y\) iz enačbe.
  4. Zapiši \(f^{-1}(x) = ...\)
$$\text{Primer: } f(x) = \frac{2-x}{x+2}$$

1. \(y = \dfrac{2-x}{x+2}\). 2. \(x = \dfrac{2-y}{y+2}\). 3. \(x(y+2) = 2-y \Rightarrow xy + 2x = 2 - y \Rightarrow y(x+1) = 2 - 2x \Rightarrow y = \dfrac{2-2x}{x+1}\). 4. \(f^{-1}(x) = \dfrac{2-2x}{x+1}\).

Tip 7: Presečišča grafov

Kako prepoznaš: "Izračunajte presečišče grafov \(f\) in \(g\)".

Postopek:

  1. Nastavi \(f(x) = g(x)\).
  2. Reši enačbo.
  3. Za vsak \(x\) izračunaj \(y = f(x)\).
  4. Zapiši točke \((x, y)\).
$$\text{Primer: } f(x) = 2^x, \quad g(x) = 65 \cdot 2^x - 1$$

1. \(2^x = 65 \cdot 2^x - 1\). 2. \(1 = 64 \cdot 2^x\). 3. \(2^x = \dfrac{1}{64} = 2^{-6} \Rightarrow x = -6\). 4. \(y = 2^{-6} = \dfrac{1}{64}\). 5. Presečišče: \(\left(-6, \dfrac{1}{64}\right)\).

Tip 8: Soda/liha funkcija

Kako prepoznaš: "Ali je funkcija soda/liha?", "utemeljite".

Postopek:

  1. Izračunaj \(f(-x)\).
  2. Primerjaj s \(f(x)\) in \(-f(x)\):
    • \(f(-x) = f(x)\) → soda
    • \(f(-x) = -f(x)\) → liha
    • Nič od tega → niti soda niti liha
$$\text{Primer: } f(x) = x^3 - x$$

1. \(f(-x) = (-x)^3 - (-x) = -x^3 + x = -(x^3 - x) = -f(x)\). 2. Funkcija je liha.

Tip 9: Transformacije grafov

Kako prepoznaš: "Narišite graf funkcije \(g(x) = f(x - 2) + 1\)".

Postopek:

  1. Začni z osnovnim grafom \(f(x)\).
  2. Uporabi transformacije:
    • \(f(x) + c\) → premik navzgor za \(c\)
    • \(f(x - c)\) → premik v desno za \(c\)
    • \(-f(x)\) → zrcaljenje čez os \(x\)
    • \(f(-x)\) → zrcaljenje čez os \(y\)
    • \(a \cdot f(x)\) → razteg v smeri \(y\)
$$\text{Primer: } g_1(x) = -f(x), \quad g_2(x) = f(x) + 1, \quad g_3(x) = f(x-2), \quad g_4(x) = 2f(x), \quad g_5(x) = f(-x)$$

1. \(g_1\): zrcaljenje čez os \(x\). 2. \(g_2\): premik navzgor za 1. 3. \(g_3\): premik v desno za 2. 4. \(g_4\): razteg v smeri \(y\) za faktor 2. 5. \(g_5\): zrcaljenje čez os \(y\).

Tip 10: Obravnava funkcije (brez odvoda)

Kako prepoznaš: "Narišite graf funkcije", "zapišite ničle, pole, asimptote".

Postopek:

  1. Določi \(D_f\).
  2. Poišči ničle (\(f(x) = 0\)).
  3. Poišči pole (\(q(x) = 0\)).
  4. Poišči začetno vrednost \(f(0)\).
  5. Določi asimptote.
  6. Nariši graf (upoštevaj obnašanje pri polih in v neskončnosti).
$$\text{Primer: } f(x) = \frac{x - 2}{x}$$

1. \(D_f = \mathbb{R} \setminus \{0\}\). 2. Ničla: \(x = 2\). 3. Pol: \(x = 0\). 4. \(f(0)\) ni definirano. 5. Navpična asimptota: \(x = 0\); vodoravna: \(y = 1\). 6. Graf: hiperbola v I. in III. kvadrantu.

Tip 11: Eksponentna in logaritemska funkcija — iskanje parametra

Kako prepoznaš: "Določite \(a\) tako, da bo graf potekal skozi točko".

Postopek:

  1. Vstavi koordinate točke v enačbo \(y = f(x)\).
  2. Reši enačbo za parameter.
$$\text{Primer: } f(x) = \log_a x \text{ poteka skozi } A\left(\frac{1}{8}, -\frac{3}{2}\right)$$

1. \(-\dfrac{3}{2} = \log_a \dfrac{1}{8}\). 2. \(a^{-3/2} = \dfrac{1}{8} = 2^{-3}\). 3. \(a^{1/2} = 2 \Rightarrow a = 4\).

Tip 12: Limita funkcije

Kako prepoznaš: "Izračunajte limito", \(\lim_{x \to a}\).

Postopek:

  1. Poskusi vstaviti \(a\) neposredno.
  2. Če dobiš \(\dfrac{0}{0}\) ali \(\dfrac{\infty}{\infty}\): poenostavi (razstavi, racionaliziraj) ali uporabi L'Hôpitalovo pravilo.
  3. Če gre \(x \to \infty\): deli z najvišjo potenco v imenovalcu.
  4. Uporabi znane limite: \(\lim_{x \to 0} \dfrac{\sin x}{x} = 1\), \(\lim_{x \to \infty} \left(1 + \dfrac{1}{x}\right)^x = e\).
$$\text{Primer: } \lim_{x \to 7} \frac{x^2 - 49}{x^2 - 2x - 35}$$

1. Vstavi \(x = 7\): \(\dfrac{0}{0}\). 2. Razstavi: \(\dfrac{(x-7)(x+7)}{(x-7)(x+5)}\). 3. Krajšaj: \(\dfrac{x+7}{x+5}\). 4. Limita: \(\dfrac{14}{12} = \dfrac{7}{6}\).

3. Pogoste napake

  • Pozabi preveriti, ali so ničle v \(D_f\).
  • Pri racionalni funkciji zamenjaš ničle in pole.
  • Pri vodoravni asimptoti pozabiš primerjati stopnji števca in imenovalca.
  • Pri inverzni funkciji pozabiš zamenjati \(x\) in \(y\).
  • Pri transformacijah zamenjaš \(f(x-2)\) (premik desno) s \(f(x+2)\) (premik levo).
  • Pri limiti \(\dfrac{0}{0}\) pozabiš razstaviti ali racionalizirati.
  • Pri eksponentni/logaritemski funkciji zamenjaš \(D_f\) in \(Z_f\).
