📊 2. Množice

Osnovni pojmi, operacije z množicami in Vennovi diagrami

📖 Osnovni pojmi

Množica je zbirka dobro določenih, razločljivih objektov (elementov).

Element: x ∈ A ali x ∉ A

Prazna množica: ∅ ali {}

Univerzalna množica: U

Moč množice: |A| (število elementov)

🔗 Operacije z množicami

PRESEK (∩)
A ∩ B = {x | x ∈ A in x ∈ B}

Skupni elementi

UNIJA (∪)
A ∪ B = {x | x ∈ A ali x ∈ B}

Vsi elementi iz obeh množic

RAZLIKA (\)
A \ B = {x | x ∈ A in x ∉ B}

Elementi v A, ki niso v B

KOMPLEMENT (^c)
A^c = U \ A = {x ∈ U | x ∉ A}

Vsi elementi razen tistih v A

📝 Pomembne zakonitosti

De Morganova zakona
(A ∩ B)^c = A^c ∪ B^c
(A ∪ B)^c = A^c ∩ B^c
Distributivnost
A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
Število elementov
|A ∪ B| = |A| + |B| - |A ∩ B|

📊 Vennov diagram - primer

Primer: U = {1,2,3,4,5,6,7}, A = {1,2,3,4}, B = {3,4,5,6}

  • A ∩ B = {3,4}
  • A ∪ B = {1,2,3,4,5,6}
  • A \ B = {1,2}
  • A^c = {5,6,7}
