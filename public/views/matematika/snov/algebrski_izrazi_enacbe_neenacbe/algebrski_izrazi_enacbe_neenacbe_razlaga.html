Algebra in enačbe

Vse, kar potrebuješ za maturo iz algebre: potence, razstavljanje, ulomki, kvadratne enačbe, eksponentne in logaritemske enačbe, polinomi. Vsak tip naloge ima postopek po korakih.

1. Teorija — formule in pravila

Kar moraš znati na pamet, preden se lotiš nalog.

Potence in koreni

  • \(a^m \cdot a^n = a^{m+n}\)
  • \(\dfrac{a^m}{a^n} = a^{m-n}\)
  • \((a^m)^n = a^{mn}\)
  • \((ab)^n = a^n b^n\)
  • \(\left(\dfrac{a}{b}\right)^n = \dfrac{a^n}{b^n}\)
  • \(a^{-n} = \dfrac{1}{a^n}\), \(a^0 = 1\) (za \(a \neq 0\))
  • \(\sqrt[n]{a^m} = a^{m/n}\)
  • \(\sqrt{a} \cdot \sqrt{a} = a\), \(\sqrt{a^2} = |a|\)

Razstavljanje (faktorizacija)

  • Skupni faktor: \(a^2 - 3a = a(a - 3)\)
  • Razlika kvadratov: \(a^2 - b^2 = (a - b)(a + b)\)
  • Vsota kubov: \(a^3 + b^3 = (a + b)(a^2 - ab + b^2)\)
  • Diferenca kubov: \(a^3 - b^3 = (a - b)(a^2 + ab + b^2)\)
  • Kvadrat binoma: \((a \pm b)^2 = a^2 \pm 2ab + b^2\)
  • Kub binoma: \((a \pm b)^3 = a^3 \pm 3a^2b + 3ab^2 \pm b^3\)
  • Kvadratni tričlenik: \(ax^2 + bx + c = a(x - x_1)(x - x_2)\)

Kvadratna enačba \(ax^2 + bx + c = 0\)

  • Diskriminanta: \(D = b^2 - 4ac\)
  • Rešitve: \(x_{1,2} = \dfrac{-b \pm \sqrt{D}}{2a}\)
  • Vietovo pravilo: \(x_1 + x_2 = -\dfrac{b}{a}\), \(x_1 \cdot x_2 = \dfrac{c}{a}\)
  • \(D > 0\) → dve realni rešitvi
  • \(D = 0\) → ena dvojna rešitev
  • \(D < 0\) → kompleksni rešitvi

Logaritmi

  • \(\log_a x = y \iff a^y = x\) (za \(a > 0, a \neq 1, x > 0\))
  • \(\log_a(xy) = \log_a x + \log_a y\)
  • \(\log_a \dfrac{x}{y} = \log_a x - \log_a y\)
  • \(\log_a x^n = n \log_a x\)
  • \(\log_a a = 1\), \(\log_a 1 = 0\)
  • \(\log_a a^n = n\), \(a^{\log_a x} = x\)
  • \(\log_a \sqrt[n]{x} = \dfrac{1}{n} \log_a x\)

Eksponentne enačbe

  • \(a^{f(x)} = a^{g(x)} \iff f(x) = g(x)\) (za \(a > 0, a \neq 1\))
  • \(a^{f(x)} = b \Rightarrow\) logaritmiraj obe strani
  • Pri vsoti členov z isto osnovo izpostavi skupni faktor
  • Pri \(a^{2x}\) in \(a^x\) uvedi novo neznanko \(t = a^x\)

Polinomi

  • Ničla polinoma: \(p(x_0) = 0\)
  • Ostanek pri deljenju z \((x-a)\): \(p(a)\)
  • Dvojna ničla: \((x - x_0)^2\) v faktorizirani obliki
  • Hornerjev algoritem: za deljenje polinoma z \((x - x_0)\)

2. Tipi nalog — postopki po korakih

Za vsak tip: kako ga prepoznaš, kako ga rešiš, primer.

Tip 1: Poenostavljanje potenc

Kako prepoznaš: "Poenostavite izraz", nastopajo potence z isto osnovo.

Postopek:

  1. Zapiši vse potence z isto osnovo.
  2. Uporabi pravila: \(a^m \cdot a^n = a^{m+n}\), \(\dfrac{a^m}{a^n} = a^{m-n}\), \((a^m)^n = a^{mn}\).
  3. Negativne eksponente pretvori v ulomke ali obratno.
  4. Poenostavi eksponent.
$$\text{Primer: } \frac{((-a)^4)^3 \cdot (-a)^{-3}}{a^9}$$

1. \(((-a)^4)^3 = a^{12}\). 2. \((-a)^{-3} = -a^{-3}\). 3. \(a^{12} \cdot (-a^{-3}) = -a^9\). 4. \(\dfrac{-a^9}{a^9} = -1\).

Tip 2: Razstavljanje izrazov

Kako prepoznaš: "Razstavite na faktorje", "zapišite v obliki produkta".

Postopek:

  1. Izpostavi skupni faktor, če obstaja.
  2. Preveri, ali je razlika kvadratov (\(a^2 - b^2\)).
  3. Preveri, ali je vsota/diferenca kubov (\(a^3 \pm b^3\)).
  4. Če je kvadratni tričlenik \(ax^2 + bx + c\): poišči ničli \(x_1, x_2\) in zapiši \(a(x - x_1)(x - x_2)\).
  5. Pri višjih stopnjah: grupiraj člene (npr. \(a^3 + 2a^2 - 9a - 18 = a^2(a+2) - 9(a+2)\)).
  6. Preveri, ali se da še naprej razstaviti.
$$\text{Primer: } x^2 + 2x - 48$$

1. Skupnega faktorja ni. 2. Ni razlika kvadratov. 3. Kvadratni tričlenik: \(D = 4 + 192 = 196\), \(\sqrt{D} = 14\). 4. \(x_{1,2} = \dfrac{-2 \pm 14}{2} \Rightarrow x_1 = 6, x_2 = -8\). 5. Rezultat: \((x - 6)(x + 8)\).

$$\text{Primer: } a^3 + 2a^2 - 9a - 18$$

1. Grupiraj: \(a^2(a + 2) - 9(a + 2)\). 2. Skupni faktor \((a + 2)\): \((a + 2)(a^2 - 9)\). 3. Razlika kvadratov: \((a + 2)(a - 3)(a + 3)\).

$$\text{Primer: } 2x^4 - 72x^2$$

1. Skupni faktor \(2x^2\): \(2x^2(x^2 - 36)\). 2. Razlika kvadratov: \(2x^2(x - 6)(x + 6)\).

Tip 3: Poenostavljanje ulomkov

Kako prepoznaš: "Poenostavite izraz", "okrajšajte ulomek", nastopajo ulomki z neznanko.

Postopek:

  1. Zapiši pogoje (imenovalec \(\neq 0\)).
  2. Razstavi števec in imenovalec na faktorje.
  3. Krajšaj skupne faktorje.
  4. Če gre za vsoto/razliko ulomkov: poišči skupni imenovalec, seštej, poenostavi.
  5. Preveri, ali je rezultat še mogoče poenostaviti.
$$\text{Primer: } \frac{2}{a^2 - 9} - \frac{1}{a^2 + 3a}$$

1. Pogoji: \(a \neq \pm 3, a \neq 0\). 2. Razstavi: \((a-3)(a+3)\) in \(a(a+3)\). 3. Skupni imenovalec: \(a(a-3)(a+3)\). 4. \(\dfrac{2a - (a-3)}{a(a-3)(a+3)} = \dfrac{a + 3}{a(a-3)(a+3)} = \dfrac{1}{a(a-3)}\).

$$\text{Primer: } \frac{a+1}{a+6} - \frac{(a+2)(a-4)}{a^2 + 4a - 12}$$

1. \(a^2 + 4a - 12 = (a + 6)(a - 2)\). 2. Skupni imenovalec: \((a+6)(a-2)\). 3. \(\dfrac{(a+1)(a-2) - (a+2)(a-4)}{(a+6)(a-2)} = \dfrac{a^2 - a - 2 - (a^2 - 2a - 8)}{(a+6)(a-2)} = \dfrac{a + 6}{(a+6)(a-2)} = \dfrac{1}{a-2}\).

Tip 4: Kvadratne enačbe

Kako prepoznaš: \(ax^2 + bx + c = 0\), "rešite enačbo".

Postopek:

  1. Zapiši v obliki \(ax^2 + bx + c = 0\).
  2. Izračunaj \(D = b^2 - 4ac\).
  3. Če \(D > 0\): \(x_{1,2} = \dfrac{-b \pm \sqrt{D}}{2a}\).
  4. Če \(D = 0\): \(x = -\dfrac{b}{2a}\) (dvojna ničla).
  5. Če \(D < 0\): kompleksni rešitvi \(x_{1,2} = \dfrac{-b \pm i\sqrt{|D|}}{2a}\).
  6. Preveri z vstavitvijo v enačbo.

Posebni primeri:

  • Nepopolna (brez b): \(ax^2 + c = 0 \Rightarrow x^2 = -\dfrac{c}{a}\) (koren).
  • Nepopolna (brez c): \(ax^2 + bx = 0 \Rightarrow x(ax + b) = 0 \Rightarrow x = 0, x = -\dfrac{b}{a}\).
  • Vietovo pravilo: uporabi, ko iščeš \(x_1 + x_2\) ali \(x_1 \cdot x_2\) brez računanja rešitev.
$$\text{Primer: } x^2 - 6x + 9 = 0$$

1. \(D = 36 - 36 = 0\). 2. \(x = \dfrac{6}{2} = 3\) (dvojna ničla).

$$\text{Primer: } x^2 - 3x - 10 = 0$$

1. \(D = 9 + 40 = 49\), \(\sqrt{D} = 7\). 2. \(x_{1,2} = \dfrac{3 \pm 7}{2} \Rightarrow x_1 = 5, x_2 = -2\).

$$\text{Primer: } 3x^2 + mx - 4 = 0, \text{ vsota rešitev } = 2$$

1. Vietovo: \(x_1 + x_2 = -\dfrac{m}{3} = 2\). 2. \(m = -6\).

Tip 5: Eksponentne enačbe

Kako prepoznaš: neznanka v eksponentu, \(a^{f(x)} = ...\)

Postopek:

  1. Poskusi zapisati obe strani z isto osnovo: \(a^{f(x)} = a^{g(x)}\).
  2. Če uspe: \(f(x) = g(x)\).
  3. Če ne: logaritmiraj obe strani (ali uporabi \(\log\) z osnovo \(a\)).
  4. Če imaš vsoto členov z isto osnovo (npr. \(3^x + 3^{x+2}\)): izpostavi \(3^x\).
  5. Če nastopa \(a^{2x}\) in \(a^x\): uvedi novo neznanko \(t = a^x\) in reši kvadratno enačbo.
$$\text{Primer: } 3^x + 3^{x+2} = \frac{10}{9}$$

1. \(3^x + 9 \cdot 3^x = \dfrac{10}{9}\). 2. \(10 \cdot 3^x = \dfrac{10}{9}\). 3. \(3^x = \dfrac{1}{9}\). 4. \(3^x = 3^{-2} \Rightarrow x = -2\).

$$\text{Primer: } 2^{x+3} \cdot 2^{x+5} = 32$$

1. \(2^{(x+3)+(x+5)} = 2^5\). 2. \(2x + 8 = 5 \Rightarrow x = -\dfrac{3}{2}\).

$$\text{Primer: } 2^{x-1} + 3 \cdot 2^x = \frac{7}{8}$$

1. \(\dfrac{2^x}{2} + 3 \cdot 2^x = \dfrac{7}{8}\). 2. \(2^x \left(\dfrac{1}{2} + 3\right) = \dfrac{7}{8}\). 3. \(2^x \cdot \dfrac{7}{2} = \dfrac{7}{8}\). 4. \(2^x = \dfrac{1}{4} \Rightarrow x = -2\).

$$\text{Primer: } 2^{2x} - 5 \cdot 2^x + 4 = 0$$

1. Uvedi \(t = 2^x\): \(t^2 - 5t + 4 = 0\). 2. \(t_1 = 1, t_2 = 4\). 3. \(2^x = 1 \Rightarrow x = 0\); \(2^x = 4 \Rightarrow x = 2\).

Tip 6: Logaritemske enačbe

Kako prepoznaš: \(\log_a f(x) = ...\), neznanka v argumentu logaritma.

Postopek:

  1. Zapiši pogoje: argumenti logaritmov \(> 0\).
  2. Uporabi pravila: \(\log_a x + \log_a y = \log_a(xy)\), \(\log_a x - \log_a y = \log_a(x/y)\).
  3. Enačbo pretvori v obliko \(\log_a f(x) = \log_a g(x)\) ali \(\log_a f(x) = c\).
  4. Iz \(\log_a f(x) = \log_a g(x)\) sledi \(f(x) = g(x)\).
  5. Iz \(\log_a f(x) = c\) sledi \(f(x) = a^c\).
  6. Reši enačbo in preveri pogoje.
$$\text{Primer: } \log_2 x = 2 - \log_2(x - 3)$$

1. Pogoji: \(x > 0, x > 3 \Rightarrow x > 3\). 2. \(\log_2 x + \log_2(x-3) = 2 \Rightarrow \log_2[x(x-3)] = 2\). 3. \(x(x-3) = 4 \Rightarrow x^2 - 3x - 4 = 0 \Rightarrow x_1 = 4, x_2 = -1\). 4. \(x_2\) ne ustreza pogoju. Rešitev: \(x = 4\).

$$\text{Primer: } \log(x+15) + \log x = 2$$

1. Pogoji: \(x > 0\). 2. \(\log[x(x+15)] = 2 \Rightarrow x^2 + 15x = 100\). 3. \(x^2 + 15x - 100 = 0 \Rightarrow x_1 = 5, x_2 = -20\). 4. \(x = 5\).

$$\text{Primer: } \log_3(2x+1) = 2$$

1. Pogoj: \(2x + 1 > 0 \Rightarrow x > -\dfrac{1}{2}\). 2. \(2x + 1 = 3^2 = 9 \Rightarrow x = 4\). 3. Preveri: \(4 > -\dfrac{1}{2}\). ✓

Tip 7: Polinomi — ničle in faktorizacija

Kako prepoznaš: "Poiščite ničle polinoma", "razstavite polinom".

Postopek:

  1. Poskusi izpostaviti skupni faktor.
  2. Preveri, ali je \(x = 1, -1, 2, -2\) ničla (vstavi v \(p(x)\)).
  3. Če najdeš ničlo \(x_0\), deli \(p(x)\) z \((x - x_0)\) (Hornerjev algoritem).
  4. Ponavljaj, dokler ne dobiš kvadratnega polinoma.
  5. Reši kvadratno enačbo za preostale ničle.
  6. Dvojna ničla: faktor \((x - x_0)\) se pojavi dvakrat.
$$\text{Primer: } p(x) = 2x^4 - 3x^3 - 15x^2 + ax - 12, \text{ } x = 2 \text{ dvojna ničla}$$

1. \(p(2) = 0\): \(32 - 24 - 60 + 2a - 12 = 0 \Rightarrow 2a = 64 \Rightarrow a = 32\). 2. \(p'(2) = 0\) (dvojna ničla): \(p'(x) = 8x^3 - 9x^2 - 30x + 32\), \(p'(2) = 64 - 36 - 60 + 32 = 0\). ✓ 3. Deli \(p(x)\) z \((x-2)^2 = x^2 - 4x + 4\). 4. \(p(x) = (x-2)^2(2x^2 + 5x - 3)\). 5. \(2x^2 + 5x - 3 = 0 \Rightarrow x_1 = \dfrac{1}{2}, x_2 = -3\). 6. Ničle: \(x = 2\) (dvojna), \(x = \dfrac{1}{2}, x = -3\).

Tip 8: Ostanek pri deljenju polinomov

Kako prepoznaš: "Izračunajte ostanek pri deljenju", "določite a tako, da bo ostanek ...".

Postopek:

  1. Ostanek pri deljenju \(p(x)\) z \((x - a)\) je \(p(a)\).
  2. Če je \(p(a) = 0\), je \(a\) ničla.
  3. Za deljenje z \((x^2 - 1)\) uporabi deljenje polinomov (ali nastavi ostanek kot \(ax + b\)).
$$\text{Primer: } p(x) = x^3 - 2x + a, \text{ ostanek pri deljenju z } (x-3) = 4$$

1. \(p(3) = 4\): \(27 - 6 + a = 4 \Rightarrow a = -17\). 2. Količnik: \(x^2 + 3x + 7\) (z deljenjem).

Tip 9: Sistemi enačb

Kako prepoznaš: dve ali več enačb z več neznankami.

Postopek (linearni sistem):

  1. Iz ene enačbe izrazi eno neznanko.
  2. Vstavi v drugo enačbo.
  3. Reši dobljeno enačbo z eno neznanko.
  4. Izračunaj še drugo neznanko.
  5. Preveri z vstavitvijo v obe enačbi.
$$\text{Primer: } 2x - 3y = 5, \quad y = \frac{1}{2}x - 2$$

1. Vstavi \(y\): \(2x - 3\left(\dfrac{1}{2}x - 2\right) = 5\). 2. \(2x - \dfrac{3}{2}x + 6 = 5\). 3. \(\dfrac{1}{2}x = -1 \Rightarrow x = -2\). 4. \(y = \dfrac{1}{2}(-2) - 2 = -3\). 5. Rešitev: \((-2, -3)\).

Tip 10: Sistemi neenačb

Kako prepoznaš: dve neenačbi, "rešite sistem neenačb".

Postopek:

  1. Reši vsako neenačbo posebej.
  2. Rešitve zapiši kot intervale.
  3. Presek intervalov je rešitev sistema.
  4. Ponazori na številski premici.
$$\text{Primer: } (x+2)^2 \leq x^2 + 8, \quad 1 - 3x < 5$$

1. Prva: \(x^2 + 4x + 4 \leq x^2 + 8 \Rightarrow 4x \leq 4 \Rightarrow x \leq 1\). 2. Druga: \(-3x < 4 \Rightarrow x > -\dfrac{4}{3}\). 3. Rešitev: \(x \in \left(-\dfrac{4}{3}, 1\right]\).

Tip 11: Besedilne naloge (ulomki, starost, razmerja)

Kako prepoznaš: opis situacije, "izračunajte ...", "koliko ...".

Postopek:

  1. Preberi nalogo in določi neznanke (npr. \(x\) = števec, \(y\) = imenovalec).
  2. Zapiši enačbe iz besedila (npr. "števec je za 1 večji od imenovalca" → \(x = y + 1\)).
  3. Reši sistem enačb.
  4. Preveri smiselnost rešitve.
  5. Zapiši odgovor v besedilu.
$$\text{Primer: Števec ulomka je za 1 večji od imenovalca. Če števec pomnožimo z 2, imenovalec pa povečamo za 12, dobimo } \frac{3}{2}.$$

1. \(x = y + 1\). 2. \(\dfrac{2x}{y + 12} = \dfrac{3}{2}\). 3. \(4x = 3(y + 12) \Rightarrow 4(y+1) = 3y + 36 \Rightarrow y = 32\). 4. \(x = 33\). 5. Ulomek: \(\dfrac{33}{32}\).

$$\text{Primer: Pred dvema letoma je bila mama petkrat starejša od sina, čez osem let pa bo mamina starost } \frac{3}{2} \text{ starosti sina.}$$

1. \(m - 2 = 5(s - 2)\). 2. \(m + 8 = \dfrac{3}{2}(s + 8)\). 3. Reši sistem: \(m = 5s - 8\), \(2(5s - 8 + 8) = 3(s + 8) \Rightarrow 10s = 3s + 24 \Rightarrow s = 8\). 4. Preveri: \(m = 5 \cdot 8 - 8 = 32\). 5. Mama je stara 32 let, sin 8 let.

Tip 12: Dokazovanje (enakosti, ničle)

Kako prepoznaš: "Dokažite", "pokažite".

Postopek:

  1. Preberi, kaj je treba dokazati.
  2. Začni z eno stranjo enakosti (običajno bolj zapleteno) in jo preoblikuj v drugo.
  3. Uporabi znane formule in pravila (razstavljanje, razširjanje, potence).
  4. Vsak korak mora biti ekvivalenten prejšnjemu.
  5. Na koncu zapiši: "S tem je enakost dokazana."

Pri dokazovanju ničle:

  1. Vstavi \(x_0\) v \(p(x)\).
  2. Izračunaj in pokaži, da je rezultat 0.
  3. Za dvojno ničlo pokaži še \(p'(x_0) = 0\).
$$\text{Primer: Dokaži, da je } x = -1 \text{ ničla polinoma } p(x) = x^3 + 3x^2 + 3x + 1.$$

1. \(p(-1) = (-1)^3 + 3(-1)^2 + 3(-1) + 1 = -1 + 3 - 3 + 1 = 0\). 2. Torej je \(x = -1\) ničla. 3. \(p(x) = (x+1)^3\) → \(x = -1\) je trojna ničla.

3. Pogoste napake

  • Pozabi zapisati pogoje pri ulomkih in logaritmih.
  • Pri logaritemskih enačbah ne preveri, ali rešitve ustrezajo pogojem.
  • Pri eksponentnih enačbah ne izpostavi skupnega faktorja (npr. \(3^x\)).
  • Napačno razstavljanje: \(a^2 + b^2 \neq (a+b)^2\) (to je vsota kvadratov, ne razlika).
  • Pozabi na dvojno ničlo pri polinomih (npr. \((x-2)^2\)).
  • Pri kvadratni enačbi z \(D < 0\) pozabi, da so rešitve kompleksne.
