Algebrski izrazi, enačbe in neenačbe

Vse o algebra za maturo: potenciranje in razstavljanje izrazov, računanje z ulomki, linearne in kvadratne enačbe in neenačbe, eksponentne in logaritemske enačbe, polinomi, sistemi enačb in besedilne naloge.

📋 Formule na maturi — osnovna raven

Na maturitetnem listu s formulami so za algebro relevantne naslednje formule:

  • Vsota in razlika kubov: \(a^3 \pm b^3 = (a \pm b)(a^2 \mp ab + b^2)\)
  • Kvadrat binoma: \((a \pm b)^2 = a^2 \pm 2ab + b^2\)
  • Razlika kvadratov: \(a^2 - b^2 = (a - b)(a + b)\)
  • Logaritem: \(\log_a(xy) = \log_a x + \log_a y\), \(\log_a \dfrac{x}{y} = \log_a x - \log_a y\), \(\log_a x^n = n \log_a x\)
  • Prehod na novo osnovo: \(\log_a x = \dfrac{\log_b x}{\log_b a}\)

2. Tipi nalog — postopki po korakih

Za vsak tip: kako ga prepoznaš, kako ga rešiš, primer.

Tip 1: Poenostavljanje potenc

\(a^m \cdot a^n = a^{m+n}\)

Kako prepoznaš: "poenostavite izraz", nastopajo potence z isto osnovo.

Postopek:

  1. Zapiši vse potence z isto osnovo.
  2. Uporabi pravila: \(a^m \cdot a^n = a^{m+n}\), \(\dfrac{a^m}{a^n} = a^{m-n}\), \((a^m)^n = a^{mn}\).
  3. Negativne eksponente pretvori v ulomke.
  4. Poenostavi eksponent.

Primer: \(\dfrac{((-a)^4)^3 \cdot (-a)^{-3}}{a^9}\)

Korak 1: \(((-a)^4)^3 = a^{12}\).

Korak 2: \((-a)^{-3} = -a^{-3}\).

Korak 3: \(a^{12} \cdot (-a^{-3}) = -a^9\).

Korak 4: \(\dfrac{-a^9}{a^9} = -1\).

Tip 2: Razstavljanje izrazov

\(a^2 - b^2 = (a-b)(a+b)\)

Kako prepoznaš: "razstavite na faktorje", "zapišite v obliki produkta".

Postopek:

  1. Izpostavi skupni faktor, če obstaja.
  2. Preveri razliko kvadratov (\(a^2 - b^2\)).
  3. Preveri vsoto/diferenco kubov (\(a^3 \pm b^3\)).
  4. Za kvadratni tričlenik: poišči ničli in zapiši \(a(x-x_1)(x-x_2)\).
  5. Pri višjih stopnjah: grupiraj člene.

Primer 1: \(x^2 + 2x - 48\)

\(D = 4 + 192 = 196\), \(\sqrt{D} = 14\). \(x_{1,2} = \dfrac{-2 \pm 14}{2} \Rightarrow x_1 = 6, x_2 = -8\). Rezultat: \((x-6)(x+8)\).

Primer 2: \(a^3 + 2a^2 - 9a - 18\)

Grupiramo: \(a^2(a+2) - 9(a+2) = (a+2)(a^2-9) = (a+2)(a-3)(a+3)\).

Primer 3: \(2x^4 - 72x^2\)

\(= 2x^2(x^2 - 36) = 2x^2(x-6)(x+6)\).

Tip 3: Poenostavljanje ulomkov

\(\dfrac{a^2 - b^2}{a - b} = a + b\)

Kako prepoznaš: "poenostavite izraz", "okrajšajte ulomek".

Postopek:

  1. Zapiši pogoje (imenovalec \(\neq 0\)).
  2. Razstavi števec in imenovalec na faktorje.
  3. Krajšaj skupne faktorje.
  4. Če gre za vsoto/razliko ulomkov: skupni imenovalec, seštej, poenostavi.

Primer: \(\dfrac{2}{a^2-9} - \dfrac{1}{a^2+3a}\)

Pogoji: \(a \neq \pm 3, a \neq 0\). Razstavi: \((a-3)(a+3)\) in \(a(a+3)\). Skupni imenovalec: \(a(a-3)(a+3)\).

\(= \dfrac{2a - (a-3)}{a(a-3)(a+3)} = \dfrac{a+3}{a(a-3)(a+3)} = \dfrac{1}{a(a-3)}\).

Tip 4: Kvadratne enačbe

\(x_{1,2} = \dfrac{-b \pm \sqrt{D}}{2a}\)

Kako prepoznaš: \(ax^2 + bx + c = 0\), "rešite enačbo".

Postopek:

  1. Zapiši v obliki \(ax^2 + bx + c = 0\).
  2. Izračunaj \(D = b^2 - 4ac\).
  3. Če \(D > 0\): \(x_{1,2} = \dfrac{-b \pm \sqrt{D}}{2a}\).
  4. Če \(D = 0\): \(x = -\dfrac{b}{2a}\) (dvojna ničla).
  5. Če \(D < 0\): kompleksni rešitvi \(x_{1,2} = \dfrac{-b \pm i\sqrt{|D|}}{2a}\).

Primer: \(x^2 - 3x - 10 = 0\)

\(D = 9 + 40 = 49\), \(\sqrt{D} = 7\). \(x_{1,2} = \dfrac{3 \pm 7}{2} \Rightarrow x_1 = 5, x_2 = -2\).

Tip 5: Eksponentne enačbe

\(a^{f(x)} = a^{g(x)} \iff f(x) = g(x)\)

Kako prepoznaš: neznanka v eksponentu, \(a^{f(x)} = \ldots\)

Postopek:

  1. Poskusi zapisati obe strani z isto osnovo.
  2. Če uspe: \(f(x) = g(x)\).
  3. Če ne: logaritmiraj obe strani.
  4. Pri vsoti členov \(3^x + 3^{x+2}\): izpostavi \(3^x\).
  5. Pri \(a^{2x}\) in \(a^x\): uvedi \(t = a^x\).

Primer 1: \(3^x + 3^{x+2} = \dfrac{10}{9}\)

\(3^x + 9 \cdot 3^x = \dfrac{10}{9} \Rightarrow 10 \cdot 3^x = \dfrac{10}{9} \Rightarrow 3^x = \dfrac{1}{9} \Rightarrow x = -2\).

Primer 2: \(2^{2x} - 5 \cdot 2^x + 4 = 0\)

\(t = 2^x\): \(t^2 - 5t + 4 = 0 \Rightarrow t_1 = 1, t_2 = 4\). \(2^x = 1 \Rightarrow x = 0\); \(2^x = 4 \Rightarrow x = 2\).

Tip 6: Logaritemske enačbe

\(\log_a f(x) = \log_a g(x) \iff f(x) = g(x)\)

Kako prepoznaš: \(\log_a f(x) = \ldots\), neznanka v argumentu.

Postopek:

  1. Zapiši pogoje: argumenti \(> 0\).
  2. Uporabi pravila za logaritme.
  3. Enačbo pretvori v obliko \(\log_a f = \log_a g\) ali \(\log_a f = c\).
  4. Reši in preveri pogoje.

Primer: \(\log_2 x = 2 - \log_2(x-3)\)

Pogoji: \(x > 3\). \(\log_2[x(x-3)] = 2 \Rightarrow x(x-3) = 4 \Rightarrow x^2 - 3x - 4 = 0 \Rightarrow x_1 = 4, x_2 = -1\).

Rešitev: \(x = 4\).

Tip 7: Polinomi — ničle in faktorizacija

\(p(x_0) = 0 \Rightarrow (x - x_0) \mid p(x)\)

Kako prepoznaš: "poiščite ničle polinoma", "razstavite polinom".

Postopek:

  1. Izpostavi skupni faktor, če obstaja.
  2. Preveri \(x = 1, -1, 2, -2\) (vstavi v \(p(x)\)).
  3. Če najdeš ničlo \(x_0\), deli \(p(x)\) z \((x - x_0)\) (Hornerjev algoritem).
  4. Ponavljaj do kvadratnega polinoma.
  5. Reši kvadratno enačbo za preostale ničle.

Primer: \(p(x) = 2x^4 - 3x^3 - 15x^2 + ax - 12\), \(x = 2\) dvojna ničla

\(p(2) = 0 \Rightarrow a = 32\). \(p'(2) = 0\) ✓. \(p(x) = (x-2)^2(2x^2 + 5x - 3)\).

Ničle: \(x = 2\) (dvojna), \(x = \dfrac{1}{2}, x = -3\).

Tip 8: Ostanek pri deljenju polinomov

Ostanek pri deljenju z \((x-a)\) = \(p(a)\)

Kako prepoznaš: "izračunajte ostanek pri deljenju".

Postopek:

  1. Ostanek pri deljenju \(p(x)\) z \((x-a)\) je \(p(a)\).
  2. Če je \(p(a) = 0\), je \(a\) ničla.
  3. Za deljenje z \((x^2-1)\): nastavi ostanek \(ax + b\).

Primer: \(p(x) = x^3 - 2x + a\), ostanek pri deljenju z \((x-3) = 4\)

\(p(3) = 4 \Rightarrow 27 - 6 + a = 4 \Rightarrow a = -17\).

Tip 9: Sistemi linearnih enačb

\(2x - 3y = 5\), \(y = \frac{1}{2}x - 2\)

Kako prepoznaš: dve enačbi, dve neznanki.

Postopek (substitucija):

  1. Iz ene enačbe izrazi eno neznanko.
  2. Vstavi v drugo enačbo.
  3. Reši dobljeno enačbo z eno neznanko.
  4. Izračunaj še drugo neznanko.
  5. Preveri z vstavitvijo v obe enačbi.

Primer: \(2x - 3y = 5\), \(y = \frac{1}{2}x - 2\)

\(2x - 3(\frac{1}{2}x - 2) = 5 \Rightarrow 2x - \frac{3}{2}x + 6 = 5 \Rightarrow \frac{1}{2}x = -1 \Rightarrow x = -2\).

\(y = \frac{1}{2}(-2) - 2 = -3\). Rešitev: \((-2, -3)\).

Tip 10: Sistemi neenačb

\((x+2)^2 \leq x^2 + 8\), \(1 - 3x < 5\)

Kako prepoznaš: dve neenačbi, "rešite sistem neenačb".

Postopek:

  1. Reši vsako neenačbo posebej.
  2. Rešitve zapiši kot intervale.
  3. Presek intervalov je rešitev sistema.
  4. Ponazori na številski premici.

Primer: \((x+2)^2 \leq x^2 + 8\), \(1 - 3x < 5\)

Prva: \(x^2 + 4x + 4 \leq x^2 + 8 \Rightarrow 4x \leq 4 \Rightarrow x \leq 1\).

Druga: \(-3x < 4 \Rightarrow x > -\dfrac{4}{3}\).

Rešitev: \(x \in \left(-\dfrac{4}{3}, 1\right]\).

Tip 11: Besedilne naloge (ulomki, starost, razmerja)

Zapiši enačbe iz besedila

Kako prepoznaš: opis situacije, "izračunajte …".

Postopek:

  1. Določi neznanke (npr. \(x\) = števec, \(y\) = imenovalec).
  2. Zapiši enačbe iz besedila.
  3. Reši sistem.
  4. Preveri smiselnost rešitve.

Primer: Števec ulomka je za 1 večji od imenovalca. Če števec pomnožimo z 2, imenovalec pa povečamo za 12, dobimo \(\dfrac{3}{2}\).

\(x = y + 1\), \(\dfrac{2x}{y+12} = \dfrac{3}{2} \Rightarrow 4(y+1) = 3y + 36 \Rightarrow y = 32\), \(x = 33\). Ulomek: \(\dfrac{33}{32}\).

Tip 12: Dokazovanje (enakosti, ničle)

Preoblikuj eno stran v drugo

Kako prepoznaš: "dokažite", "pokažite".

Postopek:

  1. Preberi, kaj je treba dokazati.
  2. Začni z eno stranjo enakosti in jo preoblikuj v drugo.
  3. Uporabi formule (razstavljanje, razširjanje, potence).
  4. Vsak korak mora biti ekvivalenten prejšnjemu.
  5. Na koncu zapiši: "S tem je enakost dokazana."

Primer: Dokaži, da je \(x = -1\) ničla \(p(x) = x^3 + 3x^2 + 3x + 1\).

\(p(-1) = -1 + 3 - 3 + 1 = 0\). Torej je ničla. \(p(x) = (x+1)^3\) → trojna ničla.

3. Pogoste napake

  • Pozabiš zapisati pogoje pri ulomkih in logaritmih.
  • Pri logaritemskih enačbah ne preveriš, ali rešitve ustrezajo pogojem.
  • Pri eksponentnih enačbah ne izpostaviš skupnega faktorja (npr. \(3^x\)).
  • Napačno razstavljaš: \(a^2 + b^2 \neq (a+b)^2\).
  • Pozabiš na dvojno ničlo pri polinomih (npr. \((x-2)^2\)).
  • Pri kvadratni enačbi z \(D < 0\) pozabiš, da so rešitve kompleksne.
  • Pri besedilnih nalogah ne preveriš smiselnosti (npr. stranice trikotnika morajo biti pozitivne).

4. Študijski vodič — hitri pregled

📋 Kaj moraš znati na pamet

  • Pravila za potence (5 osnovnih).
  • Razstavljanje: razlika kvadratov, vsota/diferenca kubov, kvadrat/kub binoma.
  • Kvadratna enačba: \(D = b^2 - 4ac\), \(x_{1,2} = \dfrac{-b \pm \sqrt{D}}{2a}\), Vietovo.
  • Logaritmi: \(\log(xy) = \log x + \log y\), \(\log(x/y) = \log x - \log y\), \(\log x^n = n \log x\).
  • Eksponentne: ista osnova → eksponenti enaki; \(a^{2x}\) in \(a^x\) → substitucija \(t = a^x\).
  • Polinomi: ničla \(p(x_0) = 0\), ostanek \(p(a)\).

🎯 Kako pristopiti k nalogi

  1. Preberi nalogo in prepoznaj tip: poenostavljanje, razstavljanje, enačba, neenačba, polinom, sistem?
  2. Za razstavljanje: skupni faktor → razlika kvadratov → kub → tričlenik → grupiranje.
  3. Za enačbe: prepoznaj tip (linearna, kvadratna, eksponentna, logaritemska).
  4. Za neenačbe: reši vsako posebej, presek intervalov.
  5. Za polinome: poskusi \(x = 1, -1, 2, -2\), Hornerjev algoritem.
  6. Za besedilne: zapiši enačbe iz besedila, reši, preveri smiselnost.

⏱️ Časovni načrt za en večer

  • 60 min: Tipi 1–6 (poenostavljanje, razstavljanje, ulomki, kvadratne, eksponentne, logaritemske).
  • 45 min: Tipi 7–12 (polinomi, ostanek, sistemi, neenačbe, besedilne, dokazovanje).
  • 30 min: Ponovi pogoste napake in študijski vodič.
