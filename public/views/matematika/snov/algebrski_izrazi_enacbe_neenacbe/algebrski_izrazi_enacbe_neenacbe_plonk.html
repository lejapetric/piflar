Algebrski izrazi, enačbe in neenačbe

Cela razlaga

1Potenciranje izrazov

\((a \pm b)^2 = a^2 \pm 2ab + b^2\)
kvadrat dvočlenika
\((x - 3)^2 = x^2 - 6x + 9\)
\((a \pm b)^3 = a^3 \pm 3a^2 b + 3ab^2 \pm b^3\)
kub dvočlenika
\((x + 1)^3 = x^3 + 3x^2 + 3x + 1\)
\((a + b + c)^2 = a^2 + b^2 + c^2 + 2ab + 2ac + 2bc\)
kvadrat tročlenika
\((x + y + 1)^2\)

2Razstavljanje

\(a^2 - b^2 = (a - b)(a + b)\)
razlika kvadratov
\(x^2 - 9 = (x - 3)(x + 3)\)
\(a^3 \pm b^3 = (a \pm b)(a^2 \mp ab + b^2)\)
vsota, razlika kubov
\(x^3 - 8 = (x - 2)(x^2 + 2x + 4)\)
\(x^2 + (a + b)x + ab = (x + a)(x + b)\)
Vietovo pravilo
\(x^2 - 5x + 6 = (x - 2)(x - 3)\)
izpostavljanje, združevanje
najprej izpostavi skupni faktor
\(ax + ay + bx + by = (a + b)(x + y)\)

3Ulomki

okrajšaj šele po razstavljanju
krajšamo faktorje, ne členov
\(\frac{x^2 - 4}{x + 2} = x - 2\), \(x \ne -2\)
skupni imenovalec = \(v\) imenovalcev
seštevanje
\(\frac{1}{x} + \frac{1}{x+1} = \frac{2x + 1}{x(x+1)}\)

4Enačbe

\(ax = b\)
linearna: \(x = \frac{b}{a}\) za \(a \ne 0\)
\(a = 0, b = 0\): vsak \(x\); \(a = 0, b \ne 0\): ni rešitve
\(A \cdot B = 0 \iff A = 0 \vee B = 0\)
razcepna enačba
\(x(x - 2)(x + 5) = 0\): \(x \in \{0, 2, -5\}\)
parameter: loči \(a \ne 0\), \(a = 0\)
linearna enačba s parametrom
\((a - 1)x = a^2 - 1\): \(x = a + 1\) za \(a \ne 1\)

5Neenačbe

množenje z negativnim obrne znak
linearna neenačba
\(-2x < 6\): \(x > -3\)
rešitev zapiši kot interval
na številski premici
\(3x - 1 \ge 5\): \(x \in [2, \infty)\)

!Pazi

  • Pri neenačbi z negativnim številom obrni neenačaj.
  • Pri ulomkih zapiši pogoj: imenovalec \(\ne 0\).
