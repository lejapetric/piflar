🔀 11. Zaporedja in vrste

Aritmetično in geometrijsko zaporedje

📖 Aritmetično zaporedje

aₙ = a₁ + (n-1)d

Sₙ = n/2 · (a₁ + aₙ) = n/2 · (2a₁ + (n-1)d)

d = razlika, Sₙ = vsota prvih n členov

📖 Geometrijsko zaporedje

aₙ = a₁ · qⁿ⁻¹

Sₙ = a₁ · (qⁿ - 1) / (q - 1)

Neskončna vsota: S = a₁ / (1 - q), |q| < 1

q = količnik
