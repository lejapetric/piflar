Cela razlaga

1Krožnica

\((x - p)^2 + (y - q)^2 = r^2\)
središče \(S(p, q)\), polmer \(r\)
\(x^2 + y^2 - 4x + 2y = 4\): \(S(2, -1), r = 3\)
dopolni do popolnega kvadrata
iz splošne oblike
\(x^2 - 4x = (x - 2)^2 - 4\)

2Elipsa

\(\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\)
polosi \(a, b\)
\(\frac{x^2}{25} + \frac{y^2}{9} = 1\): \(a = 5, b = 3\)
\(e^2 = a^2 - b^2\)
gorišči \(F(\pm e, 0)\) za \(a > b\)
\(e = 4\): \(F(\pm 4, 0)\)
\(\varepsilon = \frac{e}{a}\)
numerična ekscentričnost (\(< 1\))
\(\varepsilon = 0{,}8\)
\(\frac{(x - p)^2}{a^2} + \frac{(y - q)^2}{b^2} = 1\)
premaknjena
središče \((p, q)\)

3Hiperbola

\(\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1\)
realna os na \(x\)
\(\frac{x^2}{16} - \frac{y^2}{9} = 1\)
\(e^2 = a^2 + b^2\)
gorišči
\(e = 5\): \(F(\pm 5, 0)\)
\(y = \pm\frac{b}{a} x\)
asimptoti
\(y = \pm\frac34 x\)

4Parabola

\(y^2 = 2px\)
gorišče \(F\left(\frac{p}{2}, 0\right)\), vodnica \(x = -\frac{p}{2}\)
\(y^2 = 8x\): \(F(2, 0)\)
\(x^2 = 2py\)
odprta navzgor
\(x^2 = 4y\): \(F(0, 1)\)

5Presečišča

vstavi premico v stožnico
\(D\) kvadratne enačbe: 2, 1 (tangenta), 0
\(x^2 + y^2 = 2,\ y = x\): \((\pm 1, \pm 1)\)

!Pazi

  • Elipsa: \(e^2 = a^2 - b^2\); hiperbola: \(e^2 = a^2 + b^2\).
