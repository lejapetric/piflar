✏️ 4. Algebra

Algebrski izrazi, enačbe in neenačbe

📖 Formule za okrajšano množenje

(a + b)² = a² + 2ab + b²
(a - b)² = a² - 2ab + b²
a² - b² = (a - b)(a + b)
(a + b)³ = a³ + 3a²b + 3ab² + b³
(a - b)³ = a³ - 3a²b + 3ab² - b³
a³ + b³ = (a + b)(a² - ab + b²)
a³ - b³ = (a - b)(a² + ab + b²)

📊 Kvadratna enačba

ax² + bx + c = 0

x₁,₂ = (-b ± √(b² - 4ac)) / 2a

Diskriminanta: D = b² - 4ac

  • D > 0 → dve realni rešitvi
  • D = 0 → ena dvojna rešitev
  • D < 0 → ni realnih rešitev

📈 Linearne in kvadratne neenačbe

Linearna neenačba: ax + b > 0

Ko množimo/delimo z negativnim številom, se znak obrne.

Kvadratna neenačba: x² - 5x + 6 > 0

Rešitev: x ∈ (-∞, 2) ∪ (3, ∞)
