📊 15. Verjetnostni račun

Klasična verjetnost, pogojna verjetnost in Bernoullijevo zaporedje

📖 Osnovni pojmi

  • Poskus: Postopek z več možnimi izidi (npr. met kocke)
  • Izid: En sam rezultat poskusa
  • Dogodek: Množica izidov, ki nas zanimajo
  • Prostor izidov (Ω): Množica vseh možnih izidov

📝 Osnovne formule

Klasična verjetnost
P(A) = |A|/|Ω|
Nasprotni dogodek
P(¬A) = 1 - P(A)
Unija
P(A∪B) = P(A)+P(B)-P(A∩B)
Pogojna verjetnost
P(A|B) = P(A∩B)/P(B)
Neodvisni dogodki
P(A∩B) = P(A)·P(B)

📊 Bernoullijevo zaporedje

P(X = k) = C(n,k) · pᵏ · (1-p)ⁿ⁻ᵏ
  • Pričakovana vrednost: E(X) = n·p
  • Standardni odklon: σ = √(n·p·(1-p))

📝 Primeri

Primer 1: Vržemo dve kocki. Verjetnost vsote 7?

|Ω| = 36, ugodnih = 6 → P = 6/36 = 1/6

Primer 2: Kovanec vržemo 5-krat. Verjetnost grba natanko 3-krat?

P(X=3) = C(5,3)·(1/2)³·(1/2)² = 10/32 = 5/16

Primer 3: Totalna verjetnost

P(A) = Σ P(A|Bᵢ)·P(Bᵢ)

📈 Bayesova formula

P(Bₖ|A) = P(A|Bₖ)·P(Bₖ) / Σ P(A|Bᵢ)·P(Bᵢ)
