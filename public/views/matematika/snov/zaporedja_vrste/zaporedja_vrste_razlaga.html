Zaporedja

Vse o zaporedjih za maturo: aritmetično in geometrijsko zaporedje, splošni člen, vsote, limite, konvergenca in vrste. Vsak tip naloge ima postopek po korakih.

1. Teorija — formule in pravila

Kar moraš znati na pamet, preden se lotiš nalog.

Osnovni pojmi

  • Zaporedje je funkcija \(a: \mathbb{N} \to \mathbb{R}\), \(a_n\) je \(n\)-ti člen.
  • Splošni člen \(a_n\) — formula za \(n\)-ti člen.
  • Rekurzivna formula — \(a_{n+1}\) izražen z \(a_n\).
  • Naraščajoče: \(a_{n+1} > a_n\) za vsak \(n\).
  • Padajoče: \(a_{n+1} < a_n\) za vsak \(n\).
  • Omejeno: obstaja \(M\), da je \(|a_n| \leq M\) za vsak \(n\).

Aritmetično zaporedje

  • Definicija: \(a_{n+1} - a_n = d\) (konstantna diferenca)
  • Splošni člen: \(a_n = a_1 + (n-1) d\)
  • Vsota prvih \(n\) členov: \(S_n = \dfrac{n}{2}(a_1 + a_n) = \dfrac{n}{2}(2a_1 + (n-1)d)\)
  • Lastnost: \(a_n = \dfrac{a_{n-1} + a_{n+1}}{2}\) (aritmetična sredina)
  • Naraščajoče: \(d > 0\); padajoče: \(d < 0\); konstantno: \(d = 0\)

Geometrijsko zaporedje

  • Definicija: \(\dfrac{a_{n+1}}{a_n} = q\) (konstanten količnik)
  • Splošni člen: \(a_n = a_1 \cdot q^{n-1}\)
  • Vsota prvih \(n\) členov: \(S_n = a_1 \cdot \dfrac{q^n - 1}{q - 1}\) (za \(q \neq 1\))
  • Vsota neskončne vrste (za \(|q| < 1\)): \(S_\infty = \dfrac{a_1}{1 - q}\)
  • Lastnost: \(a_n^2 = a_{n-1} \cdot a_{n+1}\) (geometrijska sredina)
  • Naraščajoče: \(a_1 > 0, q > 1\) ali \(a_1 < 0, 0 < q < 1\)

Limita zaporedja

  • \(\lim_{n \to \infty} a_n = L\) — členi se približujejo \(L\).
  • Konvergentno: limita obstaja in je končna.
  • Divergentno: limita ne obstaja ali je \(\pm\infty\).
  • \(\lim_{n \to \infty} \dfrac{1}{n} = 0\), \(\lim_{n \to \infty} c = c\), \(\lim_{n \to \infty} q^n = 0\) za \(|q| < 1\)
  • Pravila: limita vsote = vsota limit, limita produkta = produkt limit ...

2. Tipi nalog — postopki po korakih

Za vsak tip: kako ga prepoznaš, kako ga rešiš, primer.

Tip 1: Določitev členov aritmetičnega zaporedja

Kako prepoznaš: "Prvi člen je ..., diferenca je ...", "zapišite prvih nekaj členov".

Postopek:

  1. Zapiši \(a_1\) in \(d\).
  2. Uporabi formulo \(a_n = a_1 + (n-1)d\).
  3. Za vsak \(n\) izračunaj \(a_n\).
$$\text{Primer: } a_1 = 2, \quad d = 3$$

1. \(a_2 = 2 + 3 = 5\). 2. \(a_3 = 2 + 6 = 8\). 3. \(a_4 = 2 + 9 = 11\). 4. Splošni člen: \(a_n = 3n - 1\).

Tip 2: Iskanje \(a_1\) in \(d\) iz dveh znanih členov

Kako prepoznaš: "Peti člen je ..., osmi člen je ...", "izračunajte \(a_1\) in \(d\)".

Postopek:

  1. Zapiši dve enačbi: \(a_m = a_1 + (m-1)d\), \(a_n = a_1 + (n-1)d\).
  2. Odštej enačbi: \(a_n - a_m = (n-m)d\).
  3. Izračunaj \(d = \dfrac{a_n - a_m}{n - m}\).
  4. Vstavi \(d\) v eno od enačb in izračunaj \(a_1\).
$$\text{Primer: } a_4 = 17, \quad a_5 + a_7 = 50$$

1. \(a_4 = a_1 + 3d = 17\). 2. \(a_5 + a_7 = 2a_1 + 10d = 50\). 3. Iz prve: \(a_1 = 17 - 3d\). 4. Vstavi v drugo: \(2(17 - 3d) + 10d = 50 \Rightarrow 34 + 4d = 50 \Rightarrow d = 4\). 5. \(a_1 = 17 - 12 = 5\).

Tip 3: Vsota prvih \(n\) členov aritmetičnega zaporedja

Kako prepoznaš: "Izračunajte vsoto prvih 100 členov".

Postopek:

  1. Zapiši \(a_1\) in \(d\).
  2. Uporabi \(S_n = \dfrac{n}{2}(2a_1 + (n-1)d)\).
  3. Izračunaj.
$$\text{Primer: } a_1 = 2, d = 3, n = 100$$

1. \(S_{100} = \dfrac{100}{2}(2 \cdot 2 + 99 \cdot 3) = 50(4 + 297) = 50 \cdot 301 = 15050\).

Tip 4: Določitev \(a_1\) in \(q\) iz dveh znanih členov (geometrijsko)

Kako prepoznaš: "Tretji člen je ..., šesti člen je ...".

Postopek:

  1. Zapiši: \(a_m = a_1 q^{m-1}\), \(a_n = a_1 q^{n-1}\).
  2. Deli enačbi: \(\dfrac{a_n}{a_m} = q^{n-m}\).
  3. Izračunaj \(q = \sqrt[n-m]{\dfrac{a_n}{a_m}}\) (pazi na predznak!).
  4. Vstavi \(q\) v eno od enačb in izračunaj \(a_1\).
$$\text{Primer: } a_3 = 40, \quad a_6 = 320$$

1. \(\dfrac{a_6}{a_3} = q^3 = \dfrac{320}{40} = 8 \Rightarrow q = 2\). 2. \(a_3 = a_1 \cdot 4 = 40 \Rightarrow a_1 = 10\).

Tip 5: Vsota prvih \(n\) členov geometrijskega zaporedja

Kako prepoznaš: "Vsota prvih 12 členov je ...".

Postopek:

  1. Zapiši \(a_1\) in \(q\).
  2. Uporabi \(S_n = a_1 \cdot \dfrac{q^n - 1}{q - 1}\).
  3. Če je \(|q| < 1\), lahko izračunaš tudi \(S_\infty = \dfrac{a_1}{1 - q}\).
$$\text{Primer: } a_1 = 4, q = 2, n = 12$$

1. \(S_{12} = 4 \cdot \dfrac{2^{12} - 1}{2 - 1} = 4 \cdot (4096 - 1) = 4 \cdot 4095 = 16380\).

Tip 6: Vsota neskončne geometrijske vrste

Kako prepoznaš: "Izračunajte vsoto vrste \(a_1 + a_2 + a_3 + \ldots\)".

Postopek:

  1. Preveri, da je \(|q| < 1\) (sicer vrsta divergira).
  2. Uporabi \(S_\infty = \dfrac{a_1}{1 - q}\).
$$\text{Primer: } 2 + \frac{2}{3} + \frac{2}{9} + \ldots$$

1. \(a_1 = 2, q = \dfrac{1}{3}\). 2. \(|q| < 1\). 3. \(S_\infty = \dfrac{2}{1 - \frac{1}{3}} = \dfrac{2}{\frac{2}{3}} = 3\).

Tip 7: Preverjanje, ali je zaporedje aritmetično/geometrijsko

Kako prepoznaš: "Ali je zaporedje aritmetično/geometrijsko?".

Postopek:

  1. Aritmetično: preveri, ali je \(a_{n+1} - a_n\) konstanten za vse \(n\).
  2. Geometrijsko: preveri, ali je \(\dfrac{a_{n+1}}{a_n}\) konstanten za vse \(n\).
  3. Če nobeno, zaporedje ni ne aritmetično ne geometrijsko.
$$\text{Primer: } a_n = 20 - 3n$$

1. \(a_{n+1} - a_n = (20 - 3(n+1)) - (20 - 3n) = -3\). 2. Konstantno → aritmetično z \(d = -3\). 3. \(a_1 = 17\).

Tip 8: Iskanje \(x\), da so tri števila členi zaporedja

Kako prepoznaš: "Za katere \(x\) so \(x^2 - 7, 1 - x, 2\) zaporedni členi ...".

Postopek:

  1. Aritmetično: \(b = \dfrac{a + c}{2}\) (srednji člen je povprečje).
  2. Geometrijsko: \(b^2 = a \cdot c\) (kvadrat srednjega je produkt).
  3. Reši enačbo za \(x\).
$$\text{Primer: } 11, x, 7 \text{ so členi aritmetičnega zaporedja}$$

1. \(x = \dfrac{11 + 7}{2} = 9\).

$$\text{Primer: } x^2 - 7, 1 - x, 2 \text{ so členi geometrijskega zaporedja}$$

1. \((1-x)^2 = (x^2 - 7) \cdot 2\). 2. \(1 - 2x + x^2 = 2x^2 - 14\). 3. \(x^2 + 2x - 15 = 0 \Rightarrow x_1 = 3, x_2 = -5\). 4. Preveri, kateri \(x\) daje padajoče zaporedje (če zahteva).

Tip 9: Limita zaporedja

Kako prepoznaš: "Izračunajte \(\lim_{n \to \infty} a_n\)".

Postopek:

  1. Če je \(a_n\) racionalna funkcija v \(n\): deli števec in imenovalec z najvišjo potenco \(n\).
  2. Uporabi \(\lim_{n \to \infty} \dfrac{1}{n^k} = 0\).
  3. Če je \(a_n = q^n\): \(\lim = 0\), če \(|q| < 1\); \(\lim = \infty\), če \(q > 1\); \(\lim\) ne obstaja, če \(q \leq -1\).
$$\text{Primer: } a_n = \frac{3n - 1}{2n + 5}$$

1. Deli z \(n\): \(\dfrac{3 - \frac{1}{n}}{2 + \frac{5}{n}}\). 2. \(\lim_{n \to \infty} = \dfrac{3 - 0}{2 + 0} = \dfrac{3}{2}\).

$$\text{Primer: } a_n = \frac{3n}{2n+1}$$

1. Deli z \(n\): \(\dfrac{3}{2 + \frac{1}{n}}\). 2. Limita: \(\dfrac{3}{2}\). 3. Zaporedje je omejeno (med \(1\) in \(\dfrac{3}{2}\)).

Tip 10: Dokazovanje, da je zaporedje naraščajoče/padajoče

Kako prepoznaš: "Dokažite, da je zaporedje naraščajoče".

Postopek:

  1. Izračunaj \(a_{n+1} - a_n\).
  2. Pokaži, da je ta razlika \(> 0\) (naraščajoče) ali \(< 0\) (padajoče) za vsak \(n\).
  3. Alternativa: izračunaj \(\dfrac{a_{n+1}}{a_n}\) in primerjaj z 1 (za pozitivne člene).
$$\text{Primer: } a_n = 2^n + 1$$

1. \(a_{n+1} - a_n = (2^{n+1} + 1) - (2^n + 1) = 2^n > 0\). 2. Zaporedje je naraščajoče.

Tip 11: Besedilne naloge (vrinjeni členi, geometrijski kontekst)

Kako prepoznaš: "Med števili \(a\) in \(b\) vrinite ...", "stranice trikotnika tvorijo ...".

Postopek:

  1. Preberi, kaj tvori zaporedje (stranice, dolžine, količine ...).
  2. Zapiši enačbe iz pogojev.
  3. Reši sistem za \(a_1\) in \(d\) (ali \(q\)).
  4. Preveri, da rešitve ustrezajo pogojem (npr. stranice trikotnika morajo biti pozitivne).
$$\text{Primer: Med 7 in 448 vrinite 5 števil, da dobite aritmetično zaporedje.}$$

1. \(a_1 = 7, a_7 = 448\). 2. \(a_7 = 7 + 6d = 448 \Rightarrow 6d = 441 \Rightarrow d = 73{,}5\). 3. Vrinjeni členi: \(80{,}5, 154, 227{,}5, 301, 374{,}5\).

$$\text{Primer: Stranice trikotnika tvorijo aritmetično zaporedje z diferenco 3, obseg je 30.}$$

1. Stranice: \(a, a+3, a+6\). 2. Obseg: \(a + (a+3) + (a+6) = 30 \Rightarrow 3a + 9 = 30 \Rightarrow a = 7\). 3. Stranice: \(7, 10, 13\).

3. Pogoste napake

  • Zamenjaš \(a_n\) (splošni člen) s \(S_n\) (vsota).
  • Pri geometrijskem zaporedju pozabiš, da je \(q\) lahko negativen (zaporedje izmenično).
  • Pri \(S_n = a_1 \dfrac{q^n - 1}{q - 1}\) uporabiš napačen predznak ali zamenjaš \(q^n - 1\) z \(1 - q^n\).
  • Pri neskončni vrsti pozabiš preveriti \(|q| < 1\).
  • Pri limiti \(\dfrac{\infty}{\infty}\) pozabiš deliti z najvišjo potenco.
  • Pri iskanju \(q\) iz \(q^{n-m}\) pozabiš, da ima dve rešitvi (če je \(n-m\) sod).
  • Pri besedilnih nalogah ne preveriš smiselnosti (npr. stranice trikotnika morajo biti pozitivne).
