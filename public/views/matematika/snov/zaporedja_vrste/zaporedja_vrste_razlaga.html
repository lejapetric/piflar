Zaporedja in vrste

Vse o zaporedjih in vrstah za maturo: aritmetično in geometrijsko zaporedje, splošni člen, vsote prvih \(n\) členov, limita zaporedja, konvergenca geometrijske vrste, obrestni račun in anuitete.

45+Primerov
~60 minBranja

📋 Formule na maturi — osnovna raven

Na maturitetnem listu s formulami so za zaporedja in vrste relevantne naslednje formule:

  • Aritmetično zaporedje — splošni člen: \(a_n = a_1 + (n-1)d\)
  • Aritmetično zaporedje — vsota: \(S_n = \dfrac{n}{2}(a_1 + a_n) = \dfrac{n}{2}(2a_1 + (n-1)d)\)
  • Geometrijsko zaporedje — splošni člen: \(a_n = a_1 \cdot q^{n-1}\)
  • Geometrijsko zaporedje — vsota: \(S_n = a_1 \cdot \dfrac{q^n - 1}{q - 1}\), \(q \neq 1\)
  • Neskončna geometrijska vrsta: \(S_\infty = \dfrac{a_1}{1-q}\), \(|q| < 1\)
  • Limiti: \(\lim_{n\to\infty}\left(1+\dfrac{1}{n}\right)^n = e\), \(\lim_{x\to 0}\dfrac{\sin x}{x} = 1\)

1. Teorija — formule in pravila

Kar moraš znati na pamet, preden se lotiš nalog.

Osnovni pojmi

Zaporedje

\(a_1, a_2, a_3, \ldots, a_n, \ldots\)

Funkcija \(a: \mathbb{N} \to \mathbb{R}\). \(a_n\) je \(n\)-ti člen.

Splošni člen

\(a_n = f(n)\)

Formula, ki omogoča izračun poljubnega člena.

Rekurzivna formula

\(a_{n+1}\) izražen z \(a_n\)

Vsak naslednji člen iz prejšnjega.

Naraščajoče

\(a_{n+1} > a_n\) za vsak \(n\)

Padajoče

\(a_{n+1} < a_n\) za vsak \(n\)

Omejeno

obstaja \(M\), da je \(|a_n| \leq M\)

Konvergentno

limita obstaja in je končna

Divergentno

limita ne obstaja ali je \(\pm\infty\)

Aritmetično zaporedje

Definicija

\(a_{n+1} - a_n = d\)

Konstantna diferenca \(d\).

Splošni člen

\(a_n = a_1 + (n-1)d\)

Vsota prvih \(n\) členov

\(S_n = \dfrac{n}{2}(a_1 + a_n) = \dfrac{n}{2}(2a_1 + (n-1)d)\)

Aritmetična sredina

\(a_n = \dfrac{a_{n-1} + a_{n+1}}{2}\)

Srednji člen je povprečje sosednjih.

Zveza med dvema členoma

\(a_n - a_m = (n-m)d\)

Naraščanje/padanje

\(d > 0\) narašča, \(d < 0\) pada, \(d = 0\) konst.

Geometrijsko zaporedje

Definicija

\(\dfrac{a_{n+1}}{a_n} = q\)

Konstanten kvocient \(q\).

Splošni člen

\(a_n = a_1 \cdot q^{n-1}\)

Vsota prvih \(n\) členov

\(S_n = a_1 \cdot \dfrac{q^n - 1}{q - 1}\), \(q \neq 1\)

Za \(q = 1\): \(S_n = n a_1\).

Geometrijska sredina

\(a_n^2 = a_{n-1} \cdot a_{n+1}\)

Zveza med dvema členoma

\(\dfrac{a_n}{a_m} = q^{n-m}\)

Neskončna geometrijska vrsta

\(S_\infty = \dfrac{a_1}{1 - q}\), če \(|q| < 1\)

Če \(|q| \geq 1\), vrsta divergira.

Limita zaporedja

Definicija

\(\lim_{n \to \infty} a_n = L\)

Členi se približujejo \(L\).

Osnovne limite

\(\lim_{n \to \infty} \dfrac{1}{n} = 0\), \(\lim_{n \to \infty} c = c\)

Potence

\(\lim_{n \to \infty} q^n = 0\), če \(|q| < 1\)

Racionalne funkcije

deli z najvišjo potenco \(n\)

Pravila

\(\lim(a_n \pm b_n) = \lim a_n \pm \lim b_n\)

Enako za produkt, kvocient, potenco.

Znana limita

\(\lim_{n \to \infty} \left(1 + \dfrac{1}{n}\right)^n = e\)

Obrestni račun

Navadno obrestovanje

\(G_n = G_0 \cdot (1 + n \cdot p)\)

Obresti se ne pripisujejo glavnici.

Obrestno obrestovanje

\(G_n = G_0 \cdot (1 + p)^n\)

Obresti se pripisujejo in obrestujejo naprej (geometrijsko zaporedje).

Anuiteta

\(a = G_0 \cdot \dfrac{p (1+p)^n}{(1+p)^n - 1}\)

Enak obrok za odplačilo posojila.

Konformna mera

\(p_k = \sqrt[m]{1 + p} - 1\)

Za pretvorbo med različnimi obdobji.

2. Tipi nalog — postopki po korakih

Za vsak tip: kako ga prepoznaš, kako ga rešiš, primer.

Tip 1: Določitev členov aritmetičnega zaporedja

\(a_n = a_1 + (n-1)d\)

Kako prepoznaš: "prvi člen je …, diferenca je …", "zapišite prvih nekaj členov".

Postopek:

  1. Zapiši \(a_1\) in \(d\).
  2. Uporabi \(a_n = a_1 + (n-1)d\).
  3. Za vsak \(n\) izračunaj \(a_n\).

Primer: \(a_1 = 2, d = 3\)

\(a_2 = 5\), \(a_3 = 8\), \(a_4 = 11\). Splošni člen: \(a_n = 3n - 1\).

Tip 2: Iskanje \(a_1\) in \(d\) iz dveh znanih členov

\(d = \dfrac{a_n - a_m}{n - m}\)

Kako prepoznaš: "peti člen je …, osmi člen je …".

Postopek:

  1. Zapiši dve enačbi: \(a_m = a_1 + (m-1)d\), \(a_n = a_1 + (n-1)d\).
  2. Odštej: \(a_n - a_m = (n-m)d\).
  3. Izračunaj \(d = \dfrac{a_n - a_m}{n-m}\).
  4. Vstavi \(d\) v eno enačbo in izračunaj \(a_1\).

Primer: \(a_4 = 17\), \(a_5 + a_7 = 50\)

\(a_4 = a_1 + 3d = 17\). \(a_5 + a_7 = 2a_1 + 10d = 50\). Iz prve: \(a_1 = 17 - 3d\).

\(2(17-3d) + 10d = 50 \Rightarrow 34 + 4d = 50 \Rightarrow d = 4\), \(a_1 = 5\).

Tip 3: Vsota prvih \(n\) členov aritmetičnega zaporedja

\(S_n = \dfrac{n}{2}(2a_1 + (n-1)d)\)

Kako prepoznaš: "izračunajte vsoto prvih 100 členov".

Postopek:

  1. Zapiši \(a_1\) in \(d\).
  2. Uporabi formulo \(S_n = \dfrac{n}{2}(2a_1 + (n-1)d)\).
  3. Izračunaj.

Primer: \(a_1 = 2, d = 3, n = 100\)

\(S_{100} = 50(4 + 297) = 50 \cdot 301 = 15050\).

Tip 4: Določitev \(a_1\) in \(q\) pri geometrijskem zaporedju

\(q = \sqrt[n-m]{\dfrac{a_n}{a_m}}\)

Kako prepoznaš: "tretji člen je …, šesti člen je …".

Postopek:

  1. Zapiši \(a_m = a_1 q^{m-1}\), \(a_n = a_1 q^{n-1}\).
  2. Deli: \(\dfrac{a_n}{a_m} = q^{n-m}\).
  3. Izračunaj \(q = \sqrt[n-m]{\dfrac{a_n}{a_m}}\) (pazi na predznak!).
  4. Vstavi \(q\) in izračunaj \(a_1\).

Primer: \(a_3 = 40\), \(a_6 = 320\)

\(\dfrac{a_6}{a_3} = q^3 = 8 \Rightarrow q = 2\). \(a_3 = a_1 \cdot 4 = 40 \Rightarrow a_1 = 10\).

Tip 5: Vsota prvih \(n\) členov geometrijskega zaporedja

\(S_n = a_1 \cdot \dfrac{q^n - 1}{q - 1}\)

Kako prepoznaš: "vsota prvih 12 členov".

Postopek:

  1. Zapiši \(a_1\) in \(q\).
  2. Uporabi formulo \(S_n = a_1 \dfrac{q^n - 1}{q - 1}\).
  3. Če \(|q| < 1\), lahko izračunaš tudi \(S_\infty = \dfrac{a_1}{1-q}\).

Primer: \(a_1 = 4, q = 2, n = 12\)

\(S_{12} = 4 \cdot \dfrac{2^{12} - 1}{2-1} = 4(4096 - 1) = 16380\).

Tip 6: Vsota neskončne geometrijske vrste

\(S_\infty = \dfrac{a_1}{1-q}\) (|q| < 1)

Kako prepoznaš: "izračunajte vsoto vrste \(a_1 + a_2 + a_3 + \ldots\)".

Postopek:

  1. Preveri \(|q| < 1\) (sicer vrsta divergira).
  2. Uporabi \(S_\infty = \dfrac{a_1}{1-q}\).

Primer: \(2 + \dfrac{2}{3} + \dfrac{2}{9} + \ldots\)

\(a_1 = 2, q = \dfrac{1}{3}\). \(|q| < 1\). \(S_\infty = \dfrac{2}{1 - \frac{1}{3}} = \dfrac{2}{\frac{2}{3}} = 3\).

Tip 7: Preverjanje, ali je zaporedje aritmetično/geometrijsko

\(a_{n+1} - a_n\) ali \(\dfrac{a_{n+1}}{a_n}\)

Kako prepoznaš: "ali je zaporedje aritmetično/geometrijsko?".

Postopek:

  1. Aritmetično: preveri, ali je \(a_{n+1} - a_n\) konstanten za vse \(n\).
  2. Geometrijsko: preveri, ali je \(\dfrac{a_{n+1}}{a_n}\) konstanten.
  3. Če nobeno, zaporedje ni ne aritmetično ne geometrijsko.

Primer: \(a_n = 20 - 3n\)

\(a_{n+1} - a_n = -3\). Konstantno → aritmetično z \(d = -3\), \(a_1 = 17\).

Tip 8: Iskanje \(x\), da so tri števila členi zaporedja

\(b = \dfrac{a+c}{2}\) ali \(b^2 = ac\)

Kako prepoznaš: "za katere \(x\) so \(x^2 - 7, 1 - x, 2\) zaporedni členi".

Postopek:

  1. Aritmetično: \(b = \dfrac{a + c}{2}\) (srednji člen je povprečje).
  2. Geometrijsko: \(b^2 = a \cdot c\).
  3. Reši enačbo za \(x\).

Primer: \(11, x, 7\) so členi aritmetičnega zaporedja

\(x = \dfrac{11 + 7}{2} = 9\).

Primer: \(x^2 - 7, 1 - x, 2\) so členi geometrijskega

\((1-x)^2 = (x^2 - 7) \cdot 2 \Rightarrow x^2 + 2x - 15 = 0 \Rightarrow x_1 = 3, x_2 = -5\).

Tip 9: Limita zaporedja

\(\lim_{n \to \infty} a_n\)

Kako prepoznaš: "izračunajte \(\lim_{n \to \infty} a_n\)".

Postopek:

  1. Racionalna funkcija: deli z najvišjo potenco \(n\).
  2. Uporabi \(\lim_{n\to\infty} \dfrac{1}{n^k} = 0\).
  3. Za \(a_n = q^n\): \(|q| < 1 \Rightarrow 0\), \(q > 1 \Rightarrow \infty\), \(q \leq -1\): limita ne obstaja.

Primer: \(a_n = \dfrac{3n - 1}{2n + 5}\)

Deli z \(n\): \(\dfrac{3 - \frac{1}{n}}{2 + \frac{5}{n}} \to \dfrac{3}{2}\).

Tip 10: Dokazovanje naraščanja/padanja

\(a_{n+1} - a_n > 0\) ali \(< 0\)

Kako prepoznaš: "dokažite, da je zaporedje naraščajoče".

Postopek:

  1. Izračunaj \(a_{n+1} - a_n\).
  2. Pokaži, da je ta razlika \(> 0\) (naraščajoče) ali \(< 0\) (padajoče).
  3. Alternativa: \(\dfrac{a_{n+1}}{a_n} > 1\) (naraščajoče) ali \(< 1\) (padajoče).

Primer: \(a_n = 2^n + 1\)

\(a_{n+1} - a_n = 2^n > 0\). Zaporedje je naraščajoče.

Tip 11: Besedilne naloge (vrinjeni členi, obresti, anuitete)

Zapiši enačbe iz besedila

Kako prepoznaš: "med \(a\) in \(b\) vrinite …", "stranice trikotnika tvorijo …", "posojilo".

Postopek:

  1. Preberi, kaj tvori zaporedje.
  2. Zapiši enačbe iz pogojev.
  3. Reši sistem za \(a_1\) in \(d\) (ali \(q\)).
  4. Preveri, da rešitve ustrezajo pogojem.

Primer: Med 7 in 448 vrinite 5 števil, da dobite aritmetično zaporedje

\(a_1 = 7, a_7 = 448\). \(7 + 6d = 448 \Rightarrow 6d = 441 \Rightarrow d = 73{,}5\).

Vrinjeni: 80,5, 154, 227,5, 301, 374,5.

Primer: Stranice trikotnika tvorijo aritmetično zaporedje z \(d=3\), obseg 30

Stranice: \(a, a+3, a+6\). \(3a + 9 = 30 \Rightarrow a = 7\). Stranice: 7, 10, 13.

3. Pogoste napake

  • Zamenjaš \(a_n\) (splošni člen) s \(S_n\) (vsota).
  • Pri geometrijskem zaporedju pozabiš, da je \(q\) lahko negativen (izmenično zaporedje).
  • Pri \(S_n = a_1 \dfrac{q^n - 1}{q-1}\) uporabiš napačen predznak ali zamenjaš \(q^n - 1\) z \(1 - q^n\).
  • Pri neskončni vrsti pozabiš preveriti \(|q| < 1\).
  • Pri limiti \(\infty/\infty\) pozabiš deliti z najvišjo potenco.
  • Pri iskanju \(q\) iz \(q^{n-m}\) pozabiš, da ima dve rešitvi (če je \(n-m\) sod).
  • Pri besedilnih nalogah ne preveriš smiselnosti (npr. stranice pozitivne).

4. Študijski vodič — hitri pregled

📋 Kaj moraš znati na pamet

  • Aritmetično: \(a_n = a_1 + (n-1)d\), \(S_n = \dfrac{n}{2}(a_1 + a_n)\), srednji = povprečje.
  • Geometrijsko: \(a_n = a_1 q^{n-1}\), \(S_n = a_1 \dfrac{q^n - 1}{q-1}\), \(S_\infty = \dfrac{a_1}{1-q}\) za \(|q|<1\).
  • Limite: \(\lim \dfrac{1}{n^k} = 0\), \(\lim q^n = 0\) za \(|q|<1\).
  • Obresti: \(G_n = G_0 (1+p)^n\).
  • Anuiteta: \(a = G_0 \dfrac{p(1+p)^n}{(1+p)^n - 1}\).

🎯 Kako pristopiti k nalogi

  1. Preberi nalogo in prepoznaj tip: aritmetično, geometrijsko, vrsta, limita, obresti?
  2. Za aritmetično: zapiši \(a_1\) in \(d\), uporabi formulo.
  3. Za geometrijsko: zapiši \(a_1\) in \(q\), uporabi formulo.
  4. Za vsoto: preveri, ali je končna ali neskončna.
  5. Za limite: deli z najvišjo potenco, uporabi znane limite.
  6. Za obresti: preveri, ali je navadno ali obrestno obrestovanje.
