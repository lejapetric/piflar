Pravokotni koordinatni sistem v ravnini

Vse o koordinatnem sistemu za maturo: točke v ravnini, razdalja med točkama, razpolovišče daljice, težišče trikotnika, enačbe premic, vzporednost in pravokotnost, razdalja točke do premice, ploščina trikotnika.

📋 Formule na maturi — osnovna raven

Na maturi osnovne ravni list s formulami ne vsebuje koordinatnih formul, zato si jih moraš zapomniti. Spodaj so vse ključne:

  • Razdalja med točkama: \(d(A,B) = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}\)
  • Razpolovišče daljice: \(S\left(\dfrac{x_1+x_2}{2}, \dfrac{y_1+y_2}{2}\right)\)
  • Težišče trikotnika: \(T\left(\dfrac{x_1+x_2+x_3}{3}, \dfrac{y_1+y_2+y_3}{3}\right)\)
  • Enačba premice (eksplicitna): \(y = kx + n\)
  • Smerni koeficient: \(k = \dfrac{y_2 - y_1}{x_2 - x_1}\)
  • Razdalja točke do premice: \(d(T, p) = \dfrac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}\)

1. Teorija — formule in pravila

Kar moraš znati na pamet, preden se lotiš nalog.

Točke v ravnini

Zapis točke

\(A(x_1, y_1)\)

Prva koordinata je abscisa (vodoravna os \(x\)), druga ordinata (navpična os \(y\)).

Razdalja med točkama

\(d(A, B) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\)

Pitagorov izrek v koordinatah.

Razpolovišče daljice

\(S\left(\dfrac{x_1 + x_2}{2}, \dfrac{y_1 + y_2}{2}\right)\)

Aritmetična sredina koordinat.

Težišče trikotnika

\(T\left(\dfrac{x_1+x_2+x_3}{3}, \dfrac{y_1+y_2+y_3}{3}\right)\)

Presečišče težiščnic.

Ploščina trikotnika

\(S = \dfrac{1}{2}|(x_2-x_1)(y_3-y_1) - (x_3-x_1)(y_2-y_1)|\)

Uporabno pri točkah s koordinatami.

Vzporednost vektorjev

\(\dfrac{x_2-x_1}{x_4-x_3} = \dfrac{y_2-y_1}{y_4-y_3}\)

Vektorja \(\overrightarrow{AB}\) in \(\overrightarrow{CD}\) sta kolinearna.

Enačba premice

Eksplicitna oblika

\(y = kx + n\)

\(k\) = smerni koeficient (naklon), \(n\) = začetna vrednost (presečišče z osjo \(y\)).

Implicitna oblika

\(ax + by + c = 0\)

Splošna oblika premice.

Smerni koeficient iz dveh točk

\(k = \dfrac{y_2 - y_1}{x_2 - x_1}\)

Pazi: \(x_1 \neq x_2\) (sicer navpična premica).

Enačba premice skozi točko

\(y - y_1 = k(x - x_1)\)

Z danim \(k\) in točko \(T(x_1, y_1)\).

Presečišče z osjo \(x\)

\(y = 0 \Rightarrow x = -\dfrac{n}{k}\)

Ničla premice.

Presečišče z osjo \(y\)

\(x = 0 \Rightarrow y = n\)

Začetna vrednost.

Vzporednost in pravokotnost

Vzporedni premici

\(k_1 = k_2\)

Enak smerni koeficient.

Pravokotni premici

\(k_1 \cdot k_2 = -1\)

Smerna koeficienta sta nasprotna in obratna.

Kot med premicama

\(\tan\varphi = \left|\dfrac{k_1 - k_2}{1 + k_1 k_2}\right|\)

Kot med premicama z znanima smernicama.

Razdalja točke do premice

\(d(T, p) = \dfrac{|a x_0 + b y_0 + c|}{\sqrt{a^2 + b^2}}\)

Premica \(ax + by + c = 0\), točka \(T(x_0, y_0)\).

2. Tipi nalog — postopki po korakih

Za vsak tip: kako ga prepoznaš, kako ga rešiš, primer.

Tip 1: Razdalja med točkama

\(d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}\)

Kako prepoznaš: "izračunajte dolžino daljice", "razdalja med točkama".

Postopek:

  1. Zapiši koordinate obeh točk.
  2. Vstavi v formulo.
  3. Izračunaj.

Primer: \(A(1, 2)\), \(B(4, 6)\)

\(d = \sqrt{(4-1)^2 + (6-2)^2} = \sqrt{9 + 16} = 5\).

Tip 2: Razpolovišče daljice

\(S\left(\dfrac{x_1+x_2}{2}, \dfrac{y_1+y_2}{2}\right)\)

Kako prepoznaš: "razpolovišče daljice AB".

Postopek:

  1. Seštej abscisi in deli z 2.
  2. Seštej ordinati in deli z 2.

Primer: \(A(1, 2)\), \(B(4, 6)\)

\(S\left(\dfrac{1+4}{2}, \dfrac{2+6}{2}\right) = (2{,}5, 4)\).

Tip 3: Težišče trikotnika

\(T\left(\dfrac{x_1+x_2+x_3}{3}, \dfrac{y_1+y_2+y_3}{3}\right)\)

Kako prepoznaš: "težišče trikotnika z oglišči A, B, C".

Postopek:

  1. Seštej vse tri abscise in deli s 3.
  2. Seštej vse tri ordinate in deli s 3.

Primer: \(A(0,0), B(6,0), C(0,3)\)

\(T\left(\dfrac{6}{3}, \dfrac{3}{3}\right) = (2, 1)\).

Tip 4: Enačba premice skozi dve točki

\(k = \dfrac{y_2 - y_1}{x_2 - x_1}\)

Kako prepoznaš: "zapišite enačbo premice skozi A in B".

Postopek:

  1. Izračunaj smerni koeficient \(k = \dfrac{y_2 - y_1}{x_2 - x_1}\).
  2. Vstavi v eksplicitno obliko \(y = kx + n\).
  3. Vstavi koordinate ene od točk in izračunaj \(n\).

Primer: \(A(1, 1)\), \(B(3, 5)\)

\(k = \dfrac{5-1}{3-1} = 2\). \(1 = 2 \cdot 1 + n \Rightarrow n = -1\). Enačba: \(y = 2x - 1\).

Tip 5: Vzporedna premica skozi točko

\(k_{\text{nova}} = k_{\text{dana}}\)

Kako prepoznaš: "premica, ki je vzporedna dani in gre skozi točko".

Postopek:

  1. Preberi \(k\) iz dane premice.
  2. Vstavi v \(y = kx + n\) in koordinate točke.
  3. Izračunaj \(n\).

Primer: vzporedna premici \(y = 3x + 1\), gre skozi \(A(1, -2)\)

\(k = 3\). \(-2 = 3 \cdot 1 + n \Rightarrow n = -5\). Enačba: \(y = 3x - 5\).

Tip 6: Pravokotna premica skozi točko

\(k_1 \cdot k_2 = -1\)

Kako prepoznaš: "premica, ki je pravokotna na dano".

Postopek:

  1. Preberi \(k_1\) iz dane premice.
  2. Izračunaj \(k_2 = -\dfrac{1}{k_1}\).
  3. Vstavi \(k_2\) in točko v \(y = kx + n\).

Primer: pravokotna na \(y = 2x + 3\) skozi \(A(2, 1)\)

\(k_2 = -\dfrac{1}{2}\). \(1 = -\dfrac{1}{2} \cdot 2 + n \Rightarrow n = 2\). Enačba: \(y = -\dfrac{1}{2}x + 2\).

Tip 7: Presečišče dveh premic

Reši sistem enačb

Kako prepoznaš: "izračunajte presečišče premic".

Postopek:

  1. Zapiši obe enačbi.
  2. Reši sistem (substitucija ali izenačitev \(y\)).
  3. Izračunaj \(x\), nato \(y\).

Primer: \(y = x + 5\), \(y = 2x - 3\)

\(x + 5 = 2x - 3 \Rightarrow x = 8\). \(y = 13\). Presečišče: \((8, 13)\).

Tip 8: Razdalja točke do premice

\(d = \dfrac{|a x_0 + b y_0 + c|}{\sqrt{a^2 + b^2}}\)

Kako prepoznaš: "izračunajte razdaljo točke do premice".

Postopek:

  1. Premico zapiši v implicitni obliki \(ax + by + c = 0\).
  2. Vstavi koordinate točke \((x_0, y_0)\).
  3. Uporabi formulo.

Primer: \(T(0, 0)\), premica \(3x + 4y - 10 = 0\)

\(d = \dfrac{|0 + 0 - 10|}{\sqrt{9 + 16}} = \dfrac{10}{5} = 2\).

Tip 9: Ploščina trikotnika s koordinatami

\(S = \dfrac{1}{2}|(x_2-x_1)(y_3-y_1) - (x_3-x_1)(y_2-y_1)|\)

Kako prepoznaš: tri točke \(A, B, C\) s koordinatami.

Postopek:

  1. Vstavi koordinate v formulo.
  2. Izračunaj absolutno vrednost.
  3. Deli z 2.

Primer: \(A(0, 0)\), \(B(4, 0)\), \(C(1, 3)\)

\(S = \dfrac{1}{2}|(4-0)(3-0) - (1-0)(0-0)| = \dfrac{1}{2}|12| = 6\).

Tip 10: Kot med premicama

\(\tan\varphi = \left|\dfrac{k_1 - k_2}{1 + k_1 k_2}\right|\)

Kako prepoznaš: "izračunajte kot med premicama".

Postopek:

  1. Preberi \(k_1\) in \(k_2\) iz obeh premic.
  2. Vstavi v formulo.
  3. \(\varphi = \arctan(\tan\varphi)\).

Primer: \(y = 3x + 2\), \(y = -x + 2021\)

\(\tan\varphi = \left|\dfrac{3 - (-1)}{1 + 3 \cdot (-1)}\right| = \left|\dfrac{4}{-2}\right| = 2 \Rightarrow \varphi \approx 63{,}43°\).

3. Pogoste napake

  • Zamenjaš absciso in ordinato (vrstni red \((x, y)\)).
  • Pri razdalji pozabiš kvadrat pod korenom.
  • Pri razpolovišču pozabiš deliti z 2.
  • Pri smernem koeficientu zamenjaš \((y_2 - y_1)\) in \((x_2 - x_1)\).
  • Pri pravokotnosti pozabiš \(k_1 k_2 = -1\) namesto \(k_2 = -k_1\).
  • Pri razdalji točke do premice pozabiš absolutno vrednost in imenovalec \(\sqrt{a^2 + b^2}\).
  • Pri ploščini trikotnika pozabiš deliti z 2 ali absolutno vrednost.
  • Pri kotu med premicama pozabiš absolutno vrednost.

4. Študijski vodič — hitri pregled

📋 Kaj moraš znati na pamet

  • Razdalja: \(d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}\).
  • Razpolovišče: \(S\left(\dfrac{x_1+x_2}{2}, \dfrac{y_1+y_2}{2}\right)\).
  • Težišče: \(T\left(\dfrac{x_1+x_2+x_3}{3}, \dfrac{y_1+y_2+y_3}{3}\right)\).
  • Smerni koeficient: \(k = \dfrac{y_2-y_1}{x_2-x_1}\).
  • Vzporednost: \(k_1 = k_2\), pravokotnost: \(k_1 k_2 = -1\).
  • Razdalja točke do premice: \(d = \dfrac{|ax_0 + by_0 + c|}{\sqrt{a^2+b^2}}\).
  • Ploščina trikotnika: \(\dfrac{1}{2}|(x_2-x_1)(y_3-y_1) - (x_3-x_1)(y_2-y_1)|\).

🎯 Kako pristopiti k nalogi

  1. Preberi nalogo in prepoznaj tip: razdalja, razpolovišče, premica, presečišče, ploščina?
  2. Za razdaljo: vstavi v formulo.
  3. Za premico: izračunaj \(k\), nato \(n\).
  4. Za vzporednost/pravokotnost: uporabi \(k_1 = k_2\) oz. \(k_1 k_2 = -1\).
  5. Za presečišče: reši sistem dveh enačb.
  6. Za ploščino: uporabi formulo z determinantami.

⏱️ Časovni načrt za en večer

  • 25 min: Teorija — točke, premica, vzporednost/pravokotnost.
  • 45 min: Tipi 1–5 (razdalja, razpolovišče, težišče, enačba premice, vzporednica).
  • 45 min: Tipi 6–10 (pravokotnica, presečišče, razdalja točke, ploščina, kot).
  • 25 min: Ponovi pogoste napake in študijski vodič.
