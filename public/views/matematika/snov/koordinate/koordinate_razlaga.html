📍 10. Pravokotni koordinatni sistem

Točke, premice in ravnine v 2D in 3D

📖 2D - Ravnina

Razdalja
d(A,B) = √((x₂-x₁)² + (y₂-y₁)²)
Razpolovišče
S((x₁+x₂)/2, (y₁+y₂)/2)
Težišče trikotnika
T((x₁+x₂+x₃)/3, (y₁+y₂+y₃)/3)
Premica
y = kx + n
k = (y₂-y₁)/(x₂-x₁)
Razdalja točke do premice
d(T,p) = |ax₀+by₀+c|/√(a²+b²)

📖 3D - Prostor

Razdalja
d(A,B) = √((x₂-x₁)² + (y₂-y₁)² + (z₂-z₁)²)
Premica (parametrično)
(x,y,z) = (x₀,y₀,z₀) + t(a,b,c)
Ravnina
ax + by + cz + d = 0
Razdalja točke do ravnine
d(T,π) = |ax₀+by₀+cz₀+d|/√(a²+b²+c²)

📝 Primeri

Primer 1 (2D): A(1,2), B(4,6)

d = √((4-1)² + (6-2)²) = 5

S = ((1+4)/2, (2+6)/2) = (2.5, 4)

Primer 2 (3D): A(1,2,3), B(4,6,7)

d = √(9 + 16 + 16) = √41

📊 Medsebojne lege premic

  • Vzporedni: k₁ = k₂
  • Pravokotni: k₁ · k₂ = -1
  • Presečišče: rešitev sistema dveh enačb
