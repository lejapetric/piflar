Integralski račun

Cela razlaga

1Nedoločeni integral

\(\int f(x)\,dx = F(x) + C,\ F' = f\)
primitivna funkcija
\(\int 2x\,dx = x^2 + C\)
\(\int x^n\,dx = \frac{x^{n+1}}{n+1} + C\)
\(n \ne -1\)
\(\int x^3\,dx = \frac{x^4}{4} + C\)
\(\int \frac{dx}{x} = \ln|x| + C\)
\(n = -1\)
\(\int \frac{3}{x}\,dx = 3\ln|x| + C\)
\(\int e^x\,dx = e^x + C\)
eksponentna
\(\int e^{2x}\,dx = \frac{e^{2x}}{2} + C\)
\(\int \sin x\,dx = -\cos x + C\)
\(\int \cos x\,dx = \sin x + C\)
\(\int \cos 3x\,dx = \frac{\sin 3x}{3} + C\)
\(\int (af + bg) = a\int f + b\int g\)
linearnost
\(\int (3x^2 + 1)\,dx = x^3 + x + C\)

2Določeni integral

\(\int_a^b f(x)\,dx = F(b) - F(a)\)
Newton–Leibniz
\(\int_0^2 x\,dx = 2\)
\(\int_a^b = -\int_b^a,\ \int_a^c = \int_a^b + \int_b^c\)
lastnosti
\(\int_1^1 f = 0\)

3Uporaba

\(S = \int_a^b |f(x)|\,dx\)
ploščina pod krivuljo
\(\int_0^\pi \sin x\,dx = 2\)
\(S = \int_a^b (f(x) - g(x))\,dx\)
med krivuljama, \(f \ge g\)
\(x\) in \(x^2\) na \([0, 1]\): \(\frac16\)
\(V = \pi \int_a^b f^2(x)\,dx\)
vrtenina okoli osi \(x\)
\(f = \sqrt{x}\) na \([0, 2]\): \(V = 2\pi\)

!Pazi

  • Ploščino pod osjo \(x\) štej pozitivno (razdeli pri ničlah).
  • Pri nedoločenem integralu dopiši \(+ C\).
