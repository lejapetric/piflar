Vse o odvodih za maturo: diferencialni količnik, pravila odvajanja, geometrijski pomen odvoda, tangenta in normala, ekstremi, naraščanje in padanje, konveksnost in konkavnost, prevoji.

📋 Formule na maturi — osnovna raven

Na maturi osnovne ravni lista s formulami ni, zato si moraš tabele odvodov in pravila zapomniti. Spodaj so vse ključne:

  • Tabela odvodov: \((x^n)' = nx^{n-1}\), \((\sin x)' = \cos x\), \((\cos x)' = -\sin x\), \((e^x)' = e^x\), \((\ln x)' = \tfrac{1}{x}\)
  • Vsota: \((f \pm g)' = f' \pm g'\)
  • Produkt: \((uv)' = u'v + uv'\)
  • Kvocient: \(\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}\)
  • Verižno pravilo: \((f(g(x)))' = f'(g(x)) \cdot g'(x)\)
  • Tangenta: \(y - y_0 = f'(x_0)(x - x_0)\)
  • Normala: \(y - y_0 = -\dfrac{1}{f'(x_0)}(x - x_0)\)

1. Teorija — odvod in pravila

Kar moraš znati na pamet, preden se lotiš nalog.

Osnovni pojmi

Diferenčni količnik

\(\dfrac{\Delta y}{\Delta x} = \dfrac{f(x_0 + h) - f(x_0)}{h}\)

Povprečna hitrost spreminjanja na intervalu \([x_0, x_0 + h]\). Naklon sekante.

Odvod funkcije v točki

\(f'(x_0) = \lim_{h \to 0} \dfrac{f(x_0+h) - f(x_0)}{h}\)

Trenutna hitrost spreminjanja. Naklon tangente.

Geometrijski pomen

\(k_t = f'(x_0)\)

Odvod v točki je smerni koeficient tangente.

Tangenta

\(y - y_0 = f'(x_0)(x - x_0)\)

V točki \((x_0, y_0)\).

Normala

\(y - y_0 = -\dfrac{1}{f'(x_0)}(x - x_0)\)

Pravokotna na tangento.

Stacionarna točka

\(f'(x_0) = 0\)

Kandidat za ekstrem.

Ekstrem

\(f'(x_0)=0, f''(x_0) \neq 0\)

\(f'' > 0\) → minimum, \(f'' < 0\) → maksimum.

Prevoj

\(f''(x_0) = 0\) in sprememba predznaka

Tabela osnovnih odvodov

\((c)' = 0\)
\((x^n)' = n x^{n-1}\)
\((e^x)' = e^x\)
\((a^x)' = a^x \ln a\)
\((\ln x)' = \dfrac{1}{x}\)
\((\log_a x)' = \dfrac{1}{x \ln a}\)
\((\sin x)' = \cos x\)
\((\cos x)' = -\sin x\)
\((\tan x)' = \dfrac{1}{\cos^2 x}\)
\((\cot x)' = -\dfrac{1}{\sin^2 x}\)
\((\arcsin x)' = \dfrac{1}{\sqrt{1-x^2}}\)
\((\arctan x)' = \dfrac{1}{1+x^2}\)

Pravila odvajanja

Vsota in razlika

\((f \pm g)' = f' \pm g'\)

Vsoto odvajaš po členih.

Konstanta

\((c \cdot f)' = c \cdot f'\)

Konstanto izpostaviš.

Produkt

\((uv)' = u'v + uv'\)

Ni enako \(u'v'\)!

Kvocient

\(\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}\)

Vrstni red v števcu je pomemben.

Verižno pravilo

\((f(g(x)))' = f'(g(x)) \cdot g'(x)\)

Za sestavljene funkcije.

Uporaba odvoda

Naraščanje

\(f'(x) > 0\)

Padanje

\(f'(x) < 0\)

Konveksnost (navzgor)

\(f''(x) > 0\)

Konkavnost (navzdol)

\(f''(x) < 0\)

Prevoj

\(f''(x_0) = 0\) + sprememba predznaka

Kot med krivuljama

\(\tan\varphi = \left|\dfrac{k_1 - k_2}{1 + k_1 k_2}\right|\)

2. Tipi nalog — postopki po korakih

Za vsak tip: kako ga prepoznaš, kako ga rešiš, primer.

Tip 1: Odvod polinoma

\((x^n)' = nx^{n-1}\)

Kako prepoznaš: funkcija je polinom ali vsota členov \(x^n\).

Postopek:

  1. Vsak člen odvajaj posebej.
  2. Izpostavi konstanto.
  3. Uporabi \((x^n)' = nx^{n-1}\).

Primer: \(f(x) = 2x^3 - 3x + 4\)

\(f'(x) = 6x^2 - 3\).

Tip 2: Odvod eksponentne, logaritemske in kotne funkcije

\((\sin x)' = \cos x\), \((e^x)' = e^x\)

Kako prepoznaš: nastopajo \(e^x\), \(a^x\), \(\sin x\), \(\cos x\), \(\ln x\).

Postopek:

  1. Prepoznaj obliko in uporabi ustrezno formulo.
  2. Za sestavljene funkcije uporabi verižno pravilo.

Primer: \(f(x) = 2\sin x - 1\)

\(f'(x) = 2\cos x\).

Tip 3: Odvod produkta

\((uv)' = u'v + uv'\)

Kako prepoznaš: produkt dveh funkcij, npr. \(x^2 \sin x\), \(x e^x\).

Postopek:

  1. Določi \(u\) in \(v\).
  2. Izračunaj \(u'\) in \(v'\).
  3. Uporabi \((uv)' = u'v + uv'\).
  4. Poenostavi.

Primer: \(f(x) = x^2 \sin x\)

\(f'(x) = 2x\sin x + x^2\cos x\).

Tip 4: Odvod kvocienta

\(\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}\)

Kako prepoznaš: ulomek dveh funkcij, npr. \(\dfrac{1+x}{x}\).

Postopek:

  1. Določi \(u\) in \(v\).
  2. Izračunaj \(u'\) in \(v'\).
  3. Uporabi formulo.
  4. Poenostavi.

Primer: \(f(x) = \dfrac{1+x}{x}\)

\(f'(x) = -\dfrac{1}{x^2}\).

Tip 5: Verižno pravilo

\((f(g(x)))' = f'(g(x)) \cdot g'(x)\)

Kako prepoznaš: sestavljena funkcija, npr. \(\ln(2x+5)\), \(\sin(3x)\).

Postopek:

  1. Prepoznaj zunanjo in notranjo funkcijo.
  2. Odvajaj zunanjo, pusti notranjo pri miru.
  3. Pomnoži z odvodom notranje.
  4. Poenostavi.

Primer: \(f(x) = \ln(2x+5)\)

\(f'(x) = \dfrac{2}{2x+5}\).

Tip 6: Diferenčni količnik po definiciji

\(f'(x) = \lim_{h\to 0} \dfrac{f(x+h)-f(x)}{h}\)

Kako prepoznaš: "izračunajte odvod po definiciji".

Postopek:

  1. Izračunaj \(f(x+h)\).
  2. Odštej \(f(x)\) in poenostavi števec.
  3. Deli s \(h\) in okrajšaj.
  4. Izračunaj limito, ko \(h \to 0\).

Primer: \(f(x) = x^2\)

\(\dfrac{(x+h)^2 - x^2}{h} = \dfrac{2xh + h^2}{h} = 2x + h \to 2x\).

Tip 7: Tangenta in normala na graf

\(y - y_0 = f'(x_0)(x - x_0)\)

Kako prepoznaš: "zapišite enačbo tangente/normale v točki".

Postopek:

  1. Izračunaj \(y_0 = f(x_0)\).
  2. Izračunaj \(k = f'(x_0)\).
  3. Tangenta: \(y - y_0 = k(x - x_0)\).
  4. Normala: \(y - y_0 = -\dfrac{1}{k}(x - x_0)\).

Primer: \(f(x) = x^3 - x\), tangenti vzporedni \(2x - y - 3 = 0\)

\(k_1 = 2\). \(3x^2 - 1 = 2 \Rightarrow x = \pm 1\). Tangenti: \(y = 2x - 2\) in \(y = 2x + 2\).

Tip 8: Stacionarne točke in ekstremi

\(f'(x_0) = 0\), \(f''(x_0) \neq 0\)

Kako prepoznaš: "izračunajte stacionarne točke", "lokalni minimum".

Postopek:

  1. Reši \(f'(x) = 0\).
  2. Izračunaj \(f''(x)\).
  3. \(f''(x_0) > 0\) → minimum, \(f''(x_0) < 0\) → maksimum.
  4. Izračunaj \(y_0 = f(x_0)\).

Primer: \(p(x) = x^3 + 4x^2 + ax + 20\), min. v \(A(-1, y_1)\)

\(p'(-1) = 0 \Rightarrow a = 5\). \(y_1 = p(-1) = 18\). \(p''(-1) = 2 > 0\) ✓.

Tip 9: Naraščanje in padanje

\(f' > 0\) narašča, \(f' < 0\) pada

Kako prepoznaš: "določite intervale naraščanja in padanja".

Postopek:

  1. Reši \(f'(x) = 0\) — ničle odvoda.
  2. Naredi znakovno tabelo (preveri predznak \(f'\) na vsakem intervalu).
  3. Kjer \(f' > 0\), funkcija narašča; kjer \(f' < 0\), pada.

Primer: \(f(x) = x^2 - 4x\)

\(f'(x) = 2x - 4 = 0 \Rightarrow x = 2\). Pada na \((-\infty, 2)\), narašča na \((2, \infty)\).

Tip 10: Konveksnost, konkavnost in prevoj

\(f''(x_0) = 0\) + sprememba predznaka

Kako prepoznaš: "določite prevoje", "konveksnost/konkavnost".

Postopek:

  1. Izračunaj \(f''(x)\).
  2. Reši \(f''(x) = 0\).
  3. Preveri, ali se predznak \(f''\) spremeni.
  4. \(f'' > 0\): konveksno; \(f'' < 0\): konkavno.

Primer: \(f(x) = x^3 - 3x^2\)

\(f''(x) = 6x - 6 = 0 \Rightarrow x = 1\). Prevoj: \(P(1, -2)\).

Tip 11: Odvod inverzne funkcije

\((f^{-1})'(y_0) = \dfrac{1}{f'(x_0)}\)

Kako prepoznaš: "predpis inverzne funkcije in njen odvod".

Postopek:

  1. Zapiši \(y = f(x)\).
  2. Zamenjaj \(x\) in \(y\): \(x = f(y)\).
  3. Izrazi \(y\) → \(f^{-1}(x)\).
  4. \((f^{-1})'(x) = \dfrac{1}{f'(f^{-1}(x))}\).

Primer: \(f(x) = 5x\)

\(f^{-1}(x) = \dfrac{x}{5}\). \((f^{-1})'(x) = \dfrac{1}{5}\).

Tip 12: Kot med krivuljama

\(\tan\varphi = \left|\dfrac{k_1 - k_2}{1 + k_1 k_2}\right|\)

Kako prepoznaš: "izračunajte kot med krivuljama".

Postopek:

  1. Poišči presečišče krivulj: \(f(x) = g(x)\).
  2. \(k_1 = f'(x_0)\), \(k_2 = g'(x_0)\).
  3. Uporabi formulo za kot med premicama.
  4. Za kot z osjo \(x\): \(\tan\alpha = k\).

Primer: \(f(x) = x^2 - 4\) seka os \(x\) v \(x = 2\)

\(k = f'(2) = 4\). \(\alpha = \arctan 4 \approx 75{,}96°\).

3. Pogoste napake

  • Zamenjaš produktno pravilo s "produkt odvodov": \((uv)' \neq u'v'\).
  • Pozabiš na minus pri odvodu kosinusa: \((\cos x)' = -\sin x\).
  • Pri verižnem pravilu pozabiš pomnožiti z odvodom notranje funkcije.
  • Pri kvocientnem pravilu zamenjaš vrstni red: \((u/v)' \neq (uv' - u'v)/v^2\).
  • Pri tangenti zamenjaš \(k = f'(x_0)\) s \(k = f(x_0)\).
  • Pri ekstremih pozabiš preveriti \(f''(x_0)\) — lahko je prevoj.
  • Pri naraščanju/padanju pozabiš, da \(f' = 0\) še ne pomeni ekstrema (lahko prevoj).
  • Pri kotu med krivuljama pozabiš absolutno vrednost v formuli.

4. Študijski vodič — hitri pregled

📋 Kaj moraš znati na pamet

  • Tabela odvodov (12 osnovnih) — glej zgoraj.
  • Pravila: vsota, produkt, kvocient, verižno.
  • Tangenta: \(y - y_0 = f'(x_0)(x - x_0)\).
  • Normala: \(y - y_0 = -\dfrac{1}{f'(x_0)}(x - x_0)\).
  • Ekstremi: \(f' = 0\), preveri \(f''\).
  • Naraščanje: \(f' > 0\). Padanje: \(f' < 0\).
  • Prevoj: \(f'' = 0\) in sprememba predznaka.

🎯 Kako pristopiti k nalogi

  1. Preberi nalogo in prepoznaj tip: odvod, tangenta, ekstrem, naraščanje, prevoj, kot?
  2. Za odvod: prepoznaj strukturo (vsota, produkt, kvocient, sestavljena) in uporabi ustrezno pravilo.
  3. Za tangento: izračunaj \(y_0 = f(x_0)\), \(k = f'(x_0)\), zapiši enačbo.
  4. Za ekstrem: reši \(f' = 0\), preveri \(f''\), izračunaj \(y_0\).
  5. Za naraščanje: reši \(f' = 0\), naredi znakovno tabelo.
  6. Za prevoj: reši \(f'' = 0\), preveri spremembo predznaka.
