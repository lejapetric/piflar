Geometrija

Vse o geometriji za maturo: trikotniki, štirikotniki, krog in krožnica, podobnost, kotne funkcije v pravokotnem trikotniku, obseg, ploščina, površina in prostornina teles.

45+ Primerov
~70 min Branja

1. Teorija — formule in pravila

Kar moraš znati na pamet, preden se lotiš nalog.

Trikotnik — osnovno

  • Vsota notranjih kotov: \(\alpha + \beta + \gamma = 180^\circ\)
  • Zunanji kot: vsota nasprotnih notranjih kotov
  • Obseg: \(o = a + b + c\)
  • Ploščina: \(S = \dfrac{a \cdot v_a}{2} = \dfrac{1}{2}ab \sin\gamma\)
  • Heronova formula: \(S = \sqrt{s(s-a)(s-b)(s-c)}\), \(s = \dfrac{a+b+c}{2}\)

Pravokotni trikotnik

  • Pitagorov izrek: \(a^2 + b^2 = c^2\)
  • Kotne funkcije:
    • \(\sin\alpha = \dfrac{a}{c}\) (nasprotna / hipotenuza)
    • \(\cos\alpha = \dfrac{b}{c}\) (priležna / hipotenuza)
    • \(\tan\alpha = \dfrac{a}{b}\) (nasprotna / priležna)
  • Višina na hipotenuzo: \(v_c = \dfrac{ab}{c}\)
  • Enačba: \(v_c^2 = a' \cdot b'\) (projekciji katet)

Splošni trikotnik — sinusni in kosinusni izrek

  • Sinusni izrek: \(\dfrac{a}{\sin\alpha} = \dfrac{b}{\sin\beta} = \dfrac{c}{\sin\gamma} = 2R\)
  • Kosinusni izrek: \(c^2 = a^2 + b^2 - 2ab\cos\gamma\)
  • Uporaba sinusnega: ko poznaš par stranica–nasprotni kot in še eno stran/kot.
  • Uporaba kosinusnega: ko poznaš dve stranici in vmesni kot, ali vse tri stranice.

Štirikotniki

  • Kvadrat: \(o = 4a\), \(S = a^2\), diagonala \(d = a\sqrt{2}\)
  • Pravokotnik: \(o = 2(a+b)\), \(S = ab\), diagonala \(d = \sqrt{a^2+b^2}\)
  • Paralelogram: \(o = 2(a+b)\), \(S = a \cdot v_a = ab\sin\alpha\)
  • Trapez: \(o = a + b + c + d\), \(S = \dfrac{a+c}{2} \cdot v\) (\(a, c\) osnovnici)
  • Romb: \(o = 4a\), \(S = \dfrac{e \cdot f}{2}\) (\(e, f\) diagonali)
  • Vsota notranjih kotov štirikotnika: \(360^\circ\)

Krog in krožnica

  • Obseg kroga: \(o = 2\pi r\)
  • Ploščina kroga: \(S = \pi r^2\)
  • Krožni izsek (kot \(\alpha\) v stopinjah): \(S = \dfrac{\pi r^2 \alpha}{360^\circ}\), \(l = \dfrac{2\pi r \alpha}{360^\circ}\)
  • Središčni kot je dvakratnik obodnega kota nad istim lokom.
  • Talesov izrek: kot nad premerom je \(90^\circ\).

Podobnost

  • Podobna lika: enaki koti, stranice v razmerju \(k\) (koeficient podobnosti).
  • Razmerje obsegov: \(o_2 : o_1 = k\)
  • Razmerje ploščin: \(S_2 : S_1 = k^2\)
  • Razmerje prostornin: \(V_2 : V_1 = k^3\)

Telesa — površina in prostornina

  • Kocka (rob \(a\)): \(P = 6a^2\), \(V = a^3\), telesna diagonala \(d = a\sqrt{3}\)
  • Kvader (\(a, b, c\)): \(P = 2(ab + ac + bc)\), \(V = abc\), telesna diagonala \(d = \sqrt{a^2+b^2+c^2}\)
  • Valj (polmer \(r\), višina \(v\)): \(P = 2\pi r^2 + 2\pi r v\), \(V = \pi r^2 v\)
  • Stožec (polmer \(r\), višina \(v\), stranica \(s\)): \(P = \pi r^2 + \pi r s\), \(V = \dfrac{\pi r^2 v}{3}\), \(s = \sqrt{r^2 + v^2}\)
  • Krogla (polmer \(r\)): \(P = 4\pi r^2\), \(V = \dfrac{4\pi r^3}{3}\)
  • Piramida (osnovna ploskev \(S_o\), višina \(v\)): \(V = \dfrac{S_o \cdot v}{3}\)

2. Tipi nalog — postopki po korakih

Za vsak tip: kako ga prepoznaš, kako ga rešiš, primer.

Tip 1: Koti v trikotniku

Kako prepoznaš: "Izračunajte kote", podani so razmerja ali delni podatki.

Postopek:

  1. Zapiši: \(\alpha + \beta + \gamma = 180^\circ\).
  2. Uporabi dane zveze (npr. \(\gamma = 2\beta\)).
  3. Reši sistem enačb.
$$\text{Primer: } \alpha = 48{,}6^\circ, \quad \gamma = 2\beta$$

1. \(48{,}6 + \beta + 2\beta = 180\). 2. \(3\beta = 131{,}4 \Rightarrow \beta = 43{,}8^\circ\). 3. \(\gamma = 87{,}6^\circ\).

Tip 2: Pravokotni trikotnik

Kako prepoznaš: "Pravokotni trikotnik", dane katete ali hipotenuza in kot.

Postopek:

  1. Nariši skico in označi pravi kot.
  2. Uporabi Pitagorov izrek: \(a^2 + b^2 = c^2\).
  3. Za kote uporabi \(\sin, \cos, \tan\).
  4. Za višino na hipotenuzo: \(v_c = \dfrac{ab}{c}\).
$$\text{Primer: } a = 3, c = 6$$

1. \(b^2 = 36 - 9 = 27 \Rightarrow b = 3\sqrt{3}\). 2. \(\sin\alpha = \dfrac{3}{6} = \dfrac{1}{2} \Rightarrow \alpha = 30^\circ\). 3. \(\beta = 60^\circ\).

Tip 3: Sinusni izrek

Kako prepoznaš: podan par stranica–nasprotni kot in še ena stranica/kot.

Postopek:

  1. Zapiši \(\dfrac{a}{\sin\alpha} = \dfrac{b}{\sin\beta}\).
  2. Izrazi neznanko.
  3. Pazi: pri iskanju kota ima \(\sin\) lahko dve rešitvi (\(\alpha\) in \(180^\circ - \alpha\)).
$$\text{Primer: } \alpha = 30^\circ, \beta = 50^\circ, a = 7$$

1. \(\dfrac{7}{\sin 30^\circ} = \dfrac{b}{\sin 50^\circ}\). 2. \(b = \dfrac{7 \cdot \sin 50^\circ}{\sin 30^\circ} = \dfrac{7 \cdot 0{,}766}{0{,}5} \approx 10{,}72\) cm.

Tip 4: Kosinusni izrek

Kako prepoznaš: podani dve stranici in vmesni kot, ali vse tri stranice.

Postopek:

  1. Zapiši \(c^2 = a^2 + b^2 - 2ab\cos\gamma\).
  2. Vstavi podatke in izračunaj neznanko.
  3. Za iskanje kota: \(\cos\gamma = \dfrac{a^2+b^2-c^2}{2ab}\).
$$\text{Primer: } a = 8, b = 9, c = 10$$

1. \(\cos\beta = \dfrac{a^2 + c^2 - b^2}{2ac} = \dfrac{64+100-81}{2 \cdot 8 \cdot 10} = \dfrac{83}{160}\). 2. \(\beta \approx 58{,}75^\circ\).

Tip 5: Ploščina trikotnika

Kako prepoznaš: "Izračunajte ploščino trikotnika".

Postopek:

  1. Če imaš osnovnico in višino: \(S = \dfrac{a \cdot v_a}{2}\).
  2. Če imaš dve stranici in vmesni kot: \(S = \dfrac{1}{2}ab\sin\gamma\).
  3. Če imaš vse tri stranice: Heronova formula.
$$\text{Primer: } a = 6, b = 8, \gamma = 30^\circ$$

1. \(S = \dfrac{1}{2} \cdot 6 \cdot 8 \cdot \sin 30^\circ = 24 \cdot 0{,}5 = 12\).

Tip 6: Enakokraki trikotnik

Kako prepoznaš: "Enakokraki trikotnik", podana osnovnica in krak ali višina.

Postopek:

  1. Višina na osnovnico razpolovi osnovnico.
  2. Uporabi Pitagorov izrek: \(a^2 = v^2 + \left(\dfrac{c}{2}\right)^2\).
  3. Kota ob osnovnici sta enaka.
$$\text{Primer: osnovnica } c = 10, \text{ krak } a = 7$$

1. \(v^2 = 49 - 25 = 24 \Rightarrow v = 2\sqrt{6}\). 2. \(S = \dfrac{10 \cdot 2\sqrt{6}}{2} = 10\sqrt{6}\). 3. \(\cos\alpha = \dfrac{5}{7} \Rightarrow \alpha \approx 44{,}4^\circ\). 4. Kot ob vrhu: \(180 - 2 \cdot 44{,}4 = 91{,}2^\circ\).

Tip 7: Štirikotniki — trapez, paralelogram, romb

Kako prepoznaš: "Trapez ABCD", "romb", "paralelogram".

Postopek:

  1. Nariši skico in označi znane količine.
  2. Uporabi ustrezno formulo za obseg/ploščino.
  3. Pri trapezu: \(S = \dfrac{a+c}{2} \cdot v\).
  4. Pri rombu: \(S = \dfrac{e \cdot f}{2}\) ali \(S = a \cdot v\).
  5. Pri paralelogramu: \(S = a \cdot v_a\).
$$\text{Primer: romb, stranica } a = 10, \text{ višina } v = 7$$

1. \(S = 10 \cdot 7 = 70\). 2. \(\sin\alpha = \dfrac{7}{10} = 0{,}7 \Rightarrow \alpha \approx 44{,}4^\circ\). 3. Kot ob osnovnici je \(44{,}4^\circ\), drugi je \(180 - 44{,}4 = 135{,}6^\circ\).

Tip 8: Krožni izsek in lok

Kako prepoznaš: "Krožni izsek", "dolžina loka".

Postopek:

  1. Pretvori kot v radiane (če je v stopinjah): \(\alpha_{\text{rad}} = \dfrac{\pi \alpha}{180^\circ}\).
  2. Dolžina loka: \(l = r \cdot \alpha_{\text{rad}}\).
  3. Ploščina izseka: \(S = \dfrac{1}{2} r^2 \alpha_{\text{rad}} = \dfrac{\pi r^2 \alpha}{360^\circ}\).
  4. Obseg izseka: \(o = 2r + l\).
$$\text{Primer: } r = 1, \alpha = \frac{\pi}{2} \text{ rad}$$

1. \(l = 1 \cdot \dfrac{\pi}{2} = \dfrac{\pi}{2}\). 2. \(S = \dfrac{1}{2} \cdot 1 \cdot \dfrac{\pi}{2} = \dfrac{\pi}{4}\). 3. \(o = 2 + \dfrac{\pi}{2}\).

Tip 9: Podobnost likov

Kako prepoznaš: "Podobna trikotnika", "razmerje stranic".

Postopek:

  1. Določi koeficient podobnosti \(k = \dfrac{a'}{a}\).
  2. Razmerje obsegov: \(o' = k \cdot o\).
  3. Razmerje ploščin: \(S' = k^2 \cdot S\).
  4. Razmerje prostornin: \(V' = k^3 \cdot V\).
$$\text{Primer: trikotnik } 4, 6, 8, \text{ podoben z najkrajšo stranico } 8$$

1. \(k = \dfrac{8}{4} = 2\). 2. Obseg originala: \(4+6+8 = 18\). 3. Novi obseg: \(2 \cdot 18 = 36\). 4. Ploščina originala (Heron): \(s = 9\), \(S = \sqrt{9 \cdot 5 \cdot 3 \cdot 1} = \sqrt{135} \approx 11{,}62\). 5. Nova ploščina: \(4 \cdot 11{,}62 = 46{,}48\).

Tip 10: Kvader, kocka — diagonala in prostornina

Kako prepoznaš: "Kvader", "kocka", "telesna diagonala".

Postopek:

  1. Osnovna diagonala: \(d_o = \sqrt{a^2 + b^2}\).
  2. Telesna diagonala: \(d_t = \sqrt{a^2+b^2+c^2}\).
  3. Prostornina: \(V = abc\).
  4. Površina: \(P = 2(ab+ac+bc)\).
$$\text{Primer: } a = 5, b = 12, c = 84$$

1. \(d_o = \sqrt{25 + 144} = 13\). 2. \(d_t = \sqrt{25 + 144 + 7056} = \sqrt{7225} = 85\).

Tip 11: Valj, stožec, krogla

Kako prepoznaš: "Valj", "stožec", "krogla".

Postopek:

  1. Preberi, kaj je podano (polmer, višina, prostornina ...).
  2. Uporabi ustrezno formulo.
  3. Za stožec: \(s = \sqrt{r^2 + v^2}\).
  4. Pazi na enote (npr. litre v dm³).
$$\text{Primer: stožec, } V = 64, v = 4$$

1. \(V = \dfrac{\pi r^2 v}{3} = 64\). 2. \(\pi r^2 \cdot 4 = 192\). 3. \(r^2 = \dfrac{48}{\pi} \Rightarrow r \approx 3{,}91\).

$$\text{Primer: valj, } h = 50 \text{ cm}, V = 20 \text{ L} = 20 \text{ dm}^3$$

1. \(V = \pi r^2 h = \pi r^2 \cdot 5 = 20\). 2. \(r^2 = \dfrac{4}{\pi} \Rightarrow r \approx 1{,}1\) dm.

Tip 12: Piramida

Kako prepoznaš: "Piramida", "stranska višina", "osnovni rob".

Postopek:

  1. Prostornina: \(V = \dfrac{S_o \cdot v}{3}\).
  2. Za pravilno štiristrano piramido: \(S_o = a^2\).
  3. Stranska višina \(v_1\) in višina \(v\): \(v_1^2 = v^2 + \left(\dfrac{a}{2}\right)^2\).
$$\text{Primer: } V = 22, v_1 = v + 4$$

1. \(v_1^2 = v^2 + \dfrac{a^2}{4}\). 2. \((v+4)^2 = v^2 + \dfrac{a^2}{4} \Rightarrow 8v + 16 = \dfrac{a^2}{4} \Rightarrow a^2 = 32v + 64\). 3. \(V = \dfrac{a^2 v}{3} = 22 \Rightarrow a^2 v = 66\). 4. Reši sistem: \((32v + 64)v = 66\).

Tip 13: Sestavljeni liki — ploščina osenčenega dela

Kako prepoznaš: "Izračunajte ploščino osenčenega lika".

Postopek:

  1. Razdeli lik na preproste like (trikotnike, kroge, kvadrate ...).
  2. Izračunaj ploščino vsakega dela.
  3. Seštej ali odštej ploščine (odvisno od tega, ali je lik zunaj ali znotraj).
$$\text{Primer: kvadrat } a = 4, \text{ krožni lok s središčem v B}$$

1. Ploščina kvadrata: \(16\). 2. Ploščina četrtine kroga: \(\dfrac{\pi \cdot 16}{4} = 4\pi\). 3. Osenčeni del: \(16 - 4\pi\).

Tip 14: Besedilne naloge (zemljišče, posoda, žoga)

Kako prepoznaš: "Zemljišče pravokotne oblike", "akvarij", "žoga".

Postopek:

  1. Določi obliko (pravokotnik, kvader, krogla ...).
  2. Zapiši enačbe iz besedila.
  3. Reši sistem.
  4. Preveri smiselnost (npr. dimenzije morajo biti pozitivne).
$$\text{Primer: Zemljišče } S = 405 \text{ m}^2, \text{ obseg } o = 81 \text{ m}$$

1. \(ab = 405\). 2. \(2(a+b) = 81 \Rightarrow a + b = 40{,}5\). 3. Reši kvadratno enačbo: \(a(40{,}5 - a) = 405 \Rightarrow a^2 - 40{,}5a + 405 = 0\). 4. \(a = 27, b = 13{,}5\) (ali obratno).

3. Pogoste napake

  • Pri sinusnem izreku pozabiš, da ima \(\sin\alpha = k\) lahko dve rešitvi (\(\alpha\) in \(180^\circ - \alpha\)).
  • Pri kosinusnem izreku zamenjaš predznak \(-2ab\cos\gamma\).
  • Pri ploščini trikotnika z dvema stranicama in kotom uporabiš \(\cos\) namesto \(\sin\).
  • Pri podobnosti zamenjaš razmerje obsegov (\(k\)) in ploščin (\(k^2\)).
  • Pri krožnem izseku pozabiš pretvoriti stopinje v radiane (ali obratno).
  • Pri telesih zamenjaš površino in prostornino.
  • Pri valju/stožcu pozabiš, da je višina pravokotna na osnovno ploskev.
  • Pri sestavljenih likih pozabiš odšteti ploščino, ki ni del lika.
