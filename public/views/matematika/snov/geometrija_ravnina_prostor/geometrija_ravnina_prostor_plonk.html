4Pravokotni trikotnik

\(a^2 + b^2 = c^2\)
Pitagorov izrek
\(3, 4\): \(c = 5\)
\(a^2 = c\,a_1,\ b^2 = c\,b_1\)
Evklidov izrek
\(c = 10, a_1 = 3,6\): \(a = 6\)
\(v_c^2 = a_1 b_1\)
višinski izrek
\(a_1 = 4, b_1 = 9\): \(v_c = 6\)

5Podobnost

\(\frac{a'}{a} = k,\ \frac{S'}{S} = k^2\)
podobna lika, razteg s faktorjem \(k\)
\(k = 3\): ploščina 9-krat

6Splošni trikotnik

\(\frac{a}{\sin\alpha} = \frac{b}{\sin\beta} = 2R\)
sinusni izrek
\(a = 5, \alpha = 30^\circ\): \(R = 5\)
\(c^2 = a^2 + b^2 - 2ab\cos\gamma\)
kosinusni izrek
\(a = 3, b = 5, \gamma = 60^\circ\): \(c = \sqrt{19}\)

7Prostor
