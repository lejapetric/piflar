∫ 12. Diferencialni račun

Odvodi, pravila odvajanja in uporaba

📖 Tabela odvodov

(c)' = 0
(xⁿ)' = n·xⁿ⁻¹
(√x)' = 1/(2√x)
(aˣ)' = aˣ·ln a
(eˣ)' = eˣ
(ln x)' = 1/x
(sin x)' = cos x
(cos x)' = -sin x
(tan x)' = 1/cos²x

📝 Pravila odvajanja

Vsota
(f ± g)' = f' ± g'
Produkt
(f·g)' = f'·g + f·g'
Kvocient
(f/g)' = (f'·g - f·g')/g²
Verižno
(f(g(x)))' = f'(g(x))·g'(x)

📈 Uporaba odvodov

Tangenta
y - f(x₀) = f'(x₀)(x - x₀)
Naraščanje
f'(x) > 0
Padanje
f'(x) < 0
Lokalni ekstrem
f'(x) = 0 in f''(x) ≠ 0

f''>0 → min, f''<0 → max

Prevoj
f''(x) = 0 in f'' spremeni predznak

📝 Primer

Poišči ekstreme: f(x) = x³ - 3x² + 2

f'(x) = 3x² - 6x = 3x(x-2)

Stacionarni točki: x = 0, x = 2

f''(x) = 6x - 6

f''(0) = -6 < 0 → lokalni maksimum pri (0,2)

f''(2) = 6 > 0 → lokalni minimum pri (2,-2)
