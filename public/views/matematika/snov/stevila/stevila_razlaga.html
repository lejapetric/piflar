🔢 3. Številske množice in kompleksna števila

Hierarhija številskih množic in računanje s kompleksnimi števili

📖 Številske množice (hierarhija)

ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ ⊂ ℂ
  • ℕ – Naravna števila: {1, 2, 3, 4, ...}
  • ℤ – Cela števila: {..., -3, -2, -1, 0, 1, 2, 3, ...}
  • ℚ – Racionalna števila: {p/q | p, q ∈ ℤ, q ≠ 0}
  • ℝ – Realna števila (vsa števila na številski premici)
  • ℂ – Kompleksna števila

📖 Kompleksna števila

Imaginarna enota
i² = -1
Splošna oblika
z = a + bi

a = Re(z), b = Im(z)

Konjugirano število
z̄ = a - bi
Absolutna vrednost
|z| = √(a² + b²)

📝 Računske operacije

Seštevanje
(a+bi) ± (c+di) = (a±c) + (b±d)i
Množenje
(a+bi)(c+di) = (ac-bd) + (ad+bc)i
Deljenje
razširimo s konjugiranim imenovalcem
Primer deljenja:
(3+2i)/(1-4i) · (1+4i)/(1+4i) = -5/17 + (14/17)i

🔄 Potence imaginarne enote

i¹ = i
i² = -1
i³ = -i
i⁴ = 1

💡 Perioda 4: iⁿ = i^(n mod 4)

Primer: i²⁰²⁶ = ?
2026 ÷ 4 = 506 ostanka 2 → i²⁰²⁶ = -1
