∫ 13. Integralni račun

Nedoločeni in določeni integrali, uporaba

📖 Tabela osnovnih integralov

∫ c dx = cx + C
∫ xⁿ dx = xⁿ⁺¹/(n+1) + C
∫ 1/x dx = ln|x| + C
∫ aˣ dx = aˣ/ln a + C
∫ eˣ dx = eˣ + C
∫ sin x dx = -cos x + C
∫ cos x dx = sin x + C

📝 Pravila za integriranje

Vsota
∫(f ± g) dx = ∫f dx ± ∫g dx
Konstanta
∫c·f dx = c·∫f dx
Delna integracija
∫u dv = u·v - ∫v du
Zamenjava
∫f(g(x))·g'(x) dx = ∫f(u) du

📊 Določeni integral

∫ᵇₐ f(x) dx = F(b) - F(a)

📈 Uporaba integralov

Ploščina
S = ∫ᵇₐ (f(x) - g(x)) dx
Prostornina (vrtenje okoli x)
V = π∫ᵇₐ (f(x))² dx
Povprečna vrednost
f̄ = 1/(b-a) · ∫ᵇₐ f(x) dx
