Potence in koreni

Cela razlaga

1Potence

\(a^m a^n = a^{m+n},\ \frac{a^m}{a^n} = a^{m-n}\)
enaki osnovi
\(2^3 \cdot 2^4 = 2^7\)
\((a^m)^n = a^{mn},\ (ab)^n = a^n b^n\)
potenca potence, produkta
\((x^2)^3 = x^6\)
\(a^0 = 1,\ a^{-n} = \frac{1}{a^n}\)
\(a \ne 0\)
\(2^{-3} = \frac{1}{8}\)
\(\left(\frac{a}{b}\right)^{-n} = \left(\frac{b}{a}\right)^n\)
negativen eksponent obrne ulomek
\(\left(\frac{2}{3}\right)^{-2} = \frac{9}{4}\)

2Koreni

\(\sqrt[n]{a}\,\sqrt[n]{b} = \sqrt[n]{ab}\)
enaki korenski eksponenti
\(\sqrt{2}\sqrt{8} = 4\)
\(\sqrt[n]{a^m} = a^{\frac{m}{n}}\)
potenca z racionalnim eksponentom
\(8^{\frac23} = \sqrt[3]{64} = 4\)
\(\sqrt{a^2} = |a|\)
sod koren vrne absolutno vrednost
\(\sqrt{(-3)^2} = 3\)
\(\sqrt[n]{\sqrt[m]{a}} = \sqrt[nm]{a}\)
koren korena
\(\sqrt{\sqrt[3]{x}} = \sqrt[6]{x}\)
\(\frac{a}{\sqrt{b}} = \frac{a\sqrt{b}}{b}\)
racionalizacija
\(\frac{1}{\sqrt{3} - 1} = \frac{\sqrt{3} + 1}{2}\)
delno korenjenje
izpostavi popolne kvadrate
\(\sqrt{50} = 5\sqrt{2}\)

3Iracionalne enačbe

izoliraj koren, kvadriraj, preizkus
kvadriranje doda lažne rešitve
\(\sqrt{x + 2} = x\): \(x = 2\) (\(x = -1\) odpade)
\(\sqrt{A} \ge 0\)
pogoj za sod koren: \(A \ge 0\)
\(\sqrt{x - 3}\): \(x \ge 3\)

!Pazi

  • Pri iracionalni enačbi vedno naredi preizkus.
  • \((a + b)^2 \ne a^2 + b^2\) in \(\sqrt{a + b} \ne \sqrt{a} + \sqrt{b}\).
