Naloga 1

Nasprotna števila.

Rešitev
  • \(10 \to -10,\ 999 \to -999,\ -13 \to 13,\ -999 \to 999,\ 0 \to 0\)
  • \(\text{nasprotno } -19 \text{ ima število } 19,\ \text{nasprotno } 666 \text{ ima } -666\)
Postopek

Nasprotno število dobiš tako, da zamenjaš predznak: nasprotno od \(a\) je \(-a\). Število 0 je samo sebi nasprotno. Če je dano nasprotno število, iščeš število, ki mu je nasprotno; spet samo zamenjaš predznak.

Naloga 3

Primerjanje celih števil z \(<\) in \(>\).

Rešitev
  • \(567 < 576\)
  • \(-3698 > -3896\)
  • \(468 > -486\)
  • \(-555 > -5555\)
  • \(-6655 > -6665\)
  • \(-3399 < -3398\)
Postopek

Pozitivni števili primerjaš po števkah od leve. Pri negativnih je obratno: večje je tisto, ki je bližje 0, torej tisto z manjšo absolutno vrednostjo (\(-3698\) je bližje 0 kot \(-3896\)). Vsako pozitivno število je večje od vsakega negativnega. Preverjanje: \(a < b \Leftrightarrow a - b < 0\).

Naloga 18.a

Diagram poteka igre ugibanja števila od 1 do 10.

Rešitev
  • Računalnik izbere skrito število, igralec ugiba, računalnik pa pove, ali je skrito število večje ali manjše. Najboljša strategija je razpolavljanje: vedno ugibaš sredino preostalih možnosti (5, nato 2 ali 8 …). Tako je dovolj največ 4 ugibanj.
Postopek

Po vsakem odgovoru „večje“ ali „manjše“ ostane približno polovica možnosti: \(10 \to 5 \to 2 \to 1\). Ker je \(2^3 < 10 \le 2^4\), so v najslabšem primeru potrebna 4 ugibanja.

Naloga 18.b

Temperature petih hladilnic.

Rešitev
  • \(B = -15,\ E = -14,\ C = -5,\ A = -1,\ D = 1 \ ^{\circ}\text{C}\)
  • ali (prav tako ustreza vsem pogojem): \(B = -15\), \(E = -14\), \(C = -4\), \(A = 0\), \(D = 2\) °C
Postopek

Iz pogojev: \(B < C < A\) in \(E = B + 1\). Ker so temperature cela in različna števila, \(E\) leži med \(B\) in \(C\), zato je najnižja \(B = -15\) in \(E = -14\). Edina pozitivna je \(D\), zato je najtoplejša, druga najtoplejša pa \(A\): \(D = A + 2\). Ker \(A\) ni pozitivna in je \(D > 0\), je \(A = -1\) ali \(A = 0\). Iz \(A - C = 4\) dobiš \(C\). Če 0 °C štejemo kot „ni pozitivna“, ustrezata obe rešitvi.
