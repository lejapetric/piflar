Potenčna funkcija, polinomi in racionalna funkcija

Cela razlaga

1Naravni eksponent

\(f(x) = x^n\)
\(n\) sod: soda, \(Z_f = [0, \infty)\)
\(x^4\): \(f(-2) = 16\)
\(n\) lih
liha funkcija, \(Z_f = \mathbb{R}\)
\(x^3\): \(f(-2) = -8\)
vse gredo skozi \((1, 1)\)
sode tudi skozi \((-1, 1)\)
lihe skozi \((-1, -1)\)

2Negativni eksponent

\(f(x) = x^{-n} = \frac{1}{x^n}\)
\(D_f = \mathbb{R} \setminus \{0\}\), pol v 0
\(x^{-1}\): hiperbola
asimptoti \(x = 0\), \(y = 0\)
obe osi
\(x^{-2}\) je soda, vedno pozitivna

3Polinom

\(p(x) = a_n x^n + \ldots + a_0\)
stopnja \(n\), vodilni \(a_n\)
\(2x^3 - x + 1\): st. 3
obnašanje v \(\pm\infty\)
odloča \(a_n x^n\)
\(-x^3\): levo \(+\infty\), desno \(-\infty\)

4Deljenje

\(p(x) = k(x) q(x) + r(x)\)
osnovni izrek o deljenju
\(x^2 + 1 = (x - 1)(x + 1) + 2\)
\(p(a) = r\) pri deljenju z \(x - a\)
ostanek
\(p(x) = x^3 - 2\), \(p(2) = 6\)
Hornerjev algoritem
hitro računanje \(p(a)\) in deljenje z \(x - a\)
\(x^3 - 6x^2 + 11x - 6\) pri 1: ostanek 0

5Ničle

\(p(a) = 0 \iff (x - a) \mid p(x)\)
ničla in faktor
\(x = 1\) je ničla \(x^3 - 1\)
cele ničle delijo \(a_0\)
kandidati \(\pm\) delitelji
\(x^3 - 6x^2 + 11x - 6\): \(1, 2, 3\)
sode stopnje: graf se dotakne osi
lihe stopnje: graf jo seka
\((x - 1)^2(x + 2)\)
\(p(x) = a_n(x - x_1)\cdots(x - x_n)\)
osnovni izrek algebre: \(n\) kompleksnih ničel
\(x^2 + 1 = (x - i)(x + i)\)

6Neenačbe

ničle + predznak med njimi
tabela predznakov ali skica
\((x - 1)(x + 2) > 0\): \(x < -2\) ali \(x > 1\)

7Racionalna funkcija

\(f(x) = \frac{p(x)}{q(x)}\)
\(D_f\): \(q(x) \ne 0\)
\(\frac{x + 1}{x - 2}\): \(x \ne 2\)
ničle števca
ničle funkcije
\(\frac{x + 1}{x - 2}\): \(x = -1\)
ničle imenovalca
poli (navpične asimptote)
\(x = 2\)
st \(p\) < st \(q\): \(y = 0\)
vodoravna asimptota
\(\frac{1}{x^2 + 1}\)
st \(p\) = st \(q\): \(y = \frac{a_n}{b_n}\)
razmerje vodilnih
\(\frac{2x + 1}{x - 3}\): \(y = 2\)
st \(p\) = st \(q\) + 1
poševna: kvocient deljenja
\(\frac{x^2 + 1}{x} = x + \frac1x\): \(y = x\)

8Enačbe

pomnoži z imenovalcem, preveri pogoj
racionalna enačba
\(\frac{2}{x - 1} = 1\): \(x = 3\)
\(\frac{p}{q} > 0\)
neenačba: tabela predznakov ničel in polov
\(\frac{x}{x - 1} < 0\): \(x \in (0, 1)\)

!Pazi

  • Pri dvojni ničli graf ne seka osi.
  • Neenačbe ne množi z imenovalcem (neznan predznak).
  • Pri dvojni ničli predznak ne zamenja.
