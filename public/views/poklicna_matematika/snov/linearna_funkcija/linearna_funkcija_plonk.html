Linearna funkcija in linearne enačbe

Cela razlaga

1Točke in razdalje

\(d(A, B) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\)
razdalja
\(A(1, 2), B(4, 6)\): \(d = 5\)
\(S\left(\frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2}\right)\)
razpolovišče
\(A(1, 2), B(5, 4)\): \(S(3, 3)\)
\(T\left(\frac{x_1 + x_2 + x_3}{3}, \frac{y_1 + y_2 + y_3}{3}\right)\)
težišče
\((0,0), (6,0), (0,3)\): \(T(2, 1)\)

2Linearna funkcija

\(f(x) = kx + n\)
\(k\) smerni koeficient, \(n\) začetna vrednost
\(f(x) = 2x - 4\): ničla \(x = 2\)
\(k = \frac{y_2 - y_1}{x_2 - x_1}\)
naklon skozi dve točki
\((1, 3), (3, 7)\): \(k = 2\)
\(k = \tan\varphi\)
kot z osjo \(x\)
\(k = 1\): \(\varphi = 45^\circ\)

3Enačbe premice

\(y - y_1 = k(x - x_1)\)
skozi točko z naklonom
skozi \((1, 2)\), \(k = 3\): \(y = 3x - 1\)
\(ax + by + c = 0\)
implicitna oblika
\(2x - y + 3 = 0\)
\(\frac{x}{m} + \frac{y}{n} = 1\)
odsekovna: \(m, n\) odseka na oseh
\(\frac{x}{2} + \frac{y}{4} = 1\)
\(k_1 = k_2\) / \(k_1 k_2 = -1\)
vzporedni / pravokotni premici
\(k = 2\): pravokotna ima \(k = -\frac12\)
\(\tan\varphi = \left|\frac{k_2 - k_1}{1 + k_1 k_2}\right|\)
kot med premicama
\(k_1 = 1, k_2 = 0\): \(45^\circ\)
\(d = \frac{|a x_0 + b y_0 + c|}{\sqrt{a^2 + b^2}}\)
razdalja točke od premice
\((0,0)\) do \(3x + 4y - 10 = 0\): \(d = 2\)

4Sistemi

zamenjalni ali nasprotni koeficienti
dve enačbi, dve neznanki
\(x + y = 5,\ x - y = 1\): \((3, 2)\)
\(k_1 = k_2\), \(n_1 \ne n_2\)
ni rešitve (vzporedni)
\(n_1 = n_2\): neskončno rešitev

5Enačbe in neenačbe

\(ax + b = 0 \Rightarrow x = -\frac{b}{a}\)
linearna enačba
\(3x - 6 = 0\): \(x = 2\)
množenje z negativnim obrne znak
linearna neenačba
\(-2x < 6\): \(x > -3\)

!Pazi

  • Navpična premica \(x = a\) nima smernega koeficienta.
