Kvadratna funkcija in kvadratna enačba

Cela razlaga

1Oblike zapisa

\(f(x) = ax^2 + bx + c\)
splošna; \(c\) je začetna vrednost
\(x^2 - 4x + 3\)
\(f(x) = a(x - p)^2 + q\)
temenska, \(T(p, q)\)
\((x - 2)^2 - 1\): \(T(2, -1)\)
\(f(x) = a(x - x_1)(x - x_2)\)
ničelna
\((x - 1)(x - 3)\)
\(p = -\frac{b}{2a},\ q = -\frac{D}{4a}\)
teme
\(x^2 - 4x + 3\): \(p = 2, q = -1\)

2Ničle

\(x_{1,2} = \frac{-b \pm \sqrt{D}}{2a},\ D = b^2 - 4ac\)
kvadratna enačba
\(x^2 - 4x + 3\): \(D = 4\), \(x = 1, 3\)
\(D > 0,\ D = 0,\ D < 0\)
dve, ena dvojna, nobene realne
\(x^2 + 1\): \(D = -4\)
\(x_1 + x_2 = -\frac{b}{a},\ x_1 x_2 = \frac{c}{a}\)
Vietovi pravili
\(x^2 - 5x + 6\): vsota 5, produkt 6

3Graf in presečišča

\(a > 0\)
odprta navzgor, \(q\) je minimum
\(a < 0\): navzdol, \(q\) maksimum
\(ax^2 + bx + c = kx + n\)
presečišče s premico: \(D\) da število presečišč
\(D = 0\): tangenta

4Kvadratna neenačba

ničle + skica parabole
\(f(x) > 0\), kjer je parabola nad osjo
\(x^2 - 4x + 3 < 0\): \(x \in (1, 3)\)

!Pazi

  • Pri \(a < 0\) se znak neenačbe med ničlama obrne.
  • V \(p = -\frac{b}{2a}\) ne pozabi minusa.
