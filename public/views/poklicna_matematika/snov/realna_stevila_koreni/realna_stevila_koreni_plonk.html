1Realna števila

\(\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}\)
številske množice
\(\sqrt2, \pi\) sta iracionalni
\([a, b],\ (a, b),\ [a, \infty)\)
intervali (oglati: z mejo)
\(-1 \le x < 3\): \([-1, 3)\)
zaokroževanje
5 ali več navzgor

2Absolutna vrednost

\(|x| = x\) za \(x \ge 0\), \(-x\) za \(x < 0\)
razdalja od 0
\(|-3| = 3\)
\(|x - a| < r \iff a - r < x < a + r\)
neenačba
\(|x - 2| < 3\): \(x \in (-1, 5)\)
\(|x - a| = r \Rightarrow x = a \pm r\)
enačba (\(r \ge 0\))
\(|x + 1| = 4\): \(x = 3\) ali \(x = -5\)
\(\Delta x = |x - x_0|,\ \delta = \frac{\Delta x}{|x|}\)
absolutna, relativna napaka
\(\pi \approx 3{,}14\): \(\Delta \approx 0{,}0016\)

3Koreni

\(\sqrt[n]{a}\,\sqrt[n]{b} = \sqrt[n]{ab}\)
enaki korenski eksponenti
\(\sqrt{2}\sqrt{8} = 4\)
\(\sqrt[n]{a^m} = a^{\frac{m}{n}}\)
potenca z racionalnim eksponentom
\(8^{\frac23} = \sqrt[3]{64} = 4\)
\(\sqrt{a^2} = |a|\)
sod koren vrne absolutno vrednost
\(\sqrt{(-3)^2} = 3\)
\(\sqrt[n]{\sqrt[m]{a}} = \sqrt[nm]{a}\)
koren korena
\(\sqrt{\sqrt[3]{x}} = \sqrt[6]{x}\)
\(\frac{a}{\sqrt{b}} = \frac{a\sqrt{b}}{b}\)
racionalizacija
\(\frac{1}{\sqrt{3} - 1} = \frac{\sqrt{3} + 1}{2}\)
delno korenjenje
izpostavi popolne kvadrate
\(\sqrt{50} = 5\sqrt{2}\)

!Pazi

  • \(\sqrt{a^2} = |a|\), ne \(a\).
