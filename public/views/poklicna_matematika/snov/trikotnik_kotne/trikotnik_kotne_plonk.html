Pravokotni trikotnik, sinusni in kosinusni izrek

Cela razlaga

1Pravokotni trikotnik

\(a^2 + b^2 = c^2\)
Pitagorov izrek
\(3, 4\): \(c = 5\)
\(a^2 = c\,a_1,\ b^2 = c\,b_1\)
Evklidov izrek
\(c = 10, a_1 = 3,6\): \(a = 6\)
\(v_c^2 = a_1 b_1\)
višinski izrek
\(a_1 = 4, b_1 = 9\): \(v_c = 6\)

2Pravokotni trikotnik

\(\sin\alpha = \frac{a}{c},\ \cos\alpha = \frac{b}{c},\ \tan\alpha = \frac{a}{b}\)
nasprotna, priležna, hipotenuza
\(3, 4, 5\): \(\sin\alpha = 0{,}6\)
\(30^\circ: \frac12, \frac{\sqrt3}{2}\); \(45^\circ: \frac{\sqrt2}{2}\)
\(\sin, \cos\) znanih kotov
\(\sin 60^\circ = \frac{\sqrt3}{2}\)

3Splošni trikotnik

\(\frac{a}{\sin\alpha} = \frac{b}{\sin\beta} = 2R\)
sinusni izrek
\(a = 5, \alpha = 30^\circ\): \(R = 5\)
\(c^2 = a^2 + b^2 - 2ab\cos\gamma\)
kosinusni izrek
\(a = 3, b = 5, \gamma = 60^\circ\): \(c = \sqrt{19}\)

4Ploščina

\(S = \frac{ab\sin\gamma}{2}\)
iz dveh stranic in vmesnega kota
\(a = 4, b = 5, \gamma = 30^\circ\): \(S = 5\)
