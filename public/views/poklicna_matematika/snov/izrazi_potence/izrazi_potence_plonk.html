Potence in algebrski izrazi

Cela razlaga

1Potence

\(a^m a^n = a^{m+n},\ \frac{a^m}{a^n} = a^{m-n}\)
enaki osnovi
\(2^3 \cdot 2^4 = 2^7\)
\((a^m)^n = a^{mn},\ (ab)^n = a^n b^n\)
potenca potence, produkta
\((x^2)^3 = x^6\)
\(a^0 = 1,\ a^{-n} = \frac{1}{a^n}\)
\(a \ne 0\)
\(2^{-3} = \frac{1}{8}\)
\(\left(\frac{a}{b}\right)^{-n} = \left(\frac{b}{a}\right)^n\)
negativen eksponent obrne ulomek
\(\left(\frac{2}{3}\right)^{-2} = \frac{9}{4}\)

2Potenciranje izrazov

\((a \pm b)^2 = a^2 \pm 2ab + b^2\)
kvadrat dvočlenika
\((x - 3)^2 = x^2 - 6x + 9\)
\((a \pm b)^3 = a^3 \pm 3a^2 b + 3ab^2 \pm b^3\)
kub dvočlenika
\((x + 1)^3 = x^3 + 3x^2 + 3x + 1\)
\((a + b + c)^2 = a^2 + b^2 + c^2 + 2ab + 2ac + 2bc\)
kvadrat tročlenika
\((x + y + 1)^2\)

3Razstavljanje

\(a^2 - b^2 = (a - b)(a + b)\)
razlika kvadratov
\(x^2 - 9 = (x - 3)(x + 3)\)
\(a^3 \pm b^3 = (a \pm b)(a^2 \mp ab + b^2)\)
vsota, razlika kubov
\(x^3 - 8 = (x - 2)(x^2 + 2x + 4)\)
\(x^2 + (a + b)x + ab = (x + a)(x + b)\)
Vietovo pravilo
\(x^2 - 5x + 6 = (x - 2)(x - 3)\)
izpostavljanje, združevanje
najprej izpostavi skupni faktor
\(ax + ay + bx + by = (a + b)(x + y)\)

4Ulomki

okrajšaj šele po razstavljanju
krajšamo faktorje, ne členov
\(\frac{x^2 - 4}{x + 2} = x - 2\), \(x \ne -2\)
skupni imenovalec = \(v\) imenovalcev
seštevanje
\(\frac{1}{x} + \frac{1}{x+1} = \frac{2x + 1}{x(x+1)}\)

!Pazi

  • \((a + b)^2 \ne a^2 + b^2\).
  • Krajšamo faktorje, ne členov.
